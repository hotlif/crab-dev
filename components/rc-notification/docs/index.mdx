# Notification 通知提醒

在页面角落展示包含详细内容或操作入口的通知。

[打开组件工作台](/components/rc-notification/workbench/)

## 何时使用

- 展示需要标题和详细说明的系统通知或异步任务结果。
- 为通知提供查看详情、重试等后续操作。
- 在页面角落保留通知，同时允许用户继续当前任务。

仅需简短反馈时可使用 Message；必须获得用户确认时使用 Dialog。

## 动画与关闭

通知通过 CSS 过渡从对应边缘进入和退出，进度条使用 CSS 关键帧，不依赖 Motion。系统开启减少动态效果时关闭这些动画，自动关闭仍正常工作。

`useNotification` 在每个方向独立堆叠最多 3 条通知，仅最上层计时。鼠标悬停或通知中的操作获得键盘焦点时暂停，离开后继续剩余时间；`duration={0}` 时保持显示且隐藏倒计时条。关闭后等待退场完成再移除节点。

多条通知以卡片层叠展示：最新一条完整显示，后两层按 96%、92% 缩小，每层露出 8px 边缘，并使用较浅的阴影和区分明暗的表面色。后层暂时隐藏文字和操作，关闭前层后平滑补位，避免多个关闭按钮或正文相互重叠。顶部通知向下叠放，底部通知向上叠放。

通知根节点接受原生 `div` 属性和 `className`。自定义动画通过 CSS 类实现，不再接收 Motion 的 `initial`、`animate`、`exit` 或 `transition` 属性。

关闭按钮使用通知表面的语义前景色，并保留完整的不透明焦点环与悬停、按下反馈，不通过整体透明度降低操作可见性。局部样式通过公开 Button 令牌映射，不改变其他按钮的颜色或行为。

## API

`notification.open({ title, description, duration })` 返回 `{ id, close, update }`。可调用 `handle.close()` 或 `notification.close(handle.id)` 关闭指定通知；调用 update 修改内容或时长会保留 ID 并重新计时。duration=0 时持续展示。onClose 只执行一次，已经关闭的句柄不能重新打开通知。

## 三套设计风格

Apple 使用 16px 圆角的通知面板；MD3 Expressive 使用 12px 内容容器；shadcn 使用 8px 圆角和细描边。通知队列、关闭按钮、键盘焦点暂停和倒计时与主题无关。此组件为持续通知模式扩展，不宣称等同于 MD3 snackbar 或操作系统通知中心。

切换文档站设计风格后，本页演示同步使用该设计；浅色和深色模式分别使用配对语义颜色。

## 三体系规格与验收边界

持久非阻塞通知属于项目 Web 扩展，不等同于模态 alert 或操作系统 notification。六方向、受控 open、队列与句柄更新保留；duration=0 明确避免采集途中自动消失。关闭按钮使用真实公开 Button 的焦点与状态层，堆叠背面不进入无障碍树。

| 体系 | 组件视觉规则 |
| --- | --- |
| MD3 Expressive | 沿用反馈表面、明确内容层级与可达关闭操作；桌面通知队列为扩展。 |
| Apple | 轻量浮动表面与精确对齐，保持自主 Web 定位。 |
| shadcn | 依据 Card/Alert 的中性容器组合，参考提交没有同名组件；方向与堆叠均为扩展。 |

本包几何与视觉来源：root.width / padding / border-radius / box-shadow；title/content 字阶与行高；close 的公开 Button 颜色/状态角色；stack.translate/gap/scale；窄屏 max-width 与内容内部滚动。设计值只在对应 token.toml 与它引用的语义角色维护，验收测量读取实际 DOM 计算值。

颜色、字阶、形状、状态和动效分别从 L2 角色映射到包内 L3；Theme 负责最近配置边界。明暗模式使用配对前景/背景，不进行整体反相。视觉边界与命中区域分别检查，焦点截图保留外部轮廓与阴影。强制颜色采用系统色；减少动画保留信息与最终状态。

矩阵定义在本包 `docs/visual.json`，场景使用 `visual-matrix.demo.tsx`。Chromium 覆盖其中全部设计/明暗/命名尺寸/适用密度/状态；Firefox 与 WebKit 按 `crossEngine` 的默认展示和重点交互子集执行。窄屏、RTL、中英文、长文本、品牌覆盖和配置切换后的草稿保持另有场景；未运行、未人工复核或失败的项不能计为通过。开放尺寸输入的代表样本不等于无限集合的穷尽。
