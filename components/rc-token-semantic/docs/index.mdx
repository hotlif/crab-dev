# Token Semantic

语义设计令牌（Layer 2）把 Token Global 的基础视觉原语映射为品牌色、表面色、文字色、
间距、焦点环与动效等界面语义。组件令牌应优先引用这一层，以便主题切换时只覆盖语义变量。
