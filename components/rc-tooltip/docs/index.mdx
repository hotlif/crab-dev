# Tooltip 文字提示

在鼠标悬停或键盘聚焦时展示简短说明。

[打开组件工作台](/components/rc-tooltip/workbench/)

## 何时使用

- 当需要对按钮、图标、链接等元素提供额外说明时。
- 当空间有限无法直接展示文字时，使用 Tooltip 在悬浮时补充信息。

## 主要功能

- 支持 12 个弹出方位，自动跟随空间翻转。
- 支持受控与非受控模式。
- 支持鼠标悬浮与键盘聚焦触发。
- 可配置出入场延迟与箭头显隐。
- 内置无障碍支持（`role="tooltip"` + `aria-describedby`）。

## 设计与交互

默认采用 M3 **plain tooltip**：无箭头、反色表面、与触发元素相隔 4px。鼠标可以移入提示区域继续阅读；离开触发元素和提示区域 1.5 秒后关闭，也可按 Escape 关闭。`arrow` 是兼容扩展，需要时显式开启。

提示用于补充简短说明。重要信息应直接呈现；含操作按钮的内容应使用相应弹层，不要把 plain tooltip 当作富交互容器。
