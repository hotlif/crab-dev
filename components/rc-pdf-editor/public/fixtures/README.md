# PDF interaction fixtures

`LiberationSans-Regular.ttf` is the unmodified real Liberation Sans font from the pinned official Playwright v1.64.1 noble image (`sha256:47b510dd9230bf0b9bfc9b20102241e577ea7a99334ab4c3ca19f19770e9b8ea`), `/usr/share/fonts/truetype/liberation/LiberationSans-Regular.ttf`. Its SHA-256 is `4659bc0c58c5028dd488ec928d41d9265db43d9b669fc14ca8b0832daca7b144`. The complete supplied copyright and SIL Open Font License are retained as `LICENSE.LiberationSans`. The font is unchanged and its original name retained. It supplies real Latin glyphs for the embedded document text; host UI language is a separate configuration.

`visual-document.pdf` is generated from the existing authored `scripts/web-component/sample-pdf.mjs`. The two real RGB PNG files are deterministic authored image data generated by `scripts/visual-fixtures.mjs`. `build:runtime` writes these assets through `scripts/copy-runtime.mjs`; they are input fixtures, not screenshots or accepted baselines. The workbench serves them from the current local origin. `public/runtime/pdf-editor.js` is generated from the existing production standalone Web Component build, including its production React, CSS, Worker and WASM.
