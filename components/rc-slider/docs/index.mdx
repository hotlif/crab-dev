# Slider 滑块

通过拖动滑块在指定数值范围内选择值。

[打开组件工作台](/components/rc-slider/workbench/)

## 何时使用

用于音量、亮度或阈值等有明确范围的数值调整，可选择连续值或按步长选择离散值。需要精确键入数值时可使用 NumberEdit。

## 桌面密度

使用新版竖向手柄、轨道间隙与终点标记。`size` 提供 `xs`（默认）、`s`、`m`、`l`、`xl`，轨道高度分别为 4、6、8、12、16px，手柄高度分别为 20、24、28、32、40px。这是保留 Expressive 竖向手柄的项目密度定制，尺寸不等同于官方 Expressive 规格；粗指针仍提供至少 48px 的纵向操作区域。按压时手柄变细；数值更新立即跟随拖动，不对拖动位置添加延迟。
