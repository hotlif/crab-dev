# Spin 加载中

显示耗时操作的加载状态，支持延迟显示和区域加载遮罩。

[打开组件工作台](/components/rc-spin/workbench/)

## 何时使用

- 请求或计算需要等待时，显示操作仍在进行。
- 局部区域刷新时，使用包裹模式标记加载范围。
- 内容结构已知时，可使用 Skeleton 保留布局；进度可计算时，应展示明确的进度。

## 延迟显示

`delay` 控制指示器出现前的等待时间，避免短请求导致指示器频繁闪现。例如 `delay={300}` 表示加载持续超过 300 ms 后才显示。

延迟只影响出现时机。`spinning` 变为 `false` 时，指示器立即隐藏。

## Material 3 指示器

默认的 `variant="circular"` 适合按钮、表格和紧凑区域。需要更醒目的品牌化等待反馈时，可使用 `variant="expressive"`；它通过形状变化表达持续活动，并遵循 Material 3 Expressive 的形状与动态设计语言。

两种指示器都只表达“正在进行”，不表示可计算的进度。能够确定完成比例时，应使用进度条或进度环。

## 复用 SpinIndicator

`Spin` 提供 `role="status"` 和 `aria-live`。宿主已提供加载语义时，例如按钮已设置 `aria-busy`，可改用具名导出的 `SpinIndicator`，避免重复播报。

`SpinIndicator` 和 `ExpressiveSpinIndicator` 都使用 `aria-hidden` 隐藏纯视觉图形，加载语义由宿主负责。尺寸与配色可通过 CSS 变量调整：

```tsx
import { css } from '@crab-dev/css';
import { SpinIndicator, TokenVars as spinVars } from '@crab-dev/rc-spin';

// 指示环随宿主字号缩放，并使用宿主前景色。
const style = css`
    --rc-spin-size: 1em;
    ${spinVars['ring.indicator.stroke']}: currentColor;
    ${spinVars['ring.track.stroke']}: transparent;
`;
```

`rc-button` 使用 `SpinIndicator`，`rc-table-pro` 使用 `Spin`，共同复用加载指示样式。

## 无障碍

- 使用 `role="status"` 和 `aria-live="polite"` 提供加载状态播报。
- `tip` 提供具体的操作说明；未设置时使用 `label`，默认值为“加载中”。
- 包裹模式为容器设置 `aria-busy`，并通过 `inert` 阻止内容区的指针交互和键盘聚焦。
- 在 `prefers-reduced-motion` 下，将旋转改为低频透明度变化，保留加载反馈。

两种指示器在减少动态效果时均保留 1.6 秒的低频呼吸。圆形指示器不再旋转；Expressive 关闭轨道旋转和形状变化，保留原地的轻微缩放与透明度呼吸。外层占位尺寸保持不变。

加载中的必要反馈会保护自身的呼吸时长和循环次数，避免 Wake 0.1.45 等宿主的全局减少动画重置把它缩短成一次不可见动画。此例外仅作用于指示器的减少动画分支，不会恢复页面上的普通装饰动画。

## 三套设计风格

Material 使用带底轨的品牌色圆弧；shadcn 使用无底轨的中性色圆弧；Apple 使用中性的十二辐条活动指示器。三套设计共享 status 语义、延迟显示和减少动态效果时的低频呼吸；expressive 仍是显式选择的 M3 形变扩展。

切换文档站设计风格后，本页演示同步使用该设计；浅色和深色模式分别使用配对语义颜色。
