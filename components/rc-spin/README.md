# @crab-dev/rc-spin

显示耗时操作的加载状态，支持延迟显示和区域加载遮罩。

## 主要功能

- 不传 `children` 时显示独立指示器；传入时显示区域加载遮罩。
- `delay` 延迟显示，避免短请求引起指示器闪现。
- 包裹模式使用 `aria-busy` 表达加载状态，并通过 `inert` 暂停内容区交互。
- `tip` 提供操作说明，`label` 提供默认加载名称。
- 减少动态效果偏好下，将旋转改为低频透明度变化。
- 宿主已提供加载语义时，可复用仅供视觉展示的 `SpinIndicator`。
