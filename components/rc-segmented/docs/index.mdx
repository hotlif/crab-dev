# Segmented 分段控制器

以紧凑的分段选项切换视图、时间粒度或筛选值。

[打开组件工作台](/components/rc-segmented/workbench/)

## 何时使用

- 快速切换视图、时间粒度或筛选维度。
- 选项较少，且需要在同一区域内直接比较。

Segmented 负责选择值，内容展示由业务代码处理；需要同时管理标签与内容面板时使用 Tabs。通常保持 2–5 个简短选项，选项较多时使用 Select。
