# Segmented 分段控制器

以紧凑的分段选项切换视图、时间粒度或筛选值。

[打开组件工作台](/components/rc-segmented/workbench/)

## 何时使用

- 快速切换视图、时间粒度或筛选维度。
- 选项较少，且需要在同一区域内直接比较。

Segmented 负责选择值，内容展示由业务代码处理；需要同时管理标签与内容面板时使用 Tabs。通常保持 2–5 个简短选项，选项较多时使用 Select。

Material 采用 M3 基线的单选分段按钮：等宽选项、40px 默认视觉高度、48px 命中高度、胶囊描边与分隔线。选中项使用次要色容器和勾选图形；文字选项的前置图标由勾选图形替换，仅图标选项同时保留图标和勾选标记。每个仅图标选项必须提供 `aria-label`。

Tab 进入原生单选组，方向键切换选项，Space 或 Enter 选中当前聚焦项。这是 Web 单选组的键盘模型。此组件保留 M3 基线，不等同于 Expressive 的 connected button group。

## 三套风格

| 风格 | 容器与选中反馈 | small / middle / large 视觉高度 |
| --- | --- | --- |
| macOS | 2px 内边距的中性轨道、圆角浮起选中块，保留原选项图标 | 24 / 28 / 32px |
| Material | 胶囊描边、连续分段边界、次要色填充与勾选 | 32 / 40 / 40px |
| shadcn | 3px 内边距的 muted 轨道、表面色选中块与轻阴影 | 28 / 32 / 36px |

表中是分段本身的视觉高度，macOS 和 shadcn 的轨道另含上下内边距。macOS 与 shadcn 不显示 Material 的勾选图形；读屏始终通过原生 radio 的 `checked` 状态获取选择结果。三种风格均保留焦点、禁用、悬停、按压和减少动态效果处理，命中区域至少 48px。

参考核对日期：2026-10-22。Material Web 未提供 Segmented 组件，Material 变体直接依据 [M3 Guidelines](https://m3.material.io/components/segmented-buttons/guidelines)、[Specs](https://m3.material.io/components/segmented-buttons/specs)、[Accessibility](https://m3.material.io/components/segmented-buttons/accessibility)。macOS 参考 [Apple Segmented controls](https://developer.apple.com/design/human-interface-guidelines/segmented-controls)，shadcn 参考 [Tabs 文档](https://ui.shadcn.com/docs/components/radix/tabs)及其[轨道实现](https://github.com/shadcn-ui/ui/blob/main/apps/v4/registry/new-york-v4/ui/tabs.tsx)，只借鉴分段选择外观，组件语义仍为单选组。
