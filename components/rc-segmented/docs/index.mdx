# Segmented 分段控制器

以紧凑的分段选项切换视图、时间粒度或筛选值。

[打开组件工作台](/components/rc-segmented/workbench/)

## 何时使用

- 快速切换视图、时间粒度或筛选维度。
- 选项较少，且需要在同一区域内直接比较。

Segmented 负责选择值，内容展示由业务代码处理；需要同时管理标签与内容面板时使用 Tabs。通常保持 2–5 个简短选项，选项较多时使用 Select。

采用 M3 基线的单选分段按钮：等宽选项、40px 视觉高度、48px 命中高度、胶囊描边与分隔线。选中项使用次要色容器和勾选图形；文字选项的前置图标由勾选图形替换，仅图标选项则同时保留图标和勾选标记。每个仅图标选项必须提供 `aria-label`。

Tab 进入原生单选组，方向键切换选项，Space 或 Enter 选中当前聚焦项。这是 Web 单选组的键盘模型。此组件保留 M3 基线，不等同于 Expressive 的 connected button group。
