# NumberEdit 数字输入框

输入数值，支持步进、范围限制、千分位和科学计数法显示。

[打开组件工作台](/components/rc-number-edit/workbench/)

## 三套主题的组合输入

数字编辑的字段外壳复用 LineEdit，Apple、MD3 与 shadcn 同步切换标签位置、密度、边界、聚焦和错误反馈；步进按钮复用 Button。金额、科学计数法、范围修正和键盘步进保持原有行为，不为主题维护第二套数值状态。

基础演示的 Filled 字段在 MD3 中使用浮动标签与底线，在桌面风格中呈现紧凑矩形字段。Apple 的布局与阴影为 Web 适配；数字格式和可编辑草稿沿用本库能力。

依据：[Apple Text fields 的数值格式建议](https://developer.apple.com/design/human-interface-guidelines/text-fields)、[Material Web Text field](https://material-web.dev/components/text-field/)、[LineEdit 字段边界](/components/rc-line-edit)。核对日期：2026-10-22。

## 何时使用

用于数量、金额、阈值等数值录入。支持加减按钮、方向键、长按步进和大步长调整；失焦时按范围限制修正数值。

显示时可使用千分位或自定义格式。极大、极小数值可显示为 `1.23×10²¹` 等科学计数法，聚焦后转为便于编辑的 `e` 记法。

## 标签与设计风格

数字输入框复用 LineEdit 的字段外观，支持 `label`、`appearance="outlined" | "filled"`、`supportingText` 和 `errorText`。全局切换 Material Design 3、Apple 与 shadcn 时，标签、容器和说明会统一跟随；已有数值与编辑草稿继续保留。Material 使用浮动标签，Apple 与 shadcn 使用静态标签。

使用 `label` 提供持续可见的字段名称；`supportingText` 说明单位或取值范围。校验失败时用 `errorText` 替换说明，组件会关联错误信息并标记输入无效。仅需预先显示边界状态时可使用 `status="error"`，但仍应提供能说明修复方法的文字。

## 编辑、步进与范围

**现有实现**：键入文本先保留为编辑草稿；失焦、步进或清除时提交数值。键盘 ↑ / ↓、PageUp / PageDown、Shift + ↑ / ↓、滚轮和步进按钮使用同一数值计算路径。`aria-valuenow` 随当前可解析的编辑文本更新。

| 场景 | 结果与规则 |
| --- | --- |
| 原值 3，键入 20 后按 ↑ | 得到 21，不能从旧值 3 得到 4 |
| 键入 20.5，step 为 1，未指定 precision | 得到 21.5，保留输入的小数精度 |
| 清空编辑文本后按 ↑ | 从 0 开始步进，再应用 min / max |
| 文本尚不能解析，例如单独的负号 | 步进从上次已提交值开始；尚无数值时从 0 开始 |
| 当前编辑值达到 min / max | 对应方向按钮禁用；键盘步进同样不得越界 |
| 显式指定 precision | 按该精度规范提交值，不能用于无限精度金额运算 |

`parser` 应是无副作用的解析函数，并返回有限数或 `null`；组件会在编辑期间读取它以同步步进和无障碍数值。旧调用方若假定 parser 只在失焦时执行，应移出其中的请求或其他副作用。`stringMode` 仅接受 `false`，类型检查拒绝尚未实现的 `true`。组件使用 number，不支持任意精度字符串计算。

**正例**：通过可见标签说明“预警阈值（万元）”，就近说明范围；编辑 20.5 后步进得到 21.5。**反例**：仅用 placeholder 作为名称，或步进时恢复旧值，导致用户误以为刚才的输入已经保存。

后缀单位与步进器之间保留独立间距，使键盘焦点环不盖住 `%` 等内容；RTL 中按逻辑顺序排列。没有后缀时不保留额外空位，`controls={false}` 仍显示调用方提供的后缀。

验收：分别用键盘和鼠标测试草稿步进、空值、边界、带小数的 step、只读与禁用。格式化显示不改变真实数值；长数值在聚焦后可完整编辑。粗指针下加减操作提供 48px 目标，桌面尺寸跟随控件档位；边界值禁用对应方向按钮，剩余按钮保持键盘可达。`test:browser` 使用发布样式核对三体系、浅深色及 LTR/RTL 的后缀与焦点环几何；粗指针的实际媒体配置与键盘导航另需真实浏览器验收。科学计数法覆盖层和文字缩放仍需独立复核。通用规则见[输入与选择](https://material-web.dev/components/text-field/)和[无障碍](/guides/accessibility)。

## API

`value/defaultValue/onValueChange(next, details)` 管理数值；`null` 表示空值，两种初始化方式互斥。语义回调在失焦、步进和清除提交时通知，`details.reason` 分别为 `blur/step/clear`；原生 `onChange` 接收输入事件，编辑草稿不会被误当作已提交数值。父级更新受控值不触发回调。

`details.event` 保留实际触发提交的输入、按钮或原生滚轮事件。长按重复步进沿用原始按下事件；按钮的键盘或辅助技术激活保留实际 click 事件。清除只提交一次数值变化，并调用一次 `onClear`。

`size` 跟随控件尺寸，与数据密度独立。增减按钮名称和科学计数法的读屏说明跟随 `locale`；切换语言保留数值且不触发提交回调。自定义数值 `formatter/parser` 优先。长数值与科学计数法保留可访问的真实值，控件不承担任意精度计算。
