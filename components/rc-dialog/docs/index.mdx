# Dialog

展示一个对话框，提供标题、内容区、操作区。

[打开 Dialog 对话框 工作台](/components/rc-dialog/workbench/)

## 何时使用

需要用户处理事务，又不希望跳转页面以致打断工作流程时，可以使用 Dialog 在当前页面正中打开一个浮层，承载相应的操作。
