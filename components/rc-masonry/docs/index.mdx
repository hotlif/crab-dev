# Masonry

瀑布流布局组件，将子元素按多列自适应排列，优先填充最短列。

[打开 Masonry 瀑布流 工作台](/components/rc-masonry/workbench/)

## 何时使用

- 图片画廊、卡片列表等高度不等的内容展示
- 需要紧凑排列、充分利用垂直空间的场景
