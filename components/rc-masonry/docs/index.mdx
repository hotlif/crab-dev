# Masonry 瀑布流

将高度不同的内容按多列排列，优先填充最短列。

列从当前书写方向的行内起始侧排列：LTR 从左侧开始，RTL 从右侧开始。`sequential` 按 DOM 顺序依次分配列；默认模式优先填充最短列。切换方向只镜像列的位置，不改变内容的 DOM 顺序。

省略 `gutter` 时，水平列距和垂直项距共同使用最近 ConfigProvider 的 `density` 间距。切换 compact / standard / comfortable 会从实际 CSS 间距重新计算列宽、位置和容器高度；`size` 不改变此间距。显式 `gutter`（包括 `0`）优先于密度，适合需要固定几何的画廊。

[打开组件工作台](/components/rc-masonry/workbench/)

## 何时使用

- 图片画廊、卡片列表等高度不等的内容展示
- 需要紧凑排列、充分利用垂直空间的场景

## 设计风格与主题

Masonry 是布局容器；列数、阅读顺序和内容尺寸属于布局输入，间距与动效继承语义角色。卡片内容应使用当前设计的自有组件或语义样式，无需为三套风格复制布局算法。
示例在强制颜色模式下使用成对的 Canvas / CanvasText 与可见边界，保留 Item 文字和布局间距；不以品牌容器色妨碍系统高对比阅读。
这是本库的瀑布流布局扩展。MD3、Apple、shadcn/ui 分别决定承载内容的表面、间距和动效；定位算法、阅读顺序与测量契约独立维护。RTL、容器变化和动态内容需要实测，不以某套列表规范代替布局验收。

设计来源与固定参考版本见[三套设计体系](/guides/design-styles)，当前已核对范围见[设计覆盖矩阵](/guides/design-coverage)。这段说明记录适配边界，不代表完整视觉验收已通过。
