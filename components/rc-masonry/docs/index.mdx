# Masonry 瀑布流

将高度不同的内容按多列排列，优先填充最短列。

[打开组件工作台](/components/rc-masonry/workbench/)

## 何时使用

- 图片画廊、卡片列表等高度不等的内容展示
- 需要紧凑排列、充分利用垂直空间的场景

## 设计风格与主题

Masonry 是布局容器；列数、阅读顺序和内容尺寸属于布局输入，间距与动效继承语义角色。卡片内容应使用当前设计的自有组件或语义样式，无需为三套风格复制布局算法。
本范围以 M3 Lists / Divider 的表面、分隔、状态和无障碍规则作为扩展依据；数据表、图表、PDF 编辑器和可拖动分栏并非 Material Web 的同名标准组件。macOS 与 shadcn 是本项目在相同交互能力上的设计变体，未引入第三方 UI 运行时，也不宣称原生平台逐像素复刻。
