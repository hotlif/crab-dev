# DropdownContainer 下拉容器

用于将下拉内容定位到触发元素附近，并统一管理浮层的打开、关闭与边界位置。

[打开 DropdownContainer 下拉容器 工作台](/components/rc-dropdown-container/workbench/)

## 何时使用

- Select、Menu 等需要相对触发器定位的下拉浮层。
- 下拉内容需要在窗口边缘自动调整位置，避免超出可视区域。
- 需要统一处理点击外部区域关闭、滚动和窗口尺寸变化的场景。
