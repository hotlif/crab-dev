# Realm 远程模块

运行时加载 Module Federation 远程模块，完成入口加载、共享依赖初始化、模块获取和渲染。`component` 协议在宿主 React 树中渲染远程组件；`mount` 协议通过生命周期函数挂载远程内容。

[打开组件工作台](/components/rc-realm/workbench/)

## 主要功能

- 优先复用宿主的 `default` 共享作用域；宿主未使用 Module Federation 时，创建作用域并注册 React 相关模块。
- 通过 Promise 缓存合并并发加载请求；失败或超时后清除对应缓存，允许重新加载。
- 提供延迟加载反馈，以及就近显示的错误说明和重试入口。

## 代码演示

“可重放的加载与错误”让真实模块请求保持等待：点击“返回错误”查看默认错误提示，使用其中的重试按钮重新加载，再点击“完成加载”显示远程内容。“重新加载”可以从成功状态重复这一过程，所有请求都在演示容器内完成。

## 两种接入协议

### component（默认）：远程导出 React 组件

远程与宿主共享同一 React 实例，在宿主 React 树中渲染。`remoteProps` 变化时更新组件属性，不重新加载模块。

```tsx
<Realm entry="https://cdn.example.com/remoteEntry.js" scope="orders" module="./OrderTable"
       remoteProps={{ tenantId }} />
```

### mount：远程导出生命周期对象

适配**跨框架**或**与宿主不同 React 版本**的远程。远程导出
`{ mount(container, props), update?(props), unmount?(container) }`：

- `mount` 应支持重复挂载和清理，并与 `unmount` 配对；可返回清理函数，卸载时先调用该函数，再调用 `unmount`。
- 提供 `update` 时，`remoteProps` 变化会触发增量更新；未提供时，Realm 卸载后重新挂载内容。

`mount` 协议可开启 `sandbox`，通过 Shadow DOM 隔离样式。`component` 协议不支持此选项：
注入 `document.head` 的普通样式无法直接应用到 Shadow DOM 内部。

## 远程应用的共享依赖配置

```js
// 远程应用的 webpack.config.js → ModuleFederationPlugin
shared: {
    react: { singleton: true, requiredVersion: '^19.0.0' },
    'react-dom': { singleton: true, requiredVersion: '^19.0.0' },
}
```

- React 共享依赖必须设置 `singleton: true`，以复用宿主已加载的实例，避免多个 React 实例引起 Hook 调用错误。
- 当前接入约定不支持 `strictVersion: true` 或 `eager: true`。请保持上面的共享配置，并验证远程应用与宿主的 React 版本兼容。

## 样式隔离边界

- `sandbox` 提供样式隔离，不隔离 JavaScript 执行环境。远程样式需要在 Shadow DOM 内生效，或通过 `styleSheets` 注入。
- CSS 自定义属性可从宿主继承到 Shadow DOM 内部，因此远程样式可以使用 `var(--token-semantic-*)`。
- Portal 弹层若挂载到 `document.body`，会离开 Shadow DOM 的样式范围。宿主位于原生模态对话框中时，应将弹层挂载到相应的 `dialog` 子树；可参考 Tooltip 和 DropdownContainer 的挂载处理。

## RealmError 错误码

| code | 阶段 |
|------|------|
| `ssr` | 非浏览器环境触发加载 |
| `script` | remoteEntry 网络加载失败（script onerror / module import 失败） |
| `container` | 加载成功但 `globalThis[scope]` 不存在或形状不符（scope 名错 / 非 MF remote） |
| `init` | `container.init(shareScope)` 抛错 |
| `factory` | `container.get(module)` 或模块工厂执行抛错 |
| `timeout` | 全程超过 `timeout`（默认 15s）期限 |
| `protocol` | 模块形态与所选协议不符（错误信息会指向另一协议） |
| `render` | 远程组件渲染期 / `mount()` 执行期抛错 |

加载失败或超时后，对应缓存会失效。点击错误提示中的“重试”可重新执行加载流程。

默认加载提示、错误标题、重试操作和库自产的错误说明跟随 `ConfigProvider.locale`，支持 `zh-CN` 与 `en-US`。切换语言会更新当前说明，不重新加载模块，也不重新挂载已就绪的远程内容。

`RealmError.message`、`cause` 和 `onError` 仍提供原始诊断；默认界面只根据库内部的错误来源与参数本地化，不按消息字符串猜测语言。调用方构造的 `RealmError`、远端自身的错误说明，以及显式覆盖的 `error.message` 保持原文。`errorFallback` 始终接收原始错误与重试函数，适合宿主自定义呈现。

## 工具函数

以下具名导出函数可用于预加载或独立加载模块，与组件共享缓存：

```ts
import { loadRemoteModule, preloadRemote, clearRemoteCache } from '@crab-dev/rc-realm';

// 绕过组件直接取远程模块（共享同一套缓存）
const mod = await loadRemoteModule({ entry, scope, module: './util' });
// hover 预热（吞错, 失败留给正式加载重试）
preloadRemote({ entry, scope, module: './OrderTable' });
// 清缓存（测试隔离 / 热更新用, 生产慎用；不删除 globalThis[scope]）
clearRemoteCache(entry, scope);
```

## 设计风格与主题

Realm 是视觉中性的可选加载集成。默认加载、错误和重试反馈复用 Spin、Alert、Button，分别消费 Material Design 3 Expressive、Apple、shadcn/ui 的现有组件契约；来源和固定基线见[三套设计体系](/guides/design-styles)。入口加载、共享依赖、缓存、接入协议与沙箱是本库的集成能力，不以列表或分隔线规格作为整体依据。

`component` 协议在宿主 React 树中渲染；远端是否共享配置仍取决于所用库实例和共享约定。`mount` 协议中的独立应用需要通过挂载接口显式连接配置，Shadow DOM 的 CSS 变量继承不等于跨 React 根传递 Context。Realm 不改写远端自己的显式配色、字体和内容。

默认反馈、样式隔离和远程内容分别核对。Realm 的加载或渲染成功不能替代远端应用的设计与交互验收；三体系及浅深色的覆盖等级以[覆盖矩阵](/guides/design-coverage)和对应候选记录为准。
