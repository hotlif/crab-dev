# BarChart

基于 [rc-canvas](/rc-canvas)（WebGL 2）绘制的柱状图组件。以声明式 Props 描述数据，
GPU 渲染柱体、网格与轴文本；图例、悬浮提示与数据表为 HTML 层，接入设计令牌。


## 何时使用

- 比较一组类目下的数值大小（单系列），或多个系列在相同类目上的对比（分组）。
- 展示各类目的构成结构（堆叠，正值向上、负值向下分别累计）。
- 数据量大或与其他 rc-canvas 图形同屏、追求 GPU 渲染性能时。


## 功能特性

- **分组与堆叠**：`stacked` 一键切换；分组模式支持负值向下生长。
- **分类色板**：内置 8 色、经色觉障碍模拟验证的分类色板，按序分配、颜色跟随系列；
  也可通过 `series[].color` 逐系列覆盖。超过 8 个系列不渲染并在开发期告警。
- **悬停即反馈**：整个类目列都是命中区，悬停出现背景水洗与悬浮提示，
  提示中列出该类目下全部系列的数值。
- **无障碍**：绘制层对辅助技术隐藏，完整数据以视觉隐藏的 `<table>` 等价提供
  （`aria-label` 作为表格 caption）；悬浮提示只增强、不守门。
- **设计克制**：柱厚上限 24px、数据端 4px 圆角、相邻柱与堆叠段 2px 表面留白、
  hairline 网格——数据是画面上唯一的主角。
