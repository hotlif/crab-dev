# BarChart

基于 [rc-canvas](/rc-canvas)（WebGL 2）绘制的柱状图组件。以声明式 Props 描述数据，
GPU 渲染柱体、网格与轴文本（几何全部对齐整数像素；轴文本采用 ECharts 同款
按设备像素比光栅化的 bitmap 文本，1:1 物理像素对齐，小字号与 DOM 文本同等清晰）；
图例、悬浮提示与数据表为 HTML 层，接入设计令牌。


## 何时使用

- 比较一组类目下的数值大小（单系列），或多个系列在相同类目上的对比（分组）。
- 展示各类目的构成结构（堆叠，正值向上、负值向下分别累计）。
- 数据量大或与其他 rc-canvas 图形同屏、追求 GPU 渲染性能时。


## 功能特性

- **入场与更新动画**：首次挂载时柱体从零值基线逐类目生长，数据变化时高度从旧值平滑
  补间到新值——WebGL 逐帧插值，数百根柱同时过渡仍流畅。`animate` 可关；系统偏好
  「减弱动态」(`prefers-reduced-motion: reduce`) 时自动降级为直接呈现。
- **分组与堆叠**：`stacked` 一键切换；分组模式支持负值向下生长。
- **分类色板**：内置 8 色、经色觉障碍模拟验证的分类色板，按序分配、颜色跟随系列；
  也可通过 `series[].color` 逐系列覆盖。超过 8 个系列不渲染并在开发期告警。
- **悬停即反馈**：整个类目列都是命中区，悬停出现背景水洗与悬浮提示，
  其余类目的柱同步淡化形成「聚焦-背景」层次；提示中列出该类目下全部
  显示中系列的数值。
- **图例即过滤器**：多系列时点击图例项切换该系列显隐，剩余柱体平滑重排；
  隐藏中的图例项置灰保留（可随时恢复），数据表始终保持全量。
- **键盘与触屏可达**：Tab 进入图表后 ←/→（Home/End）在柱间移动，聚焦显示
  焦点环并固定该类目的悬浮提示，Enter/Space 触发 `onBarClick`；
  触屏点按柱或类目列固定提示、点击空白清除。
- **无障碍**：绘制层对辅助技术隐藏，完整数据以视觉隐藏的 `<table>` 等价提供
  （`aria-label` 作为表格 caption）；悬浮提示只增强、不守门。
- **CJK 友好的轴留白**：y 轴刻度标签经 canvas 真实测量定宽，
  `formatValue` 返回中文（如 `1.2万`）也不会溢出裁剪。
- **设计克制**：柱厚上限 24px、数据端 4px 圆角、相邻柱与堆叠段 2px 表面留白、
  hairline 网格——数据是画面上唯一的主角。
