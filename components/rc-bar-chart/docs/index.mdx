# BarChart 柱状图

基于 [Canvas](/components/rc-canvas) 的 WebGL 2 柱状图。使用 Props 配置数据、坐标轴和展示方式；图例、悬浮提示与无障碍数据表由 HTML 元素呈现。

[打开组件工作台](/components/rc-bar-chart/workbench/)

## 何时使用

- 比较一组类目下的数值大小（单系列），或多个系列在相同类目上的对比（分组）。
- 展示各类目的构成结构（堆叠，正值向上、负值向下分别累计）。
- 数据量大或与其他 rc-canvas 图形同屏、追求 GPU 渲染性能时。

## 主要功能

- **展示方式**：支持单系列、分组、正负值堆叠，以及 `orientation="horizontal"` 横向条形。
- **尺寸与动画**：`width="auto"` 跟随父容器宽度；`animate` 控制入场和更新动画，减少动态效果偏好下直接显示结果。
- **数值与参考线**：`showValues` 显示数值标签，空间不足时省略；`referenceLines` 配置目标值等参考线，并计入值轴范围。
- **系列颜色**：内置 8 色分类色板，也可通过 `series[].color` 覆盖；超过 8 个系列时不渲染，并在开发环境提示。
- **图例筛选**：点击图例切换系列显隐，数据表仍保留全部数据。
- **交互提示**：悬停、键盘聚焦或触屏点按可查看类目数据；Enter 或 Space 触发 `onBarClick`。
- **焦点可见性**：柱体覆盖按钮和图例按钮使用 2px 不透明语义焦点轮廓。柱体轮廓外再用 2px 画布表面色隔离相邻系列，图例保留柔和阴影；系统强制颜色模式使用 `Highlight` 实线轮廓。隐藏图例聚焦时恢复不透明，划线和 `aria-pressed="false"` 继续表达系列隐藏；轮廓不参与布局，不改变图表几何。
- **无障碍数据**：绘制层对辅助技术隐藏，完整数据通过视觉隐藏的表格提供，`aria-label` 用作表格标题。
- **轴标签**：按实际文本宽度计算留白，空间不足时省略长类目并按密度抽样标签；完整类目可通过悬浮提示、键盘聚焦与数据表获取。支持通过 `formatValue` 格式化数值。

## 容器与尺度

**现有实现：** `width="auto"` 使用现有 AutoSizer 跟随父容器，工作台示例采用这一方式；公共默认宽度仍为 600px。父容器需要明确可用宽度，并允许子项收缩。

**选择规则：** 对比数据通常优先随容器适配；类别较多时应同时评估标签密度、横向条形和数据表入口，不能把缩小后的图形作为全文获取方式。显式数值宽度用于有固定绘图区的场景，应由业务提供局部查看区域。

## 设计风格与主题

BarChart 是基于 Canvas 的数据可视化扩展。Material Design 3 Expressive、Apple 和 shadcn/ui 分别提供其语义契约；来源与固定 New York V4 基线见[三套设计体系](/guides/design-styles)。柱图布局、分组、堆叠和数据交互由本库定义，不以列表或分隔线规格概括图表行为。

柱形系列、网格线、基线、轴文字和画布背景通过 L3 色板消费 L2 角色；HTML 图例和数据提示使用同一配置边界的字阶、表面、前景和焦点。八个 `data.chart.series.*` 是 Crab 的数据可视化契约，包含本库扩展的系列角色，不能称作上游统一的八色规范。`series[].color` 和 `palette` 的显式业务覆盖保持优先。

系列颜色切换不改变数据值、坐标轴范围或分组含义。图例名称、键盘数据提示和 HTML 数据表提供颜色之外的信息入口；调用方自定义颜色后仍需检查系列区分与前景配对。绘图区宽高、类目密度和数值格式属于图表配置，不能用控件 `size` 等比缩放代替容器适配。

悬停或聚焦类目时，其他类目的柱体向 `palette.canvasBackground` 混色以降低强调。对于不透明系列色与背景，CSS 变量色和字面量色都采用 sRGB 通道混合，避免弱化后改变系列的颜色辨识；绘制结果保持不透明，圆角柱与底部补齐区域重叠时不会形成深色条带。背景随主题变化时重新解析颜色，`keep=1` 的原色保持不变。

三体系、浅深色、系列显隐、提示、焦点及减少动画等适用状态分别验收，覆盖等级以[覆盖矩阵](/guides/design-coverage)及对应候选记录为准。

包内 `test:forced-colors` 分别渲染柱体焦点与图例焦点，覆盖三体系和浅深色。检查使用发布 ESM/CSS、浏览器原生强制颜色以及实际 PNG 四边轮廓像素；通过 DOM `focus()` 到达目标并读取 `activeElement` / `:focus-visible`，不将它称为真实键盘输入或整张 Canvas 动画稳定性验收。原始截图与执行结果保存在包内 `.cache/forced-colors/`，人工视觉核对仍单独记录。

包内 `test:focus` 另核普通颜色的柱体、可见图例与隐藏图例焦点，分别覆盖三体系浅深色。发布 CSS 的实际 PNG 四边须有连续实线，轮廓与外侧紧邻 2px 色带的像素对比至少 3:1；柱体还须实际绘出表面色隔离边。距离轮廓 6px 的原场景颜色另存诊断，可能属于下一系列，不能混称紧邻背景。聚焦前后的目标、柱层及画布边界保持一致。检查保留正常动态，不取消或快进动画；它验证焦点轮廓，不替代整张图表的进入动画终态验收。原图与记录存于 `.cache/focus-colors/`。
