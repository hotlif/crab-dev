# Drawer 抽屉

从屏幕边缘滑出面板，展示详情或处理辅助任务。

[打开组件工作台](/components/rc-drawer/workbench/)

## 何时使用

- 在保留当前页面上下文的同时查看详情或填写表单。
- 临时展示筛选条件、辅助信息或其他侧栏任务。
- 需要从页面边缘展开较大内容区域，关闭后继续原任务。

## 三套设计风格

Material 以 sheet 作为参考，仅未贴边的角采用 28px 圆角；macOS 使用 12px 浮层角和细描边；shadcn sheet 使用直角与单侧边界。上下左右四个位置均随主题切换，RTL 使用逻辑方向。侧边、顶部布局是基于 sheet 的项目扩展。

切换文档站设计风格后，本页演示同步使用该设计；浅色和深色模式分别使用配对语义颜色。
