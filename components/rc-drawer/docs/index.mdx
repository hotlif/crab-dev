# Drawer

从屏幕边缘滑出的浮层面板，承载二级任务、表单或详情内容。

[打开 Drawer 抽屉 工作台](/components/rc-drawer/workbench/)

## 何时使用

- 需要进行较长的表单输入、查看详情，且不希望跳转页面打断主流程时
- 在当前页面之上临时呈现辅助信息，结束后可快速返回主界面
- 作为 Dialog 的侧栏版本：承载更多内容，尤其适合宽窄比不对称的场景
