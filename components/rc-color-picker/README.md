# @crab-dev/rc-color-picker

选择和编辑颜色，支持格式切换、预设色板与透明度调整。

## 主要功能

- 通过滑块调整亮度、色度、色相和透明度。
- 支持 HEX、RGB、HSL 与 OKLCh 显示格式，输出统一为 OKLCh。
- 支持扁平或分组预设色板；浏览器支持 EyeDropper 时可使用吸管取色。
- 支持受控与非受控模式，以及禁用、尺寸和清除配置。
- 触发器支持 Enter 和 Space 打开面板，滑块提供无障碍标签。
