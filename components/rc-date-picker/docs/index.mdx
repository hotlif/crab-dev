# DatePicker 日期选择器

基于 Temporal 的日期选择器，支持日期范围限制、时区和本地化显示。

[打开组件工作台](/components/rc-date-picker/workbench/)

## 三套主题的字段与日历

日期字段复用 LineEdit；Apple 与 shadcn 使用静态标签和桌面焦点环，MD3 Expressive 保留浮动标签与轮廓／底线。日期单元格和面板圆角由 L2 决定：MD3 Expressive 保留圆形日期及大圆角表面，Apple 和 shadcn 使用桌面圆角矩形日期和紧凑面板。今天、选中日期、键盘焦点与不可选日期仍分别表达。

当前日历的桌面日期单元格为 32px，粗指针扩展到 48px；这是桌面密度扩展。日期字段仍是只读的弹层触发器，尚未实现 M3 docked picker 的直接键入日期入口，不将当前组件标为该变体的完整复刻。

日期演示的尺寸切换使用库内 Button，说明文字随主题更新。Material Web 尚无对应日历组件；此处保留现有 M3 日历基线，桌面外观参照 [shadcn Date Picker 组合](https://ui.shadcn.com/docs/components/date-picker)及 [Calendar 源码](https://github.com/shadcn-ui/ui/blob/3d98900e9b73c45f035f8109e9d41ba6a51685e7/apps/v4/registry/new-york-v4/ui/calendar.tsx)。Apple 圆角为本项目适配值，时间表盘继续作为跨主题的扩展能力。核对日期：2026-10-22。

## 主要功能

- 日历面板支持切换月份和年份。
- 通过 `range` 限制可选日期。
- 通过 `timeZone`、`locale` 和 `weekStartDay` 配置时区、本地化显示和每周起始日。
- 使用 `renderDisplayString` 自定义输入框中的日期文本。

`DatePicker`、`DateTimePicker` 和 `TimePicker` 统一使用 `value` / `defaultValue` / `onValueChange(next, details)`。`value` 非 `undefined` 时为受控模式；`null` 表示显式空值。`defaultValue` 只在首次挂载读取，与 `value` 互斥。受控用法只发出更新请求，展示由外部 `value` 决定。

日期值使用 `Temporal.ZonedDateTime | null`。`details.reason` 为 `confirm` 或 `clear`；面板内选择只修改草稿，确认后才提交。原生字段事件保持原生签名。弹层支持互斥的 `open` / `defaultOpen` 和 `onOpenChange(next, details)`。

`DatePicker` 和 `DateTimePicker` 仍在字段获得焦点时打开；触发器、尾部按钮、面板及其嵌套 Portal 内的焦点切换保持展开。焦点移出整个分支时关闭并放弃未确认的草稿，`onOpenChange` 的 `details.reason` 为 `focus-out`，`event` 为原始焦点事件；Tab 或点击移向新控件时不恢复旧字段焦点。受控模式只请求关闭，实际展开状态仍由 `open` 决定。

内置文字和无障碍名称继承最近的 `ConfigProvider.locale`；选择器的局部 `locale` 同时覆盖日历格式、星期标题、动作和可访问名称。内置字典支持中文和英文，其他语言标识使用英文文案并保留对应的 `Intl` 日期格式。`renderDisplayString` 用于自定义字段格式。

三种选择器都根据真实值是否为 `null` 判断能否清除，`renderDisplayString` 只控制展示文字：空值返回非空字符串不会创建可清除的值；已有值即使格式化为空字符串，仍可清除。空值提示应使用 `placeholder`，让格式化函数对空值返回 `''`；把提示文字当作格式化结果会成为输入框的实际显示值，不具有占位文字的样式和语义。

未提供 `placeholder` 时，`DateTimePicker` 显示当前语言的“选择日期和时间”提示；调用方提供的占位文案始终优先。切换语言会更新默认提示并保留输入节点。

`DatePicker` 和 `DateTimePicker` 的尾部图标共用一个位置。有值且未禁用时，鼠标移入字段会将日历图标切换为清除图标；移到图标上仍可清除，离开字段后恢复日历图标。也可以用 Tab 聚焦尾部按钮，再按 Enter / Space 清除。清除会触发一次 `onValueChange(null, { reason: 'clear', event })`，其中 `event` 是尾部按钮的实际点击事件，不会伪造输入框的原生 `input` / `change` 事件；同时关闭面板并将焦点返回输入框。受控用法需要同步更新 `value`。要修改已有日期，请点击输入区域打开日历。

`TimePicker` 采用相同交互，在时钟与清除图标之间切换。无悬停能力的触屏设备在字段有值时直接显示清除按钮，点击输入区域仍可打开选择面板。

顶层原生属性、事件及 ref 属于输入框。`panelProps` 只传给弹层中的面板，用于设置面板 id、className 和无障碍属性；选择草稿 selectValues、面板 onSelect 回调和 instance 由选择器内部管理。

三种选择器的弹层定位避让当前字段自己的标签、辅助说明和错误提示；向上翻转时也保留标签的可见空间，包括 MD3 浮动标签伸出字段布局框的部分。定位依据文字的实际可见范围；说明换行、标签变换或动态更新后重新计算位置，不把相邻字段或整行 Form 纳入锚点。输入框原有的宽度、悬停边界、ref 和焦点行为保持独立。

短视口或页面放大后，如果上下和侧方都放不下完整日历，面板利用较宽裕的上下空间并通过内部滚动保留导航和底部操作。

## 时间选择

`TimePicker` 从输入框下方展开时间面板，空间不足时自动调整位置。面板没有遮罩，页面其他内容仍可操作。默认显示 24 小时制表盘，选择小时后自动进入分钟；底部键盘／时钟按钮可切换输入和表盘模式。

点击字段，或聚焦后按 Enter / Space / ↓ 打开；仅 Tab 聚焦不会展开。确定后才触发 `onValueChange`。取消或 Escape 放弃草稿并返回字段；点击外部或用 Tab 移出面板也会放弃草稿，焦点继续移向目标控件。

`value` 为 `{ hour, minute, second } | null`，其中 `hour` 始终为 0–23。默认展示 `HH:mm`；隐藏的 `second` 保留传入值，空值初次确认时为 0。非法或空的时间段会标记错误并阻止确认。受控用法需要把回调值更新到 `value`。

| `panelProps` 属性 | 默认值 | 用途 |
| --- | --- | --- |
| `hourCycle` | `24` | 设为 `12` 显示 AM／PM；值仍使用 24 小时制 |
| `defaultMode` | `dial` | 初始打开表盘；设为 `input` 优先使用键盘输入 |
| `showSeconds` | `false` | 显式启用秒输入扩展，同时仅使用输入模式 |

表盘数字支持 Tab 聚焦、Enter / Space 选择；方向键移动到相邻时间刻度并同步焦点（小时步长 1、分钟步长 5）。需要任意分钟时可拖动表针或切换键盘输入，输入框的 ↑ / ↓ 每次调整 1。输入法候选确认不会提交时间。

24 小时表盘会在未选中数字的字区扣除指针线，避免指针穿过内圈文字。遮罩只作用于线，不覆盖文字、点击区域或选中圆，邻近刻度的选中反馈仍保持完整。

`size="small / medium / large"` 调整外部字段尺寸。下拉面板使用时间选择器专用的数字区和点击区域，不跟随字段缩小。窄于 360px 或低于 560px 的视口使用输入模式，保留可编辑的数字区。窗口恢复后保留当前输入，可手动切回表盘；关闭后再次打开则按 `defaultMode` 初始化。

需要秒精度时传入 `panelProps={{ showSeconds: true }}`。`DateTimePicker` 是日期与时间的组合扩展，默认保留秒输入；可通过 `panelProps.timePanelProps.showSeconds` 关闭。

## 三体系验收规格

2026-10-29 参考 [M3 Date pickers](https://m3.material.io/components/date-pickers/guidelines)、[Time pickers](https://m3.material.io/components/time-pickers/guidelines)及 [Material Web Text field](https://material-web.dev/components/text-field/)的字段结构。日期/时间面板沿用对应 M3 基线；不能因为页面采用 Expressive 就套用 Button 的形状阶梯。32px 桌面日期单元、三档字段尺寸、秒输入、日期时间组合及非模态锚定面板是本项目扩展，粗指针日期单元保留独立 48px 命中几何。

Apple 依据 [Pickers](https://developer.apple.com/design/human-interface-guidelines/pickers)的就近编辑、逻辑顺序与上下文选择原则自主实现 Web 规则；shadcn 对照产品清单锁定的 [New York V4 Calendar](https://github.com/shadcn-ui/ui/blob/3d98900e9b73c45f035f8109e9d41ba6a51685e7/apps/v4/registry/new-york-v4/ui/calendar.tsx)与 [Popover](https://github.com/shadcn-ui/ui/blob/3d98900e9b73c45f035f8109e9d41ba6a51685e7/apps/v4/registry/new-york-v4/ui/popover.tsx)，没有引入其日期库或替换 Temporal 协议。

| 设计 | 字段与面板 |
| --- | --- |
| MD3 Expressive | 浮动字段标签、色调面板、圆形日期选中边界；今天描边与已选填充分别表达。时间输入与表盘保留 M3 对应基线。 |
| Apple | 静态字段标签、轻量 overlay 表面与较小日期单元圆角；内容与精确对齐优先，选中仍有清晰前景/背景配对。 |
| shadcn | 中性描边、紧凑日历、control 形状与聚焦轮廓；范围之外日期禁用，今天和选中分别可辨。 |

几何由 L3 `cell / panel / time` 引用 L2 `picker / field / sizing`；三档字段尺寸与三档密度独立。面板定位覆盖完整字段标签和说明，Portal 继承最近边界。矩阵以固定业务日期和范围验证默认、hover、键盘焦点、禁用、错误、警告、清除、日期草稿选择、日期时间、表盘、秒输入及时间输入错误。确认前字段仍显示已提交值，非法时间阻止确认；清除按实际值判断，不依赖显示字符串。

`docs/visual.json` 与 `date-picker.visual.spec.mjs` 是包内核心场景来源。只在测试中用 `page.clock.setFixedTime` 固定“今天”，保留产品计时器与动画运行。弹层状态截取整页以保留 Portal 和外部焦点，环境扩展检查窄屏、触控、RTL、语言、品牌、强制颜色、减少动画及配置切换保持草稿。候选、基准比较与人工复审分别记录，未完成范围不标记为 verified。

时间矩阵分别展开 12/24 小时的小时与分钟表盘、无秒输入和秒输入；通过真实键盘调整时分、切换 AM/PM 与输入模式，并检查小时、分钟、秒和空草稿的错误关联及确认禁用。日期时间组合另覆盖 12 小时和非法分钟。字段的真实 Tab 焦点会打开日期面板，截图边界按实际可见 Portal 选择，不能只截取触发器。

时间几何通过 L2 `picker.time` 单一来源映射到 L3：MD3 保留 96×72 输入及 display 字阶，表盘字段为 96×80（24h 为 114px 宽）；Apple / shadcn 的自主桌面扩展使用 64×48 输入及 title.large，72×56 表盘字段及 headline.small（24h 为 88px 宽），AM/PM 横向组为 152×32。表盘自身保留 256 坐标和原来的可访问交互。上述紧凑值是项目决策，不标为 Apple 或 shadcn 官方规格；尺寸与密度不会生成第二套表盘测量。

## Temporal 运行时与“现在”

组件通过包内唯一入口选择原生 Temporal，缺少原生支持时使用已有生产依赖 `@js-temporal/polyfill`，不安装或覆盖 `globalThis.Temporal`。独立使用方通过公开 `toPickerDateTime` 从 ISO 字符串构造值，浏览器没有全局 Temporal 也能打开和编辑选择器。公共值与 Props 类型保持原有协议。

```tsx
import DatePicker, { toPickerDateTime } from '@crab-dev/rc-date-picker';

const date = toPickerDateTime('2026-06-15T09:30:00.123456789+08:00[Asia/Shanghai]');
// date retains its time zone, calendar and nanoseconds.
<DatePicker value={date} />;
```

`toPickerDateTime` 接受 ISO 字符串或 `{ toString(): string }` 序列化协议，序列化结果必须是有效的 Temporal 日期时间 ISO 字符串；非法输入会抛出异常。既有原生日期值与回调不必改写。公开声明不引入 polyfill 的完整 Intl 类型，因此普通消费方不必直接导入其类型扩展。比较与适配使用标准 ISO 字符串，避免跨实现对象品牌检查。TypeScript 6 原生声明与现有 ambient 声明的注解差异在唯一运行时边界说明，未扩散强制断言或输出联合类型；本轮保留既有 `setState` 回调兼容。

已有官方 polyfill 值可选择在进入选择器前适配一次，例如 `toPickerDateTime(Temporal.ZonedDateTime.from(iso))`；该互操作由包内专项回归验证。`@js-temporal/polyfill@0.5.1` 自身的 Intl 声明与 TypeScript 6 的 `lib.esnext` 在 `skipLibCheck: false` 时存在冲突，直接导入它的类型会触发上游诊断。本库不会替用户关闭检查；严格消费推荐上面的 ISO 字符串入口，polyfill 仍作为包内运行时依赖提供缺失平台能力。

当前时刻入口统一读取 `Date.now()` 并转换到实际业务时区，精度为毫秒，服务于日期、时分秒默认值和今天标记；不会改写调用方传入的 ZonedDateTime，也不会截断已有微秒/纳秒。在时区跨日及夏令时下，下一次午夜仍按目标时区计算。视觉测试只固定这个实际 Date 时钟；有限过渡、午夜计时器和表盘交互继续正常运行，避免伪造 Temporal.Now。

### TimePicker

| 属性 | 类型 | 说明 |
| --- | --- | --- |
| `value` | `{ hour: number; minute: number; second: number } \| null` | 当前时间；小时 0–23，分钟和秒 0–59 |
| `defaultValue` | `TimePickerValue \| null` | 非受控初始时间；与 `value` 互斥 |
| `onValueChange` | `(value: TimePickerValue \| null, details: PickerValueChangeDetails) => void` | 确认或清除时触发，原因分别为 `confirm` / `clear` |
| `open` / `defaultOpen` | `boolean` | 受控／非受控弹层状态，两者互斥 |
| `onOpenChange` | `(open, details) => void` | 弹层状态变更请求 |
| `panelProps` | `TimePickerPanelProps` 的配置子集 | 时间格式、初始模式与面板属性；草稿、操作区和有效性由选择器管理 |
| `renderDisplayString` | `(value) => string` | 自定义外部字段展示文本 |
| 字段属性 | `PickerFieldProps` | `label`、`appearance`、`size`、`disabled`、原生输入事件与 `ref` |
