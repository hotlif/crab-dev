# DatePicker 日期选择框

一个基于 Temporal API 的现代 React 日期选择器组件，支持高度自定义与国际化。

## 特性

- 📅 日历视图，支持月/年切换
- ⏳ 日期范围限制
- 🌏 时区支持
- 🗓️ 一周起始日可配置
- 🏷️ 国际化（locale 自动适配）
- 🎨 设计 Token，轻松主题定制
- 🖱️ 鼠标与键盘导航（规划中）
- 🚫 禁用日期与导航按钮
