# ComponentPreview 组件预览

在文档中展示组件预览、示例源码和说明。

[打开组件工作台](/components/rc-component-preview/workbench/)

## 何时使用

- 在组件文档中并排展示实时预览与源码。
- 为示例补充标题、说明和可复制代码。
- 需要按需加载语法高亮，避免阻塞页面首屏时。

操作栏复用 Crab Button。接入时引入 `@crab-dev/rc-component-preview/css/index.css` 和 `@crab-dev/rc-button/css/index.css`。源码保持整行并在组件内滚动，复制内容保留原始字符串，行号不属于复制内容。

`codeTheme` 控制源码的独立浅色或深色配色，语法颜色、背景、行号及高亮加载提示成对切换，不受示例舞台或页面主题影响。

## 设计风格与主题

预览容器继承 card 形状与阴影，操作栏继承工作区 toolbar 表面；演示区保持内容表面，避免外框与示例控件混为同一层级。代码配色仍由 codeTheme 独立选择，浅深代码背景不强行映射为控件背景。
这是本库的开发支持组件。MD3、Apple、shadcn/ui 分别复用各自的容器、工具栏和操作控件角色；源码展示、复制与懒加载是本库能力，不对应三套体系的同名标准组件。容器状态与代码高亮分别验收，加载期间也保留可读的文字与焦点反馈。

设计来源与固定参考版本见[三套设计体系](/guides/design-styles)，当前已核对范围见[设计覆盖矩阵](/guides/design-coverage)。这段说明记录适配边界，不代表完整视觉验收已通过。

### 预览矩阵

预览的 `compact / regular / spacious` 控制舞台留白，独立于全局数据密度。矩阵 Demo 将全局三档密度显式映射到这三个公开值，工具栏仍使用 Button 的独立小尺寸。核对折叠、真实动态源码加载、明暗源码、复制成功/失败、键盘焦点和外部打开回调；复制失败由调用方的 `onCopyCode` 就近说明，预览不假报成功。

源码加载场景仅延迟实际网络响应，保持真实 Suspense 界面；草稿输入在展开、配色及配置变化中保留。窄屏代码在自己的滚动区域内查看，外层标题、说明与工具栏可换行，焦点和复制反馈分别断言。

展开和深色源码场景等待加载提示消失及真实语法分段出现后截图。加载场景独立保存原生视频、自然帧与时间序列，不建立静态像素基准；当前加载提示是文字，不据此宣称旋转指示器动效通过。触控场景实际轻触展开、复制、外部打开和收起；窄屏检查代码独立滚动及工具栏命中，触摸拖动代码的手势仍需另验。
