# ComponentPreview 组件预览

用于在文档中展示组件效果、示例源码和补充说明。

[打开 ComponentPreview 组件预览 工作台](/components/rc-component-preview/workbench/)

## 何时使用

- 在组件文档中并排展示实时预览与源码。
- 为示例补充标题、说明和可复制代码。
- 需要按需加载语法高亮，避免阻塞页面首屏时。
