# Radio

单选框, 用于在一组选项中选择一个值。

[打开 Radio 单选框 工作台](/components/rc-radio/workbench/)

## 何时使用

- 用于在一组互斥的选项中选择一个选项
- 和 Select 的区别是, Radio 所有选项默认可见, 方便用户在比较中选择, 因此选项不宜过多
