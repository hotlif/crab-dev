# CronPicker 定时规则

支持五段式 Cron 表达式的可视化编辑、手动输入和执行时间预览。

[打开组件工作台](/components/rc-cron-picker/workbench/)

## 何时使用

- 为定时任务、报表或调度策略配置执行周期。
- 通过面板编辑表达式，并查看中文说明与后续执行时间。
- 直接输入表达式；支持月份和星期英文缩写、以 `7` 表示周日，以及 `1,2-5` 等组合写法，提交时规范化输出。

表达式采用五段式，依次表示分、时、日、月、周。`parseCron`、`formatCron`、`describeCron` 和 `nextOccurrences` 均为具名导出的纯函数，可用于独立校验与预览。
