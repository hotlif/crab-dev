# Checkbox 复选框

从一组选项中选择多个值，或标记单个选项的选中状态。

[打开组件工作台](/components/rc-checkbox/workbench/)

## 何时使用

- 从多个独立选项中选择一项或多项，例如筛选条件、权限或批量操作对象。
- 标记是否同意条款等布尔值。
- 选项需要随表单一起提交时使用 Checkbox；设置需要立即生效时通常使用 Switch。

## 无障碍

- 将可见选项文字作为 `children` 传入；没有可见文字时必须提供准确的 `aria-label`。
- 一组选项应放在带 `<legend>` 的 `<fieldset>` 中，让组名和每个选项的名称都可被感知。
- `indeterminate` 表示“部分选中”，业务仍需维护明确的 `checked` 状态，不能把它作为第三种提交值。
- 错误说明使用 `aria-describedby` 与控件关联，禁用原因应在附近以文字说明。

更多通用要求见[无障碍使用指南](/guides/accessibility)。

## 视觉状态与验证

### 三套设计风格

`ConfigProvider designSystem` 在 L2 语义令牌边界切换完整形态，组件与演示使用同一份样式。`apple` 默认 16px 方框、4px 圆角、1px 描边和轻阴影；`shadcn` 默认 16px 方框、4px 圆角、1px 描边，使用中性色与克制阴影。两者不使用 MD3 的圆形状态层，保留键盘焦点、悬停描边、选中与半选标记、错误和禁用状态。浅深色与嵌套主题均由语义变量同步。

Apple 为参考 Apple HIG 的 Web 定制，并非 AppKit 原生控件的像素复刻；small / medium / large 的方框分别为 14 / 16 / 18px。shadcn 的扩展尺寸为 14 / 16 / 20px。细指针采用紧凑 24px 控件容器，粗指针扩展为至少 48px。

以下尺寸与状态层说明专指 `md3`。

视觉以 [Material Design 3 Checkbox](https://m3.material.io/components/checkbox/overview) 为基准：默认方框 18×18px、圆角 2px、描边 2px；未选中为空心轮廓，选中与半选使用品牌填充，并分别显示勾选和横杠。

40×40px 的圆形状态层响应整个标签的悬停、聚焦与按压，透明度分别为 8% / 12% / 12%；控件区域为 48×48px。禁用透明度为 38%，禁用选中状态保留中性填充与反白标记。颜色引用 L2 语义令牌，自动响应暗黑模式和 ConfigProvider 的品牌色。

保留 Crab 的 `small / medium / large` 扩展：方框分别为 16 / 18 / 20px，状态层统一为 40px；颜色与图标过渡使用公共 `motion.interaction`。状态切换只改变颜色、透明度和图标缩放，固定外框、描边宽度与行内对齐，避免布局跳动。

原生输入负责名称、选中和键盘行为；半选通过 `aria-checked="mixed"` 表达。`aria-invalid="true"` 显示错误色，应同时通过 `aria-describedby` 关联说明。键盘焦点提供独立轮廓，强制颜色使用系统颜色，减少动态效果时移除过渡。图标为常驻的无障碍隐藏装饰，不增加 Tab 停靠点。

规则依据：[状态系统](/guides/accessibility)、[无障碍与键盘](/guides/accessibility)、[布局与密度](/guides/getting-started)。

## 状态契约

`checked / defaultChecked / onCheckedChange(next, details)` 管理单个复选框，`details.reason` 为 `toggle`；原生 `onChange(event)` 保留 DOM 事件签名。CheckboxGroup 使用 `value / defaultValue / onValueChange(next, details)`，原因是 `select / deselect`。

受控值与默认值互斥；默认值仅在初始化时使用。外部属性更新不触发操作回调，省略回调可展示只读受控快照。
