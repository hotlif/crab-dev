# Checkbox

复选框, 用于在一组选项中选择多个值。

[打开 Checkbox 复选框 工作台](/components/rc-checkbox/workbench/)

## 何时使用

- 在一组可选项中进行多项选择时
- 单独使用可以表示两种状态之间的切换, 和 Switch 类似
- 和 Switch 的区别是, 切换 Switch 会直接触发状态改变, 而 Checkbox 一般用于状态标记, 需要和提交操作配合
