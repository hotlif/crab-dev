# SplitPane 分栏面板

通过拖拽或键盘调整两侧面板尺寸，支持复位与尺寸记忆。

[打开组件工作台](/components/rc-split-pane/workbench/)

## 何时使用

- 调整编辑器侧栏、文件树或属性面板的宽度。
- 分配主内容区与控制台、日志区的高度。
- 通过 `persistKey` 记住调整结果，并提供键盘调整路径。

需要两块面板以外的自定义布局时，可直接使用 `@crab-dev/rc-hooks` 的 `useDragResize`。

## 设计风格与主题

分隔线、拖动和焦点使用语义角色。macOS 使用紧凑的细分隔轨道，MD3 保留细线与较宽命中区，shadcn 增加居中的可见握柄。粗指针仍使用公共触控目标；方向键、Home/End、Enter、禁用及减少动态效果行为保持一致。所有演示的边框、背景和文字现已跟随当前主题。
本范围以 M3 Lists / Divider 的表面、分隔、状态和无障碍规则作为扩展依据；数据表、图表、PDF 编辑器和可拖动分栏并非 Material Web 的同名标准组件。macOS 与 shadcn 是本项目在相同交互能力上的设计变体，未引入第三方 UI 运行时，也不宣称原生平台逐像素复刻。
