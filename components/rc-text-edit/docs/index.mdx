# TextEdit 多行文本输入框

输入多行文本，支持清除、字数统计和内容自适应高度。

[打开组件工作台](/components/rc-text-edit/workbench/)

## 何时使用

需要用户输入多行文本（备注、描述、评论等）时使用，支持多种尺寸、验证状态、
一键清除、字符计数与内容自适应高度。单行输入请使用 `@crab-dev/rc-line-edit`。

## 代码演示

### 选型与结构

文本域用于备注、描述、评论等允许换行的内容。标签明确对象，帮助说明用途和长度限制，计数放在内容之后；清除只作用于本字段。单行名称使用 LineEdit，带格式的编辑器不能仅靠 TextEdit 的纯文本 API 模拟。

| 场景 | 配置 | 边界 |
| --- | --- | --- |
| 稳定的短备注区 | rows | 用户可按默认 vertical 方式增高；周围内容不能被覆盖 |
| 随内容增长 | autoSize | 支持 CSS field-sizing 的浏览器生效，否则以 rows 回退；不同时手动 resize |
| 只可查看和复制 | readOnly | 保留焦点、选择和对比度，隐藏清除 |
| 暂时不可编辑 | disabled | 禁用文本域并隐藏清除；相邻文字说明原因 |
| 清除 | allowClear + onChange | 支持受控和非受控；触发标准值变更并将焦点送回文本域，onClear 仅用于额外通知 |

### 设计风格与状态

字段跟随统一的 `ConfigProvider design="material" | "shadcn"`，文档右上角的风格选择也会同步到演示。Material 的标签位于字段内，聚焦或有内容时浮动；shadcn 的同一个标签位于输入框上方。切换风格保留输入内容、焦点与辅助说明关联，无需替换组件。

提供 `label` 的 Material 文本域使用 16px / 24px 正文、12px / 16px 浮动标签，至少 56px 高；outlined 保留上下 16px 空间，filled 为标签保留上方空间。shadcn 使用上置的 14px 标签与紧凑边框。没有内置标签的嵌入用法保留 `size` 的内边距规则；`bordered={false}` 交由宿主提供边界和排版。可视高度仍由 `rows` / `autoSize` 决定，不应对包含错误信息的整组字段设置固定高度。

清除动作复用 Button，鼠标下 24×24px、粗指针下 48×48px；文本区常驻预留对应横向空间，按钮出现或消失不改变可用行宽。粗指针下文本域最小高度为 48px。计数与按钮不应遮住末行或滚动条，超长文本保留原生滚动与选择。

`appearance="outlined"` 与 `appearance="filled"` 对应 Material 的两种文本字段；shadcn 下两者均采用完整的紧凑边框。`label`、`supportingText`、`errorText` 会自动建立可见标签和 `aria-describedby` 关联。`errorText` 替换辅助说明并启用错误语义及错误播报；显式 `aria-invalid` 仍优先，warning 不自动无效。计数位于字段下方的信息区，不占用正文空间，也不会在每个字符变化时强制重复播报。

Material 聚焦时，outlined 的 1px 轮廓加粗为 3px，filled 将底线加粗为 3px；outlined 使用真实轮廓缺口，标签不会用一块固定背景盖住边框。shadcn 使用其语义主题提供的边框与焦点指示；错误与 warning 沿用各自的反馈色。禁用时移除错误强调。无边框模式和系统强制颜色模式保留独立的键盘焦点轮廓。

实现依据：2026-10-21 查阅 [M3 文本字段规格](https://m3.material.io/components/text-fields/specs)、[使用指南](https://m3.material.io/components/text-fields/guidelines)、[无障碍说明](https://m3.material.io/components/text-fields/accessibility)，并对照 [Material Web 多行字段示例](https://material-web.dev/components/text-field/#textarea)、main 分支的 [outlined 样式](https://github.com/material-components/material-web/blob/main/field/internal/_outlined-field.scss)、[filled 样式](https://github.com/material-components/material-web/blob/main/field/internal/_filled-field.scss) 与 [焦点令牌](https://github.com/material-components/material-web/blob/main/tokens/_md-comp-filled-text-field.scss)。M3 官方页面依赖 JavaScript，当前可读的实现参数以 Material Web 源码为对照；采用当前实现的 3px 焦点厚度，warning 和垂直拖拽属于本库扩展。

### 正反例与验收

- 正例：备注允许 500 字，先解释用途与上限；服务端失败后保留原文并在附近说明重试方法。
- 反例：提交失败后清空文本。用户必须重新输入；应保留受控值，仅在确认成功后重置。
- 正例：清除后继续在同一文本域输入。反例：清除按钮卸载导致焦点落到页面；当前实现已恢复至输入区。
- `resize="both"` 只在宿主允许二维尺寸变化时使用，不能撑宽整页；普通表单优先保留 vertical。
- 验收：Tab 到达清除动作，Enter 后值清空且焦点在文本域；只读 / 禁用无清除入口；错误与焦点叠加可辨认；320px 和文字放大时计数、清除、长行均不覆盖正文；autoSize 不支持时仍能通过 rows 和原生滚动完成输入。
