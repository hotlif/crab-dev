# Avatar 头像

使用图片、文字或图标展示用户与实体标识。

[打开组件工作台](/components/rc-avatar/workbench/)

## 何时使用

- 在评论、消息列表、成员列表中展示用户身份。
- 图片加载失败时，用名称缩写或图标提供稳定回退。
- 与 Badge 组合展示在线状态或未读提醒。

## 主要功能

- 支持 `small` / `medium` / `large` 尺寸阶梯。
- 支持 `circle` / `square` 两种形态。
- 支持图片、文本、图标三种内容来源，自动回退。
- 支持语义颜色变体（`default` / `primary` / `success` / `warning` / `error`）。
- 支持 `prefers-reduced-motion`，减少不必要动画。
- 设置 `onClick` 时复用 Button，支持 Enter / Space 激活与可见键盘焦点。头像视觉尺寸不变，交互容器至少为 48px；仅图标头像应提供动作名称 `aria-label`。
- AvatarGroup 的 `onExtraClick` 使用独立的“+N”按钮，避免与成员头像的点击操作嵌套；纯展示时计数徽标与最后一个头像的上方逻辑外沿相切，LTR 向右、RTL 向左。计数的实际宽度参与头像组布局，长 `renderExtra` 不会侵入前一个头像或相邻组；头像外环保持自身形状。顶部半个徽标仍向上伸出，放入裁剪容器时需保留相应垂直空间。
- 默认“+N”计数在 RTL 中保持加号在前；徽标标题与操作名称跟随最近 ConfigProvider 的中英文设置。`renderExtra` 自定义内容保留其自身文字和方向。
- `max={0}` 隐藏所有成员头像，仍保留独立的计数徽标或 `renderExtra` 摘要；提供 `onExtraClick` 时保留额外操作按钮。没有成员时不显示折叠提示。
- 强制颜色模式下，文字和图标回退使用系统成对颜色，`primary` 使用 `Highlight` / `HighlightText`，其他变体使用 `Canvas` / `CanvasText`；局部禁用文字背板，避免首字母不可见。照片仍由浏览器按原生规则处理。

## 三套设计风格

圆形头像保持跨设计一致。方形头像分别采用 Material 12px、Apple 6px、shadcn 8px 圆角；颜色与回退文字由当前语义主题提供。可点击头像继续使用原生按钮、可访问名称及可见焦点。
