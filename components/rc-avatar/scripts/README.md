The `test:browser` check consumes published Avatar/Badge ESM and actual dependency/theme CSS. It checks full overflow summaries and retained DOM nodes across LTR/RTL.

`test:forced-colors` builds the same public CSS and runs the shared `scripts/test-published-forced-colors.mjs` launcher. A fresh isolated Chrome process uses native `forced-colors: active` and the six design/mode configurations. Both text foreground and indicator background must occur inside each actual glyph range in the original CDP screenshot, so an opaque text backplate cannot satisfy the test by matching the foreground color alone. Dot fills are measured separately. This covers Badge counts, presets, custom colors, nested text and wrapped counts, Avatar initials and AvatarGroup summaries in both directions.

Set `CRAB_TEST_BROWSER_PATH` (or `CHROME_PATH`) when Chrome/Chromium is not in a standard location. Missing browsers fail; Windows background processes use `windowsHide`. The launcher closes its own process and server in `finally`, saves screenshots, exact input/fixture hashes and checks under `.cache/forced-colors/`, and retains its temporary profile for diagnosis. It never connects to a user's browser. Pixel assertions do not replace manual visual review.
