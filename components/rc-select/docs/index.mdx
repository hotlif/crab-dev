# Select 选择器

在下拉列表中选择一个或多个值，支持搜索选项。

[打开组件工作台](/components/rc-select/workbench/)

## 何时使用

- 需要在有限空间中从多个选项中选择一个或多个值。
- 选项较多，需要通过关键字快速过滤。
- 表单场景中需要统一输入尺寸与交互体验。

## 主要功能

- 支持单选与多选模式。
- 支持可搜索过滤。
- 支持受控与非受控用法。
- 支持禁用状态与禁用选项。

## 无障碍

- 使用 `label` 提供可见的浮动字段标签；`supportingText` 与 `errorText` 会自动关联到选择器。没有可见标签的特殊场景仍必须提供 `aria-label`。
- 使用方向键移动选项、Enter 选择、Escape 关闭、Backspace 删除多选标签，确保业务包装层不会拦截这些按键。
- 清除后焦点回到选择器；可继续按方向键选择新值，不能因清除入口消失而把用户留在页面根部。
- `errorText` 会替换辅助说明并启用错误状态；不要只设置 `status="error"` 而省略可见的错误原因。
- 自定义 `optionRender` 或 `tagRender` 时保留可读文本，纯装饰图标应设置 `aria-hidden="true"`。

更多通用要求见[无障碍使用指南](/guides/accessibility)。
