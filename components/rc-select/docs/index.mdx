# Select 选择器

在下拉列表中选择一个或多个值，支持搜索选项。

[打开组件工作台](/components/rc-select/workbench/)

## 三套主题的标签与选项

Select 与 LineEdit 共用 L2 字段布局：MD3 使用 56px 字段、浮动标签、真实轮廓缺口或 Filled 底线；Apple 与 shadcn 使用静态上置标签及紧凑边框。静态标签不会在打开面板或已有值时移动，也不会遮住占位文字。输入、值、搜索草稿和展开状态在主题切换时保留。

Apple 选中项使用蓝色表面与配对前景色，shadcn 使用中性色背景，MD3 使用 tonal 选中表面。键盘活动项有独立轮廓，禁用项不可选；多选复用 Checkbox。错误文字通过描述关联和 alert 通告。请在“标签与选择状态”中检查空值、搜索、多选、错误和禁用，并切换浅色／深色。

弹层定位包含本字段的标签、说明和错误，动态换行后重新定位；空间不足时可翻转到字段上方。弹层宽度和 Escape 焦点恢复仍以实际 combobox 控件为准，不把说明文字当作交互焦点。

Escape 关闭时 `onOpenChange` 的原因是 `escape`，并保留原始键盘事件；不会把键盘关闭记为触发器点击。

实际参考（2026-10-22）：[Material Web Select](https://material-web.dev/components/select/)、[Select 行为源码](https://github.com/material-components/material-web/blob/main/select/internal/select.ts)、[Outlined Field 样式](https://github.com/material-components/material-web/blob/main/field/internal/_outlined-field.scss)、[shadcn Select 源码](https://github.com/shadcn-ui/ui/blob/main/apps/v4/registry/new-york-v4/ui/select.tsx)。多选、虚拟滚动、warning 和桌面密度为项目扩展；Apple 视觉通过本库语义角色实现。

## 尺寸与外观

`size` 支持 `small`、`medium`、`large`。省略时继承最近的 ConfigProvider；没有配置时使用 `medium`。统一设置和局部覆盖见[尺寸指南](/guides/component-sizing)。

`appearance="outlined"` 是默认的描边外观，`appearance="filled"` 使用填充背景和底线；两者共享值、搜索和键盘操作。“可清除”示例可对比三种尺寸、两种外观及浅深色主题。

## 选中值与清除

`options` 中的 `value` 必须是唯一字符串，`label` 用于显示。用 `multiple` 开启多选：

| 模式 | 受控 `value` | 清除后的 `onValueChange` 参数 |
| --- | --- | --- |
| 单选 | `string` 或 `null` | `null`，详情为 `reason: 'clear', options: []` |
| 多选 | `string[]` | `[]`，详情为 `reason: 'clear', options: []` |

传入 `value` 时，在 `onValueChange(next, details)` 中更新状态；省略回调可展示只读受控快照。单选空值使用 `null`。不传 `value`（或传入 `undefined`）时由组件维护选中值，`defaultValue` 只负责初始化，两种状态不可同时提供。

详情包含 `reason: 'select' | 'deselect' | 'clear' | 'remove'`、选中 `options`，单选另提供 `option`。`open/defaultOpen/onOpenChange` 独立控制展开，外部更新不会触发操作回调；原生 `onChange/onFocus/onBlur` 保留 DOM 事件签名。

受控关闭请求由父级确认；父级继续传入 `open={true}` 时，搜索草稿和键盘高亮保持不变。初始 `open` 或 `defaultOpen` 会直接高亮并滚动到单选的当前选项，不产生展开回调。即使列表已展开，`disabled` 也禁止选择、搜索和标签移除；自定义标签收到的移除回调同样遵守禁用状态。

字段尺寸继承 `size`，选项间距与虚拟列表行高继承 `density`。长选项允许内容测量扩展行高，多选标签可换行，保持视觉布局与滚动定位一致。

设置 `allowClear` 后，有已选项且组件未禁用时，鼠标移入字段会将尾部箭头切换为清除图标；移到图标上仍可清除，离开字段后恢复箭头。两种图标共用一个位置，切换不会挤动文字。Tab 聚焦尾部按钮时也会显示清除；无悬停能力的触屏设备直接显示清除。

点击清除会清空选中值、关闭列表，并把焦点移回选择器。要修改已有值，请点击字段的内容区域打开列表；空值或未启用 `allowClear` 时，也可点击尾部箭头。禁用时这些操作不可用。

## 搜索与加载

`searchable` 在展开的列表中提供本地过滤：文本 `label` 按内容匹配，非文本 `label` 则按 `value` 匹配，忽略大小写。

内置标签移除、展开、收起、清除和空结果文案随 ConfigProvider 的 `locale` 切换；切换语言保留选中值。

组件没有搜索词回调，不能直接把 `searchable` 当作远程搜索接口。异步加载选项时，由应用获取数据并更新 `options`，请求期间可设置 `loading`；`loading` 只显示加载状态，不会发起请求。

## 标签与校验

- 用 `label` 提供可见字段名称，用 `supportingText` 补充选择要求。不能展示标签时，提供 `aria-label` 或指向外部标签的 `aria-labelledby`。
- `errorText` 会启用错误状态并替换辅助说明。`status="warning"` 只改变视觉状态，警告原因应通过 `supportingText` 等可见文字说明。
- `required` 提供必填语义和标签星号，不会自动校验或提交表单。
- 自定义选项和标签时保留可读名称；纯装饰图标使用 `aria-hidden="true"`。

## 键盘操作

| 操作 | 效果 |
| --- | --- |
| Tab | 在选择器、尾部按钮及页面其他控件之间移动焦点；有可清除值时，尾部按钮切换为清除 |
| 上 / 下方向键 | 展开列表并移动高亮选项 |
| Enter | 展开列表，或选择当前高亮项；单选收起后焦点回到选择器 |
| Space | 选择器收起时展开列表；搜索输入中可正常输入空格 |
| Escape | 关闭列表，焦点回到选择器 |
| Backspace | 多选且搜索词为空时，删除最后一个已选标签 |
| 清除按钮上的 Enter / Space | 清空选中值，焦点回到选择器 |

更多要求见[无障碍使用指南](/guides/accessibility)。

## 三体系规格与验收矩阵（2026-10-29）

| 体系 | 字段与集合规格 | 桌面扩展 |
| --- | --- | --- |
| MD3 Expressive | outlined / filled 沿用字段标签、错误说明和色调表面；选中行、活动行与键盘焦点分别表达 | 搜索、多选标签、warning、虚拟集合和三档行密度是本库扩展 |
| Apple | 内容优先、静态标签、轻量面板，选中与活动状态清晰；不复制系统原生弹出菜单 | Web combobox、长中英文标签及公开三档尺寸 |
| shadcn New York V4 | 中性字段、描边、popover 层级、清晰焦点与选项高亮 | 保留本库字段标签、多选和虚拟化协议 |

字段几何来自 L2 `field.*` / `sizing.*`，集合高度和虚拟测量共用 `density.item`，L3 不按设计 ID 分支。公开 small / medium / large 控制字段，compact / standard / comfortable 独立控制选项行；命中区域按粗指针规则扩展，不能通过视觉高度推断触控目标。三体系均使用配对浅深色、required / error 的持久说明，并保留清除入口及尾部键盘焦点。

`visual.json` 是包内验收轴来源：三体系浅深色 × 三尺寸 × 三密度 × default、hover、focus-visible、expanded、selected、multiple、error、warning、disabled、empty、loading。通过实际键盘、打开与选项点击进入状态；loading 单独保留自然动画帧、视频与 trace，不用静止基准代替动态复审。其他稳定状态使用 Playwright 原生截图比较；Firefox / WebKit 子集以 `crossEngine` 为准。未支持的 pressed/readOnly 说明在 notApplicable 中。

来源：[Material Web Select](https://material-web.dev/components/select/) 与 [Menu](https://material-web.dev/components/menu/)；[Apple menus](https://developer.apple.com/design/human-interface-guidelines/menus)；[shadcn 固定 Select 源码](https://github.com/shadcn-ui/ui/blob/3d98900e9b73c45f035f8109e9d41ba6a51685e7/apps/v4/registry/new-york-v4/ui/select.tsx)。Material Web 是 Web 基线，搜索/密度扩展不宣称属于官方 Expressive 新组件。

验收另外检查 Portal 配置更新、切换保留搜索实例与草稿、320/768px、RTL、英文、品牌、强制颜色及减少动画。已有 Dropdown 登记浏览器检查只覆盖底层 iframe 焦点协议，不能替代 Select 自身跨文档外观；嵌套 Provider、iframe/Shadow DOM 中的真实选择和最近配置由 Drawer 包的公开组合边界 Demo 与所属原生场景补充。新增场景在实际运行、逐图复审前仍为待验。规格与自动场景不表示人工外观已通过；以对应源码指纹的实际报告和逐项复审为准。
