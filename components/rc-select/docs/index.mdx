# Select 选择器

在下拉列表中选择一个或多个值，支持搜索选项。

[打开组件工作台](/components/rc-select/workbench/)

## 尺寸与外观

`size` 支持 `small`、`middle`、`large`。省略时继承最近的 ConfigProvider；没有配置时使用 `middle`。统一设置和局部覆盖见[尺寸指南](/guides/component-sizing)。

`appearance="outlined"` 是默认的描边外观，`appearance="filled"` 使用填充背景和底线；两者共享值、搜索和键盘操作。“可清除”示例可对比三种尺寸、两种外观及浅深色主题。

## 选中值与清除

`options` 中的 `value` 必须是唯一字符串，`label` 用于显示。用 `multiple` 开启多选：

| 模式 | 受控 `value` | 清除后的 `onChange` 参数 |
| --- | --- | --- |
| 单选 | `string` 或 `null` | `(null, undefined)` |
| 多选 | `string[]` | `([], [])` |

传入 `value` 时，在 `onChange` 中更新状态；单选空值应使用 `null`。不传 `value`（或传入 `undefined`）时，由组件维护选中值，可用 `defaultValue` 设置初始值。

设置 `allowClear` 后，有已选项且组件未禁用时，鼠标移入字段会将尾部箭头切换为清除图标；移到图标上仍可清除，离开字段后恢复箭头。两种图标共用一个位置，切换不会挤动文字。Tab 聚焦尾部按钮时也会显示清除；无悬停能力的触屏设备直接显示清除。

点击清除会清空选中值、关闭列表，并把焦点移回选择器。要修改已有值，请点击字段的内容区域打开列表；空值或未启用 `allowClear` 时，也可点击尾部箭头。禁用时这些操作不可用。

## 搜索与加载

`searchable` 在展开的列表中提供本地过滤：文本 `label` 按内容匹配，非文本 `label` 则按 `value` 匹配，忽略大小写。

组件没有搜索词回调，不能直接把 `searchable` 当作远程搜索接口。异步加载选项时，由应用获取数据并更新 `options`，请求期间可设置 `loading`；`loading` 只显示加载状态，不会发起请求。

## 标签与校验

- 用 `label` 提供可见字段名称，用 `supportingText` 补充选择要求。不能展示标签时，提供 `aria-label` 或指向外部标签的 `aria-labelledby`。
- `errorText` 会启用错误状态并替换辅助说明。`status="warning"` 只改变视觉状态，警告原因应通过 `supportingText` 等可见文字说明。
- `required` 提供必填语义和标签星号，不会自动校验或提交表单。
- 自定义选项和标签时保留可读名称；纯装饰图标使用 `aria-hidden="true"`。

## 键盘操作

| 操作 | 效果 |
| --- | --- |
| Tab | 在选择器、尾部按钮及页面其他控件之间移动焦点；有可清除值时，尾部按钮切换为清除 |
| 上 / 下方向键 | 展开列表并移动高亮选项 |
| Enter | 展开列表，或选择当前高亮项 |
| Space | 选择器收起时展开列表；搜索输入中可正常输入空格 |
| Escape | 关闭列表 |
| Backspace | 多选且搜索词为空时，删除最后一个已选标签 |
| 清除按钮上的 Enter / Space | 清空选中值，焦点回到选择器 |

更多要求见[无障碍使用指南](/guides/accessibility)。
