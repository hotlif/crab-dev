# Select

下拉选择器，支持单选、多选与搜索。

[打开 Select 选择器 工作台](/components/rc-select/workbench/)

## 何时使用

- 需要在有限空间中从多个选项中选择一个或多个值。
- 选项较多，需要通过关键字快速过滤。
- 表单场景中需要统一输入尺寸与交互体验。

## 功能特性

- 支持单选与多选模式。
- 支持可搜索过滤。
- 支持受控与非受控用法。
- 支持禁用状态与禁用选项。
