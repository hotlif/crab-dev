# Switch 开关

切换立即生效的开启或关闭状态。

[打开组件工作台](/components/rc-switch/workbench/)

## 何时使用

用于通知开关、功能启停等立即生效的布尔设置。选中状态表示开启，未选中表示关闭。需要先选择、再随表单提交的选项通常使用 Checkbox。

## 视觉状态与验证

切换轨道使用独立的实线焦点环，强制颜色下保留轨道、手柄位置与焦点。立即生效操作如涉及异步保存，应在业务层明确处理中和失败恢复；组件本身不会请求服务器。

强制颜色使用系统配对颜色：关闭为 Canvas / CanvasText，开启为 Highlight / HighlightText，禁用手柄为 GrayText。悬停、按压和焦点不能用普通主题的手柄颜色覆盖这组配对；半透明状态光晕不参与强制颜色绘制，键盘焦点由独立轮廓表达。LTR/RTL 只改变手柄移动方向，不改变开启或禁用语义。

`md3` 下，`medium`（默认）与 `large` 使用 52×32px 轨道；`small` 保留 28×16px，作为显式紧凑选项。`shadcn` 的 `small` / `medium` / `large` 轨道维持 28×16、32×18、36×20px。

`apple` 的 small / medium / large 轨道为 28×16、36×22、44×26px，手柄分别为 12、18、22px；这组比例保留桌面 mini 与 regular 控件的层级，尺寸为项目的 Web 适配。

三套设计各自定义手柄和状态反馈：MD3 默认未选中手柄 16px、选中 24px、按压 28px，并保留圆形状态层；Apple 使用带轻阴影的白色手柄与蓝色选中轨道；shadcn 使用中性色轨道，选中手柄消费配对前景色。后两者在选中前后保持手柄等大，不叠加 MD3 光晕。浅深色与嵌套风格均通过 L2 变量切换。

shadcn 浅色关闭态在固定 New York V4 参考基础上增加 1px 手柄边界，作为项目桌面辨识扩展，不属于上游修复。描边宽度与颜色由公共 L2 `toggle.handle.unchecked-border-width` / `toggle.handle.unchecked-border-color` 映射到本包 L3，颜色沿用 `border.strong`；`border-box` 保持手柄外部几何。开启态、深色、MD3 与 Apple 的手柄不增加该边界；强制颜色继续使用既有系统配对颜色。

`aria-invalid="true"` 给轨道和焦点提供错误色，开启状态同时使用错误填充；应配合 `aria-describedby` 提供具体错误与恢复操作。Apple 是参考 Apple HIG 的 Web 定制，紧凑尺寸为项目适配，不声称复刻 AppKit。

视觉尺寸与命中区独立：所有指针环境下，命中区均至少为 48×48 CSS px；标签使用 14px 正文。

键盘焦点使用公共 L2 焦点角色，通过 L3 覆盖可调整；减少动态效果时移除非必要过渡。实际浏览器应逐项检查 Tab / Shift+Tab、原生激活方式、两种主题、强制颜色、长标签与粗指针布局。当前源码修复与自动检查状态见质量审查记录，不能把 CSS 中存在媒体查询等同于设备验收通过。

规则依据：[状态系统](/guides/accessibility)、[无障碍与键盘](/guides/accessibility)、[布局与密度](/guides/getting-started)。

## 维护与矩阵验收

触控场景使用原生轻触改变开启值，保留粗指针命中区检查；窄屏与真实缩放分别测量轨道、标签和实际文字范围，不能仅凭 Demo 容器无溢出判定内容可用。新增断言仍需对应浏览器结果与人工外观复审。

MD3 的描边轨道、状态层与可变手柄，Apple 的紧凑胶囊和轻阴影，shadcn 的中性轨道与浅色圆柄，均继续从同一组 L2 角色映射到本包 L3。标签字体随最近配置边界，视觉轨道和至少 48px 命中区分别处理。三档 size 不受 collection density 缩放。

状态矩阵覆盖开关两值的 hover / focus-visible / pressed、错误与禁用。开值通过真实点击进入；禁用时保留原值。状态通过 role=switch / aria-checked 告知，无加载或半选协议，异步保存反馈由所属表单负责。

包内 `docs/visual.json` 是该组件的可执行尺寸、密度、状态与跨引擎范围清单；`visual-matrix.demo.tsx` 使用公开入口。Chromium 执行完整核心矩阵，Firefox / WebKit 执行清单指定的默认与关键交互子集。窄屏 320 / 768px、长内容、RTL / 英文、品牌覆盖、强制颜色与减少动画分别登记环境场景；配置切换保留原 DOM 与值。真实 200% 浏览器缩放、iframe / Shadow DOM 与跨 Document 验收仍由集成矩阵记录，不以视口或 DPR 代替。

本批来源复核日期为 2026-10-29。[Material Web 控件文档](https://material-web.dev/components/switch/)提供 Web 行为对照；Material Web 不完整覆盖 Expressive，精确 Expressive 形态采用本页注明的项目扩展。[Apple HIG](https://developer.apple.com/design/human-interface-guidelines)作为自主 Web 实现的原则依据；shadcn 继续锁定 New York V4 的 `3d98900e9b73c45f035f8109e9d41ba6a51685e7`，引用提交以产品清单为准。M3 官网需 JavaScript 的规格页未在本批静态读取中补造精确参数。

测试发现、截图候选、像素稳定性与人工外观复审分别记录。当前新增矩阵尚待统一浏览器执行和逐项复审，设计覆盖保持 partial，不能用用例存在或默认测试通过更新为 verified。

## 状态契约

`checked / defaultChecked / onCheckedChange(next, details)` 管理开关状态，`details.reason` 为 `toggle`，`details.event` 为原生按钮激活对应的 React 点击事件。

受控值与默认值互斥；默认值仅在初始化时使用。外部属性更新不触发操作回调，省略回调可展示只读受控快照。
