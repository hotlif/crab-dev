# Switch

开关组件, 用于在两种状态之间切换。

[打开 Switch 开关 工作台](/components/rc-switch/workbench/)

## 何时使用

- 需要表示开关状态/两种状态之间的切换时
- 和 Checkbox 的区别是, 切换 Switch 会直接触发状态改变, 而 Checkbox 一般用于状态标记, 需要和提交操作配合
