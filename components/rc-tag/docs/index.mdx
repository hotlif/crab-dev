# Tag 标签

标记分类、属性或状态，支持关闭和勾选。

[打开组件工作台](/components/rc-tag/workbench/)

## 何时使用

- 用于标记事物的属性和维度。
- 进行分类和筛选。
- 展示状态信息（成功、警告、错误等）。

预设颜色包括默认、品牌、成功、警告和错误。状态应同时通过文字或图标表达。

## 主要功能

- 支持预设颜色与自定义颜色字符串（如 `#1677ff`）。
- 支持 `icon` 前缀图标。
- 支持 `closable` 与 `onClose` 关闭交互。
- 支持 `closeIcon` 自定义关闭图标。
- 关闭按钮使用标签内的紧凑绘制尺寸，悬停、聚焦和按下反馈与当前标签前景配对；焦点环位于关闭角色内部。粗指针下保留 Button 独立的触控命中区域，不用放大可见背景代替触控适配。
- `CheckableTag` 对应 Material Filter chip，选中后显示勾选标记并使用 secondary container；多个筛选标签应放在有名称的 toolbar 中。

## 自定义颜色配对

非强制颜色模式下，`color` 为不透明十六进制颜色时（`#RGB`、`#RRGGBB`，以及 alpha 完全不透明的 `#RGBA` / `#RRGGBBAA`），Tag 按 sRGB 相对亮度选择对比更高的黑色或白色文字；这与当前设计体系和明暗模式无关，背景保留调用方原值。

CSS 变量、半透明颜色及其他 CSS 颜色语法不会自动推断背景或前景，请同时通过 `style.color` 提供与实际背景配对的文字色。非强制颜色模式下，`style.color` 优先于自动值；显式覆盖后的对比由调用方负责。此能力不解析任意 CSS，不通过挂载后读取 DOM 改色，服务端和客户端采用同一规则。预设色使用各设计体系的成对语义令牌；启用强制颜色后，预设色、自定义色与显式文字色均让位于下述系统配色。

## 三体系验收规格

2026-10-29 对照 [M3 Chips](https://m3.material.io/components/chips/guidelines)、[Material Web Chip 文档、示例与行为](https://material-web.dev/components/chip/)与 [Filter chip 样式](https://github.com/material-components/material-web/tree/main/chips/internal)。`CheckableTag` 对应 filter chip 的可选信息；普通 Tag 是项目状态展示扩展，可关闭 Tag 借鉴 input chip 的移除操作。它们不共用一个含糊的“标签按钮”语义。Apple 采用 [Buttons](https://developer.apple.com/design/human-interface-guidelines/buttons)的清晰动作与状态原则，自主实现 Web 标签；shadcn 对照锁定修订的 [New York V4 Badge](https://github.com/shadcn-ui/ui/blob/3d98900e9b73c45f035f8109e9d41ba6a51685e7/apps/v4/registry/new-york-v4/ui/badge.tsx)，可选择与关闭是保留的项目扩展。

| 设计 | 视觉与状态边界 |
| --- | --- |
| MD3 Expressive | 状态标签保持安静；筛选采用 secondary container 与勾选标记，hover / focus / press 为独立状态层。原有 chip 基线保留，不把 Expressive Button 几何套到筛选上。 |
| Apple | 轻量表面、紧凑字阶和明确选中填充；移除是具名的原生按钮，不把整个标签伪装为关闭动作。 |
| shadcn | 中性色与描边组织层级，primary / feedback 使用配对前景；圆角与 chip 几何经 L2 `status` 映射。 |

Tag 公开三档尺寸独立于三档密度；CheckableTag 只公开单一 chip 几何，不虚构额外尺寸。静态颜色覆盖 default / primary / success / warning / error，交互矩阵覆盖真实 hover、Tab 焦点、按下、选中、禁用和关闭。禁用筛选退出 Tab 顺序；选中勾选提供非颜色标记。关闭按钮命中区域与图标边界分别核对，焦点不被标签裁切。状态过渡自然完成后截图；强制颜色使用系统前景/背景配对，减少动画保留最终状态。

包内 `docs/visual.json`、`tag.visual.spec.mjs` 与“标签与筛选状态矩阵”Demo 为验收来源。环境扩展检查长文本、窄屏、触控、RTL、中英文和配置切换保持选择；真实截图与人工视觉复审分别记录，未复审范围保持待验收。

## 状态契约

CheckableTag 使用 `checked / defaultChecked / onCheckedChange(next, details)`，`details.reason` 为 `toggle`。Tag 的关闭按钮复用 Button，`onClose` 接收 `HTMLButtonElement` 的 React 点击事件，关闭文案默认跟随全局语言。

受控值与默认值互斥；默认值仅在初始化时使用。外部属性更新不触发操作回调，省略回调可展示只读受控快照。

强制颜色模式下，普通 Tag 使用 Canvas 表面、CanvasText 文字与边框，保留标签文字和图标；关闭按钮继续使用 Button 的系统配色、关闭语义与可见焦点。Tag 自行保持系统前景和表面的配对，避免浏览器文字背板遮住内容。

CheckableTag 使用系统前景与表面颜色，选中态使用配对的 Highlight / HighlightText，禁用态使用 GrayText，并保留勾选标记与可见焦点。

## 三套设计风格

普通标签在 Material / Apple / shadcn 下分别采用 8px / 4px / 胶囊圆角。可选标签在 Material 下对应 32px 高、14px 标签字的 filter chip；Apple 与 shadcn 使用紧凑的 24px 高选择标签。选中勾选、键盘操作和 disabled 语义保持一致，普通静态 Tag 不冒充 M3 交互 chip。

切换文档站设计风格后，本页演示同步使用该设计；浅色和深色模式分别使用配对语义颜色。
