# Canvas WebGL 画布

使用 React 组件声明二维图形，由 WebGL 2 在 GPU 上绘制。支持矩形、圆形、线条、文字、图片和分组变换。

[打开组件工作台](/components/rc-canvas/workbench/)

## 何时使用

- 需要绘制大量 2D 图元（矩形、圆、线、文字、图片）且追求 GPU 加速与流畅动画时。
- 需要以声明式 React 组件树组织画面，而非命令式操作 Canvas 2D API 时。
- 需要对图形做分组变换（平移 / 旋转 / 缩放）并保持嵌套坐标系时。

## 主要功能

- **WebGL 2 渲染**：通过内置着色器绘制图元。
- **声明式 API**：`<Canvas>` 内嵌套 `<Rect>` / `<Circle>` / `<Line>` / `<Image>` / `<Text>` / `<Group>`。
- **SDF 抗锯齿**：圆角矩形与圆形通过有符号距离场实现亚像素级平滑边缘。
- **任意角度直线**：顶点着色器端挤出（line extrusion），支持任意斜率与线宽。
- **分组变换**：`<Group>` 维护 TRS 矩阵栈，子孙坐标随父级叠加，支持任意层级嵌套。
- **OKLCh 颜色**：颜色解析支持 `oklch()`、十六进制与 `rgb()/rgba()`。
- **设备像素比自适应**：根据 `devicePixelRatio` 调整画布分辨率。

## 画布与阅读视口

**现有示例：** 固定绘图坐标放在有名称、可聚焦的局部滚动区域内。窄屏可横向查看完整画布，页面正文不会随绘图宽度扩张。画板中的显式配色服务于图元样张，不代表业务界面的语义主题；画板周围的焦点使用公共语义颜色。

**选择规则：** 要保持坐标和形状比例时使用局部滚动；要让画布本身随容器变化，可使用已有 `fillParent`，并为父容器提供明确尺寸。滚动区域的键盘可达不等于内部图元已具备名称、选择或拖拽的键盘替代，交互图形仍需单独实现和验收。

## API

`CanvasImage.src` 支持字符串 URL 和 `ImageBitmap`。位图由调用者持有，替换或卸载后应调用 `close()`；Canvas 在最后一个消费者释放时删除图片和字形的 GPU 纹理及 CPU 缓存，不关闭调用者提供的位图。

更换图片时保留上一张已上传纹理，新图片上传成功后再替换；加载或上传失败调用 `onError`，保留原图。`Canvas.onRender` 在每次实际绘制完成后通知，可用于交接双缓冲画面；图片的 `onLoad` 仅表示上传完成，不表示画面已经绘制。使用双缓冲时应在旧场景移除后关闭其位图。

Canvas 真正卸载后主动释放 WebGL 上下文，避免虚拟列表反复挂载画布耗尽浏览器配额；StrictMode 的挂载检查保留正在使用的上下文。上下文意外丢失期间暂停绘制通知，浏览器恢复后重建绘图资源，重新上传仍在使用的图片和字形并重绘，无需重新加载业务数据。资源释放与恢复依据 [WebGL 最佳实践](https://developer.mozilla.org/en-US/docs/Web/API/WebGL_API/WebGL_best_practices)及 [Khronos 上下文丢失处理说明](https://wikis.khronos.org/webgl/HandlingContextLost)。
