# @crab-dev/rc-divider

分隔内容或行内操作，明确分组边界。

## 主要功能

- 支持水平和垂直方向；垂直分割线适用于行内操作。
- 水平分割线可添加标题，并配置标题位置与偏移量。
- 提供实线、虚线、点线，以及四档留白。
- 默认表达 `separator` 语义；纯装饰线可设置 `decorative`。
- 带文字时通过 `aria-labelledby` 关联标题，此时不能设置 `decorative`。
