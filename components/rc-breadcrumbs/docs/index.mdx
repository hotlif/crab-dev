# Breadcrumbs 面包屑导航

展示页面层级，并提供返回上级页面的入口。

[打开组件工作台](/components/rc-breadcrumbs/workbench/)

## 何时使用

- 页面存在明确层级关系，需要展示当前位置。
- 需要在深层页面中提供快速返回上层路径的入口。

## 主要功能

- 支持通过 `items` 配置导航层级。
- 支持 `separator` 自定义分隔符。
- 支持 `maxCount` 折叠中间层级，避免路径过长。
- 支持每一项配置 `href`、`onClick`、`disabled`。
