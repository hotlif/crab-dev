`test:forced-colors` builds published Table ESM and real dependency/theme CSS, then uses the shared isolated Chrome launcher. Each of the six design/mode configurations includes a two-row table in LTR and RTL, with the first row controlled-selected and physical left/right fixed columns.

The fixture checks native selection attributes, the system color pair, cell geometry and actual character/word ranges. Actual screenshot pixels must contain foreground strokes and background gaps within each selected word. Every character must also retain strictly matched background gaps, so a solid text backplate cannot pass by matching the foreground color. Exact and antialiased foreground counts remain recorded for every character: a thin stem may contain only subpixel antialiasing, so individual characters are not required to contain a pure foreground pixel. Word foreground uses tolerance 32; all background checks retain tolerance 2. The unselected row must retain automatic color adjustment. The two declared directions are separate scenarios, not an assertion of mirrored table geometry. This focused check does not replace the full interaction or visual matrix.

Set `CRAB_TEST_BROWSER_PATH` or `CHROME_PATH` for a nonstandard Chrome/Chromium executable. Missing browsers fail; screenshots and source/ESM/CSS/helper fingerprints are saved in `.cache/forced-colors/`. The launcher owns and closes its isolated process, and never attaches to the user's browser.
