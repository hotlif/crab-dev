# Table

表格用于展示结构化数据。

[打开 Table 表格 工作台](/components/rc-table/workbench/)

## 何时使用

当需要清晰展示大量信息、进行数据对比，或在行列维度上进行查看与操作时，使用表格。


表格常见能力包括：

- 📄 展示多列结构化数据
- 🔎 支持排序、筛选等数据处理
- ✅ 支持行选择与批量操作
- 📌 支持固定表头与固定列
- 🧩 支持自定义单元格渲染
