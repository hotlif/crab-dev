# Menu

为页面和功能提供导航的菜单列表。

[打开 Menu 菜单 工作台](/components/rc-menu/workbench/)

## 何时使用

导航菜单是一个网站的灵魂，用户依赖导航在各个页面中进行跳转。

我们提供了两种菜单模式。

- 📋 垂直菜单：侧边栏导航，支持展开/收起子菜单。
- ➡️ 水平菜单：顶部导航栏，支持下拉子菜单。
