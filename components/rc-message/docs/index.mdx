# Message 全局提示

在页面顶部展示简短的操作反馈。

[打开组件工作台](/components/rc-message/workbench/)

## 何时使用

用于保存成功、复制完成或操作失败等简短反馈。消息在页面顶部居中显示，可按 `duration` 自动关闭。需要详细说明或后续操作时使用 Notification，需要持续展示的页面提示使用 Alert。

## 主要功能

- 支持五种类型：`success`、`info`、`warning`、`error`、`loading`。
- 顶部居中弹出，自动消失。
- 支持自定义 `duration` 控制显示时长。
- 鼠标悬停或内容中的操作获得键盘焦点时暂停倒计时，离开后继续剩余时间。
- 支持自定义图标 `icon`。
- 通过 `useMessage` Hook 创建实例。
- 多条消息堆叠，最多显示 3 条，仅最上层消息计时；旧消息恢复到最上层后继续剩余时间。
- 入场、退场和进度条均使用 CSS，自动适配减少动态效果偏好。`duration={0}` 的常驻消息不展示倒计时条。

## API

`useMessage()` 的 open/success/error/warning/info/loading 均返回 `{ id, close, update }`。例如 `const handle = message.loading('正在保存', 0)`，保存完成后 `handle.update({ type: 'success', content: '已保存', duration: 2000 })`。update 保留 ID 并重新计时；close 重复调用只通知一次。实例也支持 `message.close(id)` 和 `message.update(id, patch)`。

默认 Message 组件通过 open/onExitComplete 控制显隐，duration 只控制进度动画；自动关闭与 onClose 回调由 useMessage 管理。

## 三套设计风格

MD3 Expressive 使用逆色 snackbar 表面；Apple 使用 12px 圆角的面板通知；shadcn 使用 8px 圆角的中性 toast 表面。边界、前景和背景通过语义角色成对切换，进度、排队、悬停暂停及读屏通告保持一致。多个堆叠消息和倒计时进度条是项目扩展。

切换文档站设计风格后，本页演示同步使用该设计；浅色和深色模式分别使用配对语义颜色。


消息默认使用 `role="status"` 和 `aria-live="polite"` 排队通告，不抢占当前焦点。直接渲染组件时可通过原生属性显式设置紧急通告。自动消失的信息也应在触发位置提供持久反馈，较长内容建议传入至少 4000ms 的 duration。

## 三体系规格与验收边界

轻量操作结果参考 Snackbar 的非阻塞反馈语义，但多类型、加载、队列是项目扩展。矩阵独立组件明确 open 与 duration=0；自动关闭归 useMessage 管理，浮层场景使用真实 handle.update/close，不以修改样式假造状态。loading 图标复用公开 SpinIndicator 的三体系实现，不再维护私有 SMIL 旋转；减少动画沿用同一指示器的低频呼吸，单独自然视频验收。

| 体系 | 组件视觉规则 |
| --- | --- |
| MD3 Expressive | 强调结果可读性与浮动层级；不把无限加载图标称为 Expressive loading indicator。 |
| Apple | 轻量表面、内容清晰，自主 Web 通知模式。 |
| shadcn | 参照中性浮动反馈与描边层级；参考提交未提供同名 Message，独立实现。 |

本包几何与视觉来源：root.padding / border-radius / border-color / box-shadow；body 字阶；icon.width / margin-right；stack.translate 和空间动效；progress 仅在有限 duration 时显示。设计值只在对应 token.toml 与它引用的语义角色维护，验收测量读取实际 DOM 计算值。

颜色、字阶、形状、状态和动效分别从 L2 角色映射到包内 L3；Theme 负责最近配置边界。明暗模式使用配对前景/背景，不进行整体反相。视觉边界与命中区域分别检查，焦点截图保留外部轮廓与阴影。强制颜色采用系统色；减少动画保留信息与最终状态。

矩阵定义在本包 `docs/visual.json`，场景使用 `visual-matrix.demo.tsx`。Chromium 覆盖其中全部设计/明暗/命名尺寸/适用密度/状态；Firefox 与 WebKit 按 `crossEngine` 的默认展示和重点交互子集执行。窄屏、RTL、中英文、长文本、品牌覆盖和配置切换后的草稿保持另有场景；未运行、未人工复核或失败的项不能计为通过。开放尺寸输入的代表样本不等于无限集合的穷尽。
