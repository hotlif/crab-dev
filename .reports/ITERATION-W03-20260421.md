## 二、核心交付

### 2.1 rc-app-main-layout —— 标签栏 + 侧边栏折叠（v0.0.3）

本周最重量级的改动。AppMainLayout 从静态布局容器演进为具备完整交互状态管理的应用框架壳：

| 子功能 | Commit | 行数 | 说明 |
|--------|--------|------|------|
| 标签栏 + 上下文 + 状态管理 | `73c9cfd` | +1,501 / -175 | 新增 `tabBar.tsx`（443 行）、`context.tsx`（69 行）、`reducer.ts`（102 行）、`useTabs.ts`（71 行） |
| 布局 + useTabs 测试 | `e1bd7bc` | +215 | 覆盖 `layout.test.tsx` 和 `useTabs.test.tsx` |
| 基础 Demo 更新 | `ab86a79` | +178 / -73 | 集成标签页与面包屑导航的完整示例 |
| Token 增强（统一使用 token） | `af5b146` | +746 / -70 | AppLayout 与 Menu 统一改用语义令牌，消除魔法数值 |
| 侧边栏折叠支持 | `c0fbf36` | +125 / -13 | `sidebar.tsx` / `layout.tsx` / `reducer.ts` 新增 collapsed 状态联动 |

**架构变化：** 引入 Context + Reducer 双层状态管理，`header.tsx` 承接标签页操作，`sidebar.tsx` 响应折叠状态，`tabBar.tsx` 负责渲染和上下文菜单（右键 Tab 操作区）。

### 2.2 rc-menu —— Inline 模式垂直折叠（v0.0.2）

| 子功能 | Commit | 行数 | 说明 |
|--------|--------|------|------|
| Token + 图标 + 子项背景修复 | `d18d01a` | +36 / -4 | 新增 open-state token、icon 相关 token，修复展开子项背景色异常 |
| Inline Collapsed 模式 | `8c78bfa` | +715 / -9 | 新增 `vertical/collapsed.tsx`、`vertical/index.tsx`（路由入口），原实现重命名为 `vertical/normal.tsx`；Demo + 测试覆盖折叠交互 |

**实现思路：** Vertical 模式按 `inlineCollapsed` prop 在运行时切换 `normal` 与 `collapsed` 两个静态子树，折叠状态下隐藏标签文字、仅保留图标，鼠标悬停通过 Tooltip 补充标签。通过拆分子树而非条件样式来满足 Linaria 零运行时约束。

## 九、总结

第三周的核心成果是 **应用框架壳的功能深化**。rc-app-main-layout 新增了完整的标签页系统（Tab Bar + Context + Reducer + useTabs）和侧边栏折叠联动，从静态布局容器演进为具备状态管理能力的应用框架；rc-menu 新增了 inline-collapsed 垂直折叠模式，与侧边栏收起形成完整的导航折叠体验。

**关键数据：**

- **净增代码：** +3,897 行（无清理因素，是 W2 的 1.9 倍）
- **新增组件：** 1 个（Breadcrumbs，P1 优先级）
- **重大功能增强：** 3 处（Menu 折叠 / AppLayout 标签栏 / AppLayout 侧边栏折叠）
- **Commit 质量：** 连续三周 0% 模糊率

**主要问题：**

- **与计划偏差显著：** W02 下周计划的 3 项"必须完成"全部未执行（build 产物、virtual 测试、hooks 测试），优先级决策需要更纪律化
- **活跃天数不足：** 04-17~19 连续 3 天空档，违反 5/7 活跃天数目标
- **技术债持续积压：** build 产物缺失已连续 2 周，形成发布阻塞风险

下周重心**必须**回到技术债清零：先补齐所有组件的 build 产物，再推进 P1 组件扩展。
