## 已取得的证据

以下为实际执行结果，不代表未列出的视觉范围已经验收。

- 全量入口已通过架构、命令、拓扑、令牌、安装与生成物复现、lint、库构建、导出、独立打包消费、全部类型检查和默认测试。
- 独立 PnP 消费覆盖产品清单中的全部公开包、ESM / CommonJS、内部入口与资产入口，使用自己的官方 TypeScript。
- 默认测试 2,147 项通过；字段关联与跨 Document 协调包含行为回归。
- 生成器 53 项契约通过，覆盖泛型、继承、重导出、联合互斥、独立状态组合、跨文件缓存失效、展示配置错误与孤儿产物；最后连续生成检查无漂移。
- 最终文档站生产构建通过，1,889 个 JavaScript 产物未发现未绑定名称；所有源与生成物已同步。
- 登记的 49 项附加检查均在修正并复验后通过。Table 的真实 iframe 检查验证文档间复制隔离和列宽拖动资源归属；Tree 的真实编辑示例验证缺省变量回退与行内焦点环。
- 实际浏览器核对最终设计对照页：三体系浅深色切换保留同一输入草稿；320px 和 768px 页面没有整页横向溢出；另核对强制颜色和减少动画条件。十张实际截图均已查看，源码与产物指纹采集前后一致，详见[候选验收记录](../.website/review/20261029-maintainability-candidate/README.md)。这是指定页面和状态的证据，不能推广为全组件验收。

完整日志与[逐项附加结果索引](../.website/review/20261029-maintainability-candidate/validation/required-results.json)保存在候选验收目录。首次统一检查在旧 Table 几何断言处失败；修正后按相同计划复验相关项目并继续后续项目，最后重新运行全局阶段。这里不将首次失败命令记为通过，也不重复执行未受修正影响的附加检查。临时缓存或浏览器 profile 不纳入交付源。
