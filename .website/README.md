# Crab UI 组件文档站

网站以“组件查阅 + 可运行示例 + API 参考”为主要入口，覆盖 52 个包、三个完整业务教程，并保留 246 个进阶示例和原组件工作台地址。Wake 精确使用 `0.1.43`，公共 Crab CSS 保持 `0.1.38`。代码检查已迁移到 `yarn lint`，版本、规则差异及最新验证见[工具链迁移记录](review/toolchain/README.md)。

## 生产示例可用性

`yarn build` 在 Wake Docs 构建之后执行 `yarn check:build`，对主站与工作台的生产 JavaScript 做作用域检查；发现未定义引用时构建失败。`yarn test:build` 验证该检查能够识别已复现的打包错误。报告位于 `docs-dist/binding-check.json`。检查允许依赖中的受保护 CommonJS / AMD 分支、React DevTools 等宿主标识符；它不替代真实浏览器交互测试。

Wake / Crab CSS 0.1.38 的直接 `cx(...)` 转换可能在局部变量重命名之后插回旧变量名。已复现 DatePicker 的 `centerFlexStyle`、表格固定列及多个工作台的同类错误。受影响源码使用 `cx.call(undefined, ...)` 保留同一公开函数的运行时调用和参数作用域，没有复制 cx 实现或修改 Wake。升级工具链后，应先通过最小构建复现、`check:build` 和实际示例操作，再考虑恢复直接调用；不要仅为格式统一改回。

下拉教程必须在容器内通过 `useDropdownContext` 连接 `refs.setReference` 和 `dispatch`；只放入一个 Button 不会自动展开。日期示例使用可见标签，日期选择需确认，方向键和 Enter 可完成选择。日期时间面板在窄屏下上下排列，浮层内部允许纵向滚动。

独立工作台与嵌入预览统一使用公共主题。各包 `wake.config.toml` 的 `theme_css` 指向项目内 `docs/theme.css`，再导入共享的 `components/rc-theme/docs/workbench.css`。共享适配层只消费公共语义前景和表面，不保存第二份色板。先运行根目录 `yarn build:library`，再启动或构建文档，保证公共主题 CSS 已生成。质量检查与迁移说明见 [持续审查记录](review/quality/README.md)。

## 展示接口

`wake.config.toml` 通过 `docs.ui` 加载 `docs/site/ui.tsx`，注册全部 14 个公开展示组件。Wake 管理路由、搜索、主题偏好、加载和 Demo 状态；站点负责布局与 Crab 组件适配。样式位于 `docs/site/siteStyles.ts`，通过 Crab CSS 编译公开令牌值，不依赖 Wake 内部类名或私有变量。组件 CSS 随模块引用自动加载，站点与示例不手写 CSS 副作用导入。CSS-only 的 `rc-theme` 仅声明依赖不会被加载，因此由 `docs.theme_css` 指定项目内的 `docs/theme.css`，再通过 CSS `@import` 交给 Wake 加载公共主题。

首页以企业应用定位、“开始使用”和“组件目录”两个主要入口开始；右侧由 Card、Avatar、Tag 和 Button 组成只读项目概览，明确标注示例数据，并可直达页面下方的完整交互体验。项目概览位于 `docs/site/homeProjectPreview.tsx`，属于站点展示，不维护另一套表单或任务状态。下方“设计与实践”分别通往设计语言、无障碍指南与本页业务实战，桌面三列，窄屏按 DOM 顺序堆叠。随后依次展示常用组件、业务实战与真实交互体验。常用组件的数量从当前分类条目计算，正文说明这是精选入口，“查看全部组件”进入完整目录。分类复用 Card 的 filled 变体，以语义表面底色、标题与统一内边距分组；标题为普通 h3，独立的“查看分类”链接进入对应目录章节，内部组件名称分别进入文档。交互体验继续复用任务清单、访问图表、团队邀请和通知偏好，示例内容与可复制源码共同生成。组件页先展示基础示例，再进入分步教程、API 和进阶示例。基础示例直接复用教程第一步的运行入口和源码，不维护第二份示例文件。API 使用语义化属性列表，适合长类型和手机阅读；筛选结果、继承信息和提取警告仍来自 Wake。

`siteContext.ts` 提供站点公开状态、部署前缀链接和教程目录挂载点。新增链接使用 Wake 的 `href` 或 `useSiteHref`，章节 fragment 与查询参数在路径解析后拼接。示例 iframe 独立，继续使用工作台原有主题通信。

桌面采用三栏；768–1279 px 使用左侧导航与正文，页内展开目录；低于 768 px 使用左侧 Drawer 导航，不显示确认表单式的底部操作。搜索与导航取消时恢复触发器，选择页面后在原生 `close` 事件中将焦点交还正文，等待 Dialog / Drawer 的退出动画完成。Demo 在全屏退出动画结束前继续由弹层持有唯一 preview。

导航分组按钮使用独立 SVG 箭头与 `aria-expanded` 驱动旋转，子页通过缩进和中性导线表达层级。当前页使用公共 selection 紫色浅填充，悬停使用中性填充，避免悬停项抢过当前页；手机导航行与关闭按钮至少 44 px。代码块根据公开 `code` 建立行边界，高亮节点与源码行数不符时回退为完整源码；不依赖 Wake 默认主题的逐行样式。复制仍使用 Wake 提供的回调。

搜索弹层的输入、结果数量和快捷键提示固定，仅结果区滚动。无边框 LineEdit 嵌入站点输入容器，由容器提供一层焦点环；选中结果采用填充与打开标记，不能再用焦点描边代替选中态。结果按 combobox / listbox / option 关联，方向键更新 Wake 的 activeIndex 并让当前项进入可视区；IME 组合输入、加载及错误期间不打开旧结果。关键词、结果与选中项仍由 Wake 管理，站点只提供展示和回调适配。

生成的示例搜索标题使用“名称 — 说明”。搜索适配器将其拆成名称、说明与来源三层，限制视觉行数，但保留完整的无障碍描述；不改变索引或原路由。没有可用结果时，底部操作变为“编辑关键词”，只聚焦输入，不执行无效导航。

`/learn/components` 是组件目录。`generate-tutorials.mjs#createLearningMap` 根据导航和教程记录生成分类数量、组件入口与学习步骤，常用组件分类先于基础工具，原分类锚点保持不变。`componentCatalog.tsx` 和 `catalogStyles.ts` 负责整块可点击入口及响应式网格；复用 Crab Button 与站点链接解析，不使用手绘缩略图。此页使用两栏外壳和正文分类索引，不重复显示右侧及折叠目录；其他文档仍使用原阅读布局。不要直接编辑生成的 `docs/learn/components.mdx`。

首次运行，在仓库根目录执行 `yarn install --immutable` 和 `yarn docs:dev`。已有组件构建产物时，可进入 `.website` 运行 `yarn start`。

在本目录运行 `yarn build` 生成生产站，再运行 `yarn preview`，通过 [本地预览](http://127.0.0.1:4173) 检查。预览服务只监听本机；可用 `DOCS_PREVIEW_PORT` 指定端口。它用于验收构建结果，不会发布网站。

生产预览不会热更新已经打开的页面。重新构建后，需要刷新用户实际查看的浏览器标签；仅刷新内置预览不能保证 Chrome 中的旧页面同步。交付时核对实际标签的页面标题与主要内容，避免用新产物的验收结果描述仍停留在旧版本的页面。

本次改版的验证范围、结果和现有工具链阻塞见 [验收记录](VALIDATION.md)。React `19.3.0` 与 TypeScript `7.0.2` 按要求保留；构建、Wake Lint、类型检查与 React 测试分别记录结果。

首页体验沿用 `docs/examples/home/profile.tsx` 作为单一运行入口，展示的完整源码由生成器直接提取。`docs/site/learningHome.tsx` 与 `homeStyles.ts` 负责首页布局和排版。陈列复用 Card、Avatar、Checkbox、BarChart、Segmented、Switch、Tag、Form、LineEdit 和 Button；任务、图表和通知各自维护示例状态，重置会重新挂载完整陈列。邀请为本地模拟，不会发送邮件。错误状态和文案共同维护，编辑会清除旧结果；提交中输入只读，提交结束只恢复尚未被用户主动转移的焦点，反馈支持长邮箱断行。首页先展示发布清单和邀请表单，图表、通知、标签与键盘体验保留在“更多组件体验”中，展开与收起不重置已有状态。示例使用两列并按内容高度排列，767 px 以下切为单列。Card 的公开 padding 令牌在此示例中设为 0，由自有内容层统一提供桌面 24 px、窄屏 16 px 内边距，避免重复叠加。表单采用 12 px 字段间距，输入、提交与周期选项为 44 px，Switch 通过包含说明文字的 label 扩大命中区域。`learn/index.mdx` 中的 `practiceGallery.tsx` 继续使用 Crab Tabs 按需运行三个实战教程的最终步骤。`liveExample.tsx` 统一使用 Crab ComponentPreview、Button、Alert 和 Spin，提供预览、源码、复制、重置与错误重试。不要另画组件缩略图；组件共性问题应在对应组件内修复。

组件目录现在按用户要求采用带示意图的概览卡片。`content/catalog/overview.json` 维护用途介绍；`docs/site/catalog/` 按输入、展示、结构与基础能力拆分静态 SVG 插图，`catalogStyles.ts` 负责令牌化外观。这里的插图仅用于识别组件用途，统一 `aria-hidden`、不可聚焦；整张卡片复用 Button 链接跳转到真实交互文档，不挂载 iframe 或另写可操作控件。此概览插图是上述缩略图限制的特定例外，首页陈列和教学演示仍使用真实组件。生成器检查全部 52 个入口的介绍与插图覆盖，并继续维护原分类锚点。更新介绍后执行 `yarn generate:docs`，不要手改 `learn/components.mdx`。

站点明暗主题统一导入 `@crab-dev/rc-theme/css/index.css`，配对来源为公共 `rc-token-semantic/src/theme.ts`。`palette.ts` 保留展示别名，`paletteStyles.ts` 只设置文档专用变量，禁止重新声明公共 L2 颜色。正文采用 16 px 基准，导航采用 14 px，辅助标记采用 12 px。首页展示样式使用站点自有类名，不能通过后代规则覆盖真实示例的输入、按钮或正文样式。

焦点颜色使用公共 L2 的紫色焦点角色，输入保留清晰的细边框与低透明度外圈。站点的通用 `:focus-visible` 只是低优先级兜底，并排除 `[data-wake-demo]` 及其后代，防止覆盖 LineEdit 等组件内部的焦点处理、形成两层描边。强制颜色模式会隐藏 box-shadow，因此仍保留系统色键盘描边兜底。LineEdit 教程中的标签间距由示例自身定义，源码和运行示例一起生成。

视觉维护需同时检查内容、控件状态和窄屏断行。文档标题与首页卡片采用 600 字重，侧栏分组采用 500；API 正文使用 14 px，并区分属性、类型、说明、默认值与弃用标记。搜索与主题入口桌面等高 40 px，手机等高 44 px。搜索常态无外框，快捷键不再另包边框；主题通过单个图标入口选择浅色、深色或跟随系统。主题入口复用 DropdownContainer 的定位与外部关闭、Button 的操作反馈，并在站点内补齐 menu / menuitemradio 语义、方向键与焦点恢复；偏好继续交给 Wake 保存。菜单采用 44 px 普通列表，避免覆盖 Select 内部固定的虚拟行高。菜单通过专用布局锚点与触发器右边缘对齐。入口的可访问名称和原生提示包含当前设置；文字选项在浮层中完整显示。首页手机内边距与其他页面一致，顶栏保持一行；主导航链接移入移动 Drawer，不能仅隐藏而失去入口。

预览标题栏通过公开 ComponentPreview 令牌移除装饰横线、使用轻背景，不能通过内部类名覆盖组件。表格选区使用透明填充，避免遮住文字；成功、错误、警告和信息背景在 L2 主题中分别使用对应色相。颜色仍来自 OKLCh 令牌，反馈背景使用 Oklab 混合，避免深色 Zinc 的微小色度在极坐标插值时把绿色偏移成蓝色。教程步骤使用中性选中态，操作说明与预期结果放在独立说明区。

教学示例内的字段、提示和按钮布局由示例源自己定义，不向所有预览注入表单样式。资料表单控制阅读宽度，提示靠近字段，提交结果与按钮留出间距；数据列表使用 Table 公开的自动列宽、40 px 行高和 AutoSizer，筛选区在窄屏自动堆叠；后台编辑抽屉的标题边界、关闭点击区域和字段间距通过公开令牌及自有类名控制。修改这些示例后继续运行 `generate:docs`，保证示例可独立复制运行。

生成器测试会检查站点和教学示例，禁止手写已有等价组件的按钮、输入框、选择框和弹层。首页布局由 Layout 的公开路由数据决定，正文排版限定在站点自身边界，避免污染运行中的真实组件。修改 UI 路径或启停 `docs.ui` 后需重启 `docs:dev`；自定义 UI 模式的开发构建使用完整单图。

子路径部署可用 `yarn wake docs build . --base /handbook/ --outdir .tmp/docs-handbook` 验证。预览服务支持 `DOCS_PREVIEW_DIR=.tmp/docs-handbook`、`DOCS_PREVIEW_BASE=/handbook/` 和独立的 `DOCS_PREVIEW_PORT`；这些是环境变量，请使用当前终端语法设置。不存在的文档路由返回 HTTP 404，并显示站点 NotFound 界面。

动效维护：`motion.interaction` 为 150 ms 的快速反馈，`motion.fade` 为 200 ms，`motion.expand` 为 300 ms，均从全局时长与缓动令牌组合。按钮、输入框与选择控件显式列出需要过渡的视觉属性，不能使用 `transition: all` 让字号、高度、内边距等几何属性意外参与动画。组件自身须处理减少动画偏好，不能只依赖文档站的全局覆盖。

导航与源码使用 Grid 行高连续展开，收起区域立即设置 `inert` 和 `aria-hidden`，但不在退场开始时直接隐藏或卸载内容。源码高亮仍在首次展开时按需加载；收起不重新挂载运行中的 preview。选中按钮不临时增加边框宽度。导航裁切区域应预留键盘焦点环空间。

Dialog 采用 200 / 150 ms 的进场 / 退场，Drawer 采用 300 / 200 ms；JavaScript 动画显式读取减少动画偏好。原生 dialog 关闭、内容重置和背景滚动恢复都在退出完成后进行，卸载时也要释放滚动锁。站点通过 `html:has(.crab-docs)` 预留滚动条空间，避免弹层开关时正文横向移动。

教学重置只重新挂载组件实例，保留已经成功加载的 lazy 资源，避免重复出现加载占位。明确点击加载失败后的重试才重建 lazy 资源。切换教学步骤继续通过步骤 key 隔离状态；工作台 iframe 的入口与生命周期保持独立。

验收动效前先读取浏览器的 prefers-reduced-motion。2026-09-11 实测用户 Chrome 为 reduce、内置预览为 no-preference，二者表现不同属于偏好差异；不得为展示动画擅自覆盖用户的减少动画设置。

首页阅读与空间规范：业务实战放在交互体验之前；主要目录入口称为“组件目录”，精选区域的“查看全部组件”明确表达范围扩展。分类说明解释具体使用任务：对象摘要、成员身份与无数据说明归信息展示，多条记录、层级与统计指标归数据与可视化；路由和自动尺寸入口分别标注“路由工具”“尺寸工具”。保持与完整目录相同的六类名称与目标锚点。跨页前进使用 →，页内向下定位使用 ↓，返回索引使用 ↑，GitHub 外链保留 ↗。分类与学习入口不使用装饰序号。Card 内容层统一提供 24 px 内边距，959 px 以下为 16 px；标题、说明与组件名称共用左侧基线。分类间距为 16 px，1200 px 起三列、640–1199 px 两列、更窄时单列。

每个组件的中英文名称在所有宽度下按两行排列：中文与英文均为 14 px，行间距 2 px；长名称自然断行。中文用链接色和 500 字重，英文用次要文本色和 400 字重；路由和尺寸工具的说明独占下一行。首屏数量、学习路径说明和实战组件名称同样使用 14 px，12 px 保留给章节上标等低优先级标记。组件入口网格通过 CSS auto-fit 按卡片可用宽度选择一列或两列，每项目标最小宽度 144 px（包含点击留白），容器更窄时按 100% 收缩；同时以可用宽度的一半作为下限，避免宽卡片出现三列加一个孤立入口。无需运行时测量或额外的小屏左右对齐规则。分类链接、组件入口与目录按钮至少高 44 px；“查看分类”的可访问名称包含可见文案和对应分类名称，常态使用次要文本色，悬停与键盘焦点时显示链接色及下划线。分类容器没有整卡点击或悬浮浮起。

639 px 以下，首屏学习入口保留完整标题、收起补充描述，减少目录之前的滚动距离；常用组件区显示六类页内索引，末尾提供返回索引入口，完整列表始终展开。分类标题使用稳定的 `home-*` 锚点及 `tabIndex={-1}`，使原生链接定位后仍有合理的键盘起点；没有筛选、折叠或运行时滚动监听。所有新增链接使用 `useSiteHref`，完整目录及组件地址不变。标题基础 margin 重置使用低优先级 `:where()`，只在存在章节上标时增加标题前 8 px，避免重置规则吞掉实际设计间距。

章节采用上 24 px、下 32 px 的留白，相邻章节合计约 56 px；章节标题下方为 24 px，639 px 以下为 16 px。以上属于首页局部设计规格，不是公共组件默认值。实战条目保留 16 px 内边距。

共用 Layout 的第一个键盘入口是“跳到主要内容”，直接聚焦当前 Wake 正文 main，滚动时为固定顶栏预留空间。搜索输入通过挂载时 autoFocus 处理 Dialog 关闭后重新挂载的情况，打开 effect 继续覆盖内容保留的路径；搜索外壳为桌面 24 px、窄屏 16 px，标题与页脚间距 16 px，输入左右 12 px，避免重复外框和双重内边距。搜索与邀请输入使用关联 label，使外缘留白也能点击聚焦；清除按钮继续保留自身行为。组件中英文名称采用正文行高，避免继承按钮的单行行高后挤在一起。修改后须运行文档与工程检查，并在真实浏览器校验分类断点、焦点和完整名称；涉及示例时还须生成源码，并检查搜索、表单提交与长反馈。
