# 三套设计体系

Crab UI 用同一套组件能力承载三个独立设计体系：MD3 Expressive、macOS、shadcn/ui。它们共享公共交互语义，通过成组的设计令牌定义颜色、排版、形状、尺寸、层级和状态。明暗、品牌、尺寸和密度是独立配置轴。组件库、文档站与工作台默认都使用 MD3 Expressive。

## 桌面专业视觉基线

三体系以任务效率、内容层级和清晰状态为共同目标。默认 `medium / standard`；紧凑密度用于高密度数据，舒适密度增加阅读与操作空间。粗指针使用独立的命中区域和自动几何下限，画布坐标与文档页面不随密度缩放。

| 能力 | MD3 Expressive | macOS Tahoe 26 | shadcn/ui |
| --- | --- | --- | --- |
| 操作 | 用填充、色调和形状表达主次，强调集中于关键动作 | 清楚的主操作、轻量次操作和稳定的圆角轮廓 | 中性层次、描边与克制的强调色 |
| 字段 | 上置稳定标签、紧凑连续轮廓或状态底线，错误和说明独立占位 | 上置稳定标签、清楚的输入边界和外部焦点环 | 上置标签、明确描边和一致的聚焦反馈 |
| 集合选择 | 成对色调前景与容器角色，选中和焦点分别表达 | 强调选中内容，保持邻近条目可读 | 用表面层次与边界区分选中、悬停和焦点 |
| 浮层 | 表面层级、组件形状和明确动作区 | 内容优先、轻量表面与清晰层级 | 边界、阴影与紧凑操作布局 |
| 数据与工具栏 | 数据行独立于按钮尺寸，强调不覆盖整片数据 | 稳定列对齐、紧凑工具和可见焦点 | 中性数据表面、简洁分隔与紧凑组合 |
| 动效 | 空间变化与颜色效果分开，保留中断和减少动画路径 | 简短、不过冲的状态反馈 | 按固定参考版本使用克制的淡入与位移 |

共享几何、形状、排版和动效的合同由 `rc-token-semantic` 维护；Theme 将语义角色绑定到设计和明暗边界。单组件的主题特例通过该包的局部令牌与静态样式块实现，并在组件正文中说明。设计标识、名称、来源和参考版本从产品清单生成，密度的 CSS 与数值测量来自同一份令牌。桌面扩展不将通用尺寸档位当作官方组件的统一高度。

| 组件能力 | 必核状态 |
| --- | --- |
| 操作与选择 | 默认、悬停、按下、焦点、禁用、选中及适用的加载 |
| 字段与表单 | 空值、有值、标签、说明、错误、只读、禁用、清除和键盘路径 |
| 弹层与导航 | 展开、关闭、翻转、嵌套、焦点进入与恢复、窄屏和滚动 |
| 数据集合与编辑器 | 空数据、首屏加载、刷新已有数据、失败、选择、编辑、展开和虚拟滚动 |

上述内容定义实现与验收目标。覆盖状态仍以实际候选的逐组件证据为准；规格、构建和共享测试不能替代视觉复审。

## 工程管理与设备运维

专业工作台以设备树、数据表格、属性面板和多任务页签组织连续工作。桌面示例使用 `small / compact`，字段与工具按钮保持接近的尺度，正文维持可读性与独立焦点；分栏支持调整，长表格在自己的区域滚动，设备编号与日期保持稳定对齐。表格以水平分隔表达行关系，表头与正文通过字重和留白区分，不给每个数据单元格绘制完整线框。状态同时提供文字和形状，语义色留给运行、待保养与检修等业务含义。

macOS Tahoe 的材质与层级服务于操作定位；数据、参数和工作备注保留实色表面。以搜索设备、切换树范围、选择记录、编辑参数并返回原草稿的完整路径验收，不能仅凭单个按钮或组件展示页判断是否适合工程软件。

## 配置与交互对照

`designSystem="md3" | "macos" | "shadcn"` 选择体系，`colorMode="light" | "dark"` 设置解析后的明暗；文档站另提供跟随系统的偏好。品牌、尺寸、密度、语言和方向各自独立：`brandColor` 用一个不透明十六进制色重算语义色对，`null` 回落到所选体系的默认品牌；`size`、`density`、`locale`、`direction` 与继承最近边界的 `nonce` 见[公共 API](/guides/public-api)。旧浏览器偏好迁移见[迁移指南](/guides/migration)。

## MD3 Expressive

依据 Material Design 3 Expressive。颜色采用成对语义角色和表面层级，排版表达内容优先级，形状、选中/按下状态和动效按对应组件变体确定。不能把统一胶囊、放大圆角或改主色等同于 Expressive。

实施每个组件前查阅对应使用指南、规格和无障碍说明；同时对照 Material Web 的文档、示例、行为、样式和令牌。Material Web 的既有 M3 基线不自动代表所有 Expressive 新变体，差异必须逐项记录。空间变化和颜色/透明度变化使用各自的动效角色，减少动画时保留必要反馈。

## macOS Tahoe 26 Liquid Glass

固定以 macOS Tahoe 26（2025 年引入的 Liquid Glass）为设计基准，显示名称为 macOS，公共 ID 为 `macos`。以 [Apple Liquid Glass 概览](https://developer.apple.com/cn/documentation/technologyoverviews/liquid-glass)及其采用指南为入口，具体 macOS 控件以 [WWDC25 AppKit 说明](https://developer.apple.com/videos/play/wwdc2025/310/)为基准。参考 Apple HIG 的 Materials、Buttons、Menus、Text fields、Toggles；Web 的尺寸、阴影与模糊参数是项目适配值，不等同于 AppKit 系统常量。

界面分为内容层与操作层。正文、表格、树、卡片、画布和编辑区域使用稳定的实色内容表面；浮层、菜单容器、工具栏与侧边导航使用 regular Liquid Glass 的 Web 适配：带底色的半透明材质、背景模糊、边缘与斜向高光、柔和悬浮阴影。普通字段保留清晰边界，不给整页套透明滤镜。玻璃效果只采样页面内背景，不采样操作系统桌面，也不模拟原生光学折射。

| 组件族 | Tahoe 适配 |
| --- | --- |
| Button | 保持五档桌面尺寸；xs/s/m 采用圆角矩形，l/xl 采用胶囊；普通 push、次要 tint、主要 tint 和浮动 glass 独立实现；危险、禁用、焦点独立表达 |
| LineEdit、TextEdit、NumberEdit、Select | 外部稳定标签、8px 控件轮廓、28/32/36px 单行 Web 档位、轻内阴影与外部焦点环；内容编辑表面实色 |
| Checkbox、Radio、Switch、Slider | 紧凑桌面比例、强调色选择、独立焦点、清晰滑块；Checkbox/Radio 的边缘与按压反馈独立实现，表格/树扩大命中区域也不会出现圆形 MD 状态光圈 |
| Segmented、Tabs、导航 | 紧凑轨道与有边缘高光的选中块；不使用 MD 状态遮罩、下划线或按下形变；Tabs 的 card/pill 变体保留 API，统一映射为桌面 tab bezel |
| NumberEdit、Select、TimePicker | 上下箭头组成一个数字步进器；单选菜单左侧勾选列与活动行分开；时间默认数字输入，显式 dial 属于扩展 |
| Card、Alert、CheckableTag | 卡片内容不随悬停抬升或按下缩放；内联提示使用中性正文与状态图标；可选标签按桌面 toggle button 表达，保持传入图标稳定 |
| Dropdown、Dialog、Drawer、Tooltip | 浮层材质、分级圆角与阴影；Portal 使用最近 Provider 配置；弹层内长内容保持可读 |
| Message、Notification | 玻璃浮动反馈表面，语义状态色和关闭操作保持清楚 |
| Table、Tree、表单、编辑器、图表 | 内容实色、桌面字阶、分隔线与清晰选中；没有直接原生对应的部分属于本库扩展 |
| AppMainLayout、PdfEditor | 独立悬浮侧栏；工具栏文字保持透明背景，相关操作共享玻璃容器；PDF 缩略图以选中边框表达，不给文档预览铺大块强调色 |

浅色玻璃以浅灰底色承载深色文本，深色使用深灰底色承载浅色文本。macOS 独立定义错误、成功、警告、信息和搜索高亮的颜色配对，不引用 MD3 颜色合同。深色主操作与实色状态标记保持饱和底色配白字，文本链接和状态正文另用浅色角色，避免直接把 Material 深色模式的浅色实心控件带入 Mac。默认使用系统字体；其他平台采用字体回退。品牌、明暗、尺寸、密度保持独立。嵌套 md3/shadcn 边界重置玻璃角色，切换主题保留输入、选择和草稿。

材质默认实色，仅在浏览器支持 backdrop-filter 时增强；prefers-reduced-transparency、prefers-contrast: more 恢复实色，forced-colors 使用系统色并移除装饰，减少动画沿用现有动效退化。材质不会通过鼠标跟踪或循环动画制造持续运动。

设计覆盖保持 partial，逐组件的实际截图、状态和交互证据才能提升覆盖等级。

## shadcn/ui

参考 shadcn/ui 的组件用途、设计变量与可组合原则，在本仓库 React 19、Crab CSS 和令牌体系中实现。中性表面、描边层次、圆角矩形、字体与焦点需要相互一致；品牌覆盖不应破坏前景配对。

本轮固定参考 New York V4，源码提交为 `3d98900e9b73c45f035f8109e9d41ba6a51685e7`，核对日期 2026-10-23。不跟随上游最新页面自动切换 Radix/Base、主题或组件变体。名称表示设计依据，不表示引入其运行时或承诺所有上游组件完全等价。

## 共同契约与独立规则

| 范围 | 共同契约 | 体系独立决策 |
| --- | --- | --- |
| 颜色 | 浅深色成对前景、表面、边界与状态 | 品牌、色调、表面层级和选中角色 |
| 品牌 | 一个种子色重算语义色对，不退化成主色覆盖 | 色相、明度映射与默认品牌 |
| 排版 | 文字可读、中文回退、长内容适配 | 字阶、字重、字体与层级节奏 |
| 形状与尺寸 | 视觉与触控命中区域分别定义 | 各组件轮廓、比例、间距与允许变体 |
| 交互 | 受控值、键盘、焦点、禁用和错误语义 | 选中/按下形态、状态层和反馈表达 |
| 动效 | 可中断，适配减少动画 | 运动角色、时序、缓动和形变 |
| 浮层 | 定位、关闭、焦点恢复和主题边界 | 表面、阴影、边框、排版和操作布局 |

组件没有直接对应规范时，采用最接近的语义和布局规则组合扩展，并注明项目决策。为 Web、紧凑尺寸和专业编辑器做的扩展必须显式记录，不能声称原生平台逐像素复刻。

## 组件级主题精修

动效优先表达操作反馈和空间关系。颜色与透明度使用 effects，位移、缩放和形状使用 spatial；文字度量、折叠行高与虚拟测量使用有界的 layout，避免过冲裁切内容。三体系沿用各自动效合同，组件只为实际变化的属性声明过渡。浮层定位坐标与入场位移分开，按实际弹出方向移动；退出中重开从当前状态继续，动画被替换后等待新的有效退出，业务操作不等待动画完成。

系统减少动画时取消装饰性移动与循环，保留可见的选中、焦点、错误和加载反馈。Spin 的低频呼吸属于必要的忙碌反馈，沿用已有降级合同。动效验收需要自然播放、中断、反转和运行中切换偏好；静态截图只说明某个时刻的外观。

三体系分别审查组件的尺寸、排版、形状、图标、状态和交互细节。主题可以有自己的内部布局、反馈方式和动效；公共接口、受控值、事件含义与无障碍语义保持一致。切换主题应保留输入、选择、草稿与有效焦点，核心交互节点优先保持稳定。

共性问题修在共享语义或公共能力层。只影响单个组件的特例留在组件包内，使用 L3 局部变量和必要的 `<component>.designs.ts` 静态样式块；通过最近的 `useConfig().designSystem` 选取样式，再用 `cx()` 组合。颜色继续引用成对语义角色，组合控件通过公开 `TokenVars` 映射状态。不得用祖先主题选择器使外层主题覆盖内层 Provider，也不并列渲染三套交互树再隐藏其中两套。

每项主题特例记录对应组件、变体、设计依据、适用状态与验证结果。无需特例的组件继续复用公共合同。逐组件审查记录维护于仓库的 `.website/review/component-theme-audit.md`；它记录本次工作进度，不替代产品清单的设计覆盖与验证证据。

## 覆盖与验收

[覆盖矩阵](/guides/design-coverage)由产品清单生成，已验收行同时列出源码提交与证据文件，产物指纹和矩阵范围保存在清单的 `verification` 记录里。每个可视包分别验证三体系、浅深色及适用的 default、hover、focus-visible、pressed、disabled、selected、error、loading；并核对键盘、Portal、iframe、窄屏、触控、长文本、强制颜色与减少动画。标为无独立视觉的包不进入这套视觉矩阵，但仍需行为、类型和依赖检查。

partial 表示已有实现但完整矩阵未验收，verified 需要当前提交和产物证据。改名、共享主题测试、少量截图或工程通过，均不能把整套体系自动标为完成。

状态核对分别记录默认、悬停、按下、键盘焦点、选中、禁用、错误、加载和展开等适用项。滚动或折叠容器中的焦点、关闭动作的局部反馈、空数据与阻塞状态的优先关系，以及宿主通用样式对组件的影响，需要真实构建 CSS 和浏览器证据。失败原图保留；修复后在新候选版本复核，采集前提错误与产品缺陷分开记录。
