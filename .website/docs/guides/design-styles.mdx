# 三套设计风格

同一套组件 API 提供 macOS、Material Design 3 和 shadcn 三套风格。差异包括控件比例、标签布局、选中表现、容器层次、字体和状态反馈。切换风格只更新配置与设计令牌，保留正在编辑的内容。

文档站首次访问默认使用 macOS。浏览器保存过的选择优先保留；主题菜单分别控制设计风格和明暗模式。组件库没有指定 `design` 时仍使用 Material，应用应显式选择自己的默认风格。

## 交互对照

下面直接使用库内组件。可以编辑字段、改变选项、用键盘切换标签页，或打开菜单、对话框和侧边面板。顶部选项同步修改整个文档站的风格；不重新创建输入组件。通过站点主题菜单分别检查浅色和深色。

## 风格差异

| 范围 | macOS | Material Design 3 | shadcn |
| --- | --- | --- | --- |
| 文字与表面 | 平台系统字体、银灰表面、细描边和柔和阴影 | Material 字体角色、分层表面和状态层 | 中性文字和表面、描边优先 |
| 操作按钮 | 蓝色主要操作、圆角矩形次要操作 | Filled / Tonal / Outlined 等操作层级和胶囊形状 | 中性主要操作与稳定的圆角矩形 |
| 输入与表单 | 独立标签、蓝色焦点反馈、桌面控件比例 | 浮动标签、56px 字段与 Filled 底线 / Outlined 轮廓 | 独立标签、中性焦点反馈、紧凑描边字段 |
| 选择控件 | 蓝色复选框、单选圆点和紧凑开关 | 状态层、Material 选中指示与开关比例 | 中性选中填充和紧凑开关 |
| 导航与分段 | 蓝色当前行、滑块式分段选择、紧凑工具栏 | 胶囊导航项、Primary Tabs 指示与分段轮廓 | 中性当前行、分段轨道与描边边界 |
| 弹层与反馈 | 描边浮层、柔和投影、清晰默认操作 | 表面层次、Material 阴影和操作分组 | 中性描边、较弱投影、紧凑操作分组 |
| 文档站 | 顶部工具栏、银灰侧栏、卡片式标题与演示 | 左侧导航 rail、胶囊目录与分层演示容器 | 顶部导航、平面侧栏、分隔标题与描边演示 |

窄屏都使用紧凑顶部导航和可关闭的导航抽屉。布局变化使用同一棵页面内容树，输入草稿、已选项与演示实例不会因风格切换丢失。

## 依据与实现边界

查阅日期：2026-10-22。Material 使用既有 M3 基线，未把导航改为 Expressive expanded rail。导航参考 [M3 Drawer 使用指南](https://m3.material.io/components/navigation-drawer/guidelines)、[规格](https://m3.material.io/components/navigation-drawer/specs)与[无障碍说明](https://m3.material.io/components/navigation-drawer/accessibility)。文档侧栏的 256px 宽度与紧凑目录行属于网站扩展，区别于标准 Drawer 的 360dp 容器和 56dp 指示器；保留其胶囊选中、语义颜色与可见焦点，未添加额外选中竖线。

Material Web 没有对应导航 drawer 组件，菜单行为与浮层对照 [Menu 文档与演示](https://material-web.dev/components/menu/)、[菜单行为](https://github.com/material-components/material-web/blob/main/menu/internal/menu.ts)、[菜单样式](https://github.com/material-components/material-web/blob/main/menu/internal/_menu.scss)及 [v0.192 菜单令牌](https://github.com/material-components/material-web/blob/main/tokens/versions/v0_192/_md-comp-menu.scss)。组件专门参考资料记录在各组件页。

macOS 参考 Apple 的 [Sidebars](https://developer.apple.com/design/human-interface-guidelines/sidebars)、[Toolbars](https://developer.apple.com/design/human-interface-guidelines/toolbars) 与 [Buttons](https://developer.apple.com/design/human-interface-guidelines/buttons)。这是一套面向 Web 的 macOS 风格定制，保留浏览器语义、键盘行为与触控目标，不等同于原生 AppKit 或 Liquid Glass 实现；未添加无功能的窗口控制按钮。

shadcn 参考官方 [Sidebar 文档](https://ui.shadcn.com/docs/components/sidebar)、[New York Sidebar 实现](https://github.com/shadcn-ui/ui/blob/main/apps/v4/registry/new-york-v4/ui/sidebar.tsx) 和 [Theming](https://ui.shadcn.com/docs/theming)。使用中性表面、圆角矩形和描边层次，通过本仓库 React 19、Crab CSS 与 L1 / L2 / L3 令牌实现；不引入第三方 UI 组件。

2026-10-23 复查补充：窄屏导航复用库内 Drawer 的表面与交互，通过导航专用令牌设定自由边圆角。Material 使用基线 Navigation Drawer 的 16dp 圆角，区别于通用侧面板的形状；macOS 使用 12px 圆角。shadcn 侧边面板对照 [Sheet 文档](https://ui.shadcn.com/docs/components/sheet)与 [New York Sheet 实现](https://github.com/shadcn-ui/ui/blob/main/apps/v4/registry/new-york-v4/ui/sheet.tsx)，保持靠屏幕边缘的直角。实际核对了三套深色导航、当前项、键盘边界和 Escape 关闭，以及窄屏搜索结果与焦点恢复。

本页用于集中核对常用状态。复杂数据表、编辑器、拖拽、移动布局、系统高对比度、减少动态效果及所有尺寸组合仍应结合各组件页与目标浏览器逐项验收；少量截图或自动测试通过不能代表全部组合已符合平台规范。
