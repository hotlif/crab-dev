# 统一尺寸与密度

通过 `ConfigProvider` 的 `size` 设置一组组件的默认尺寸。三个档位调整控件高度、数据行高和部分间距，容器宽度和页面排版仍由应用布局决定。

## 选择设计风格

`design` 在两套风格间切换，`theme` 单独控制浅色或深色，两者都可以在运行时修改：

```tsx
<ConfigProvider design="shadcn" theme="dark" size="middle">
    <Button>保存</Button>
</ConfigProvider>
```

| 风格 | 配色与形状 |
| --- | --- |
| `material` | Material Design 3 的品牌、表面与状态角色，常用按钮保留胶囊形状；组件库未设置 `design` 时的默认风格 |
| `shadcn` | 中性灰阶、圆角矩形按钮与较弱的容器层次；控件圆角 8px，卡片与弹层圆角 12px |

本网站默认显示 shadcn，可在导航中的主题按钮打开外观菜单，分别选择“设计风格”和“明暗模式”。风格偏好会保存在当前浏览器；文档、组件、浮层和工作台演示同步切换。首页能力墙默认跟随全站，也可单独覆盖明暗和品牌色。

两套风格共用 `small`、`middle`、`large` 三档配置，各组件按当前风格决定具体尺寸。切换风格不会修改 `size`；嵌套 `ConfigProvider` 可以只覆盖 `design`，继续继承外层明暗模式、尺寸和品牌色。`brandColor={null}` 恢复当前风格的默认品牌，显式品牌色可以继续覆盖任一风格。

文本字段体现两套风格的结构差异：Material 的 LineEdit 使用 56px 容器，标签在空白、未聚焦时位于字段内，聚焦或有值后浮起；Filled 强调底线，Outlined 为浮动标签保留轮廓缺口。shadcn 独立字段将标签放在输入框上方；在 Form 中使用 `Item labelPlacement="control"` 时，标签在左侧、输入在右侧并保持同排，说明与错误对齐输入列。shadcn 输入框随尺寸档位使用 32 / 36 / 40px。TextEdit 按相同的标签规则呈现，并按多行内容扩展。`theme` 仍独立控制明暗。

## 选择档位

| 档位 | 使用场景 |
| --- | --- |
| `small`（紧凑） | 信息较多的桌面表单、列表和后台工作区 |
| `middle`（标准） | 常规页面；没有配置时的默认值 |
| `large`（宽松） | 需要更宽松的阅读和操作空间 |

按浏览器内的可用空间和操作需求选择。同一块 2K 或 4K 屏幕，在不同系统缩放、浏览器缩放和窗口大小下，可用空间也不同，因此组件不会按物理分辨率自动选择档位。应用可以提供尺寸设置，让用户选择。

切换档位不会等比缩放整个页面。文字和图标仍使用各组件的设计尺寸；窄屏下的换行、分栏和横向滚动需要由布局处理。

## 设置默认尺寸

将需要统一尺寸的内容放进 `ConfigProvider`：

```tsx
import ConfigProvider from '@crab-dev/rc-config-provider';
import Button from '@crab-dev/rc-button';
import Select from '@crab-dev/rc-select';

export default function Example() {
    return (
        <ConfigProvider size="small">
            <Button>查询</Button>
            <Select
                label="任务状态"
                options={[
                    { value: 'pending', label: '待处理' },
                    { value: 'active', label: '处理中' },
                ]}
            />
        </ConfigProvider>
    );
}
```

需要运行时切换时，把所选档位保存在 React state 中，再传给 `ConfigProvider size={size}`。Provider 会渲染一个 `div`，可用 `className` 为这层容器设置布局。样式接入见[开始使用](/guides/getting-started)。

如果应用已经用 ConfigProvider 管理主题，把 `size` 加在同一个根级 Provider 上即可；新增的局部 Provider 会继承它的主题。配置继承规则见[ConfigProvider](/components/rc-config-provider)。

## 覆盖局部尺寸

在同一页面里，可以单独放大一个组件，也可以给一组组件设置另一个档位：

```tsx
<ConfigProvider size="small">
    <Button>继承紧凑尺寸</Button>
    <Button size="large">使用宽松尺寸</Button>
    <ConfigProvider size="middle">
        <Button>使用标准尺寸</Button>
    </ConfigProvider>
</ConfigProvider>
```

优先级从高到低为：组件显式的 `size`、ButtonGroup 等分组的尺寸、最近的 `ConfigProvider`、默认 `middle`。嵌套 Provider 只覆盖传入的配置，其余配置继续继承。

## 基础尺寸

下表为两套风格的基础尺寸，单位为 CSS px。除最后一行外，数值均指高度，不表示宽度。标签、辅助说明、多选标签换行或自定义内容可能增加组件的总高度。

| 项目 | small | middle | large |
| --- | --- | --- | --- |
| 按钮 / 分段按钮视觉高度 | 32 | 36 | 40 |
| Material 单行文本字段 | 56 | 56 | 56 |
| shadcn 单行文本字段 / 现有选择字段 | 32 | 36 | 40 |
| 输入框内操作按钮 | 24 | 28 | 32 |
| 表格数据 / 分组 / 汇总行 | 32 | 40 | 48 |
| 表格表头 / 筛选行 | 36 | 40 | 44 |
| 树节点 / Menu 导航项 | 32 | 36 | 40 |
| Select 选项 | 28 | 32 | 36 |
| 分页按钮 | 32 | 36 | 40 |
| Form 相邻字段行间距 | 6 | 8 | 12 |

常规紧凑控件正文为 14px；Material 文本字段使用 16px 输入文字和 12px 浮动标签，56px 字段为两者分别留出空间。选择字段仍按现有桌面尺寸呈现；多行输入按内容扩展。Switch 的轨道宽高分别为 28×16、32×18、36×20px。

shadcn 风格的常用按钮与输入框采用 8px 圆角，卡片与弹层采用 12px 圆角；Material 风格保留各组件的形状角色与层级。按钮可显式设置 `shape="round"` 或 `shape="circle"`，卡片可显式设置 `variant="outlined"` 或 `variant="elevated"`；这些局部设置在切换风格时继续生效。

shadcn 风格采用无色度的 Neutral 灰阶：浅色使用白色与浅灰表面、深色文字和黑色主操作；深色使用近黑表面与浅色文字。Material 风格保留彩色品牌和色调容器。两套风格都保留反馈状态的语义颜色；需要自定义品牌时，可通过 `ConfigProvider brandColor` 显式设置。

紧凑桌面密度参考 [shadcn/ui Button](https://ui.shadcn.com/docs/components/button) 的简洁比例，是本项目的定制。Material 文本字段单独保留其标签结构与 56px 基础高度；其余组件继续沿用现有 Material 交互语义与状态反馈，紧凑尺寸不作为全部组件符合官方 M3 默认尺寸的声明。

表格的 `getRowHeight`、行 `height`、表头高度，以及 Tree 的 `defaultNodeHeight` 等显式设置会覆盖对应默认值。表中的视觉尺寸也不等于触控目标：例如紧凑按钮和 Select 清除按钮，在粗指针设备上会保留至少 48px 的操作区。

## 适用范围

| 类别 | 跟随配置的方式 |
| --- | --- |
| LineEdit、TextEdit | Material 保留文本字段标签空间，shadcn 使用紧凑尺寸；多行字段按内容扩展 |
| Button、Select、日期时间与 Cron 选择器、分段按钮、分页等控件 | 使用对应的组件尺寸档位 |
| Card、Avatar、Checkbox、Radio、Switch、Tabs、Tag、Spin、Skeleton、ColorPicker、Drawer | 按各组件的尺寸定义调整；不同组件的同名档位不代表相同宽高 |
| Table、TablePro、Tree | 调整默认行高；自定义行高仍优先 |
| Menu、Form | 继承导航项高度或字段间距等密度设置 |
| Badge、Slider | 使用下文说明的特殊映射 |
| Alert、Dialog、通知、提示，以及画布、图表、虚拟列表、分栏和测量容器 | 容器不进行统一比例缩放；内部复用的控件可继承尺寸 |

Badge 的 `large` 对应 `default`；Slider 的 `small` / `middle` 默认对应 `xs`，`large` 对应 `s`。显式设置的按钮、滑块扩展档位继续生效，但它们也使用本库的桌面尺寸。

Tabs、Pagination、Skeleton、ColorPicker、Drawer 兼容原有的 `medium`，其含义与 `middle` 相同。统一配置时使用 `small`、`middle`、`large`。

## 设计依据

三档配置是 Crab UI 的统一尺寸入口，实际数值按组件与风格映射。紧凑尺寸标尺参考 [shadcn/ui Button](https://ui.shadcn.com/docs/components/button) 的 32 / 36 / 40px 和 [Input](https://ui.shadcn.com/docs/components/input) 的 36px；交互语义与状态反馈延续已有 M3 组件。Material 文本字段使用 56px 容器与浮动标签；shadcn 的中性颜色、形状及标签布局通过 L2 风格边界实现，表单使用左侧同排标签，独立字段使用上置标签。其余紧凑尺寸不代表 M3 或 Material 3 Expressive 的官方默认规格。

组件结构、标签空间与触控操作区对照 [M3 文本字段](https://m3.material.io/components/text-fields/specs)、[M3 密度](https://m3.material.io/foundations/layout/grids-spacing/density)、[Material Web 文本字段](https://material-web.dev/components/text-field/)和[按钮](https://material-web.dev/components/button/)。文本字段对照 Material Web 的 [行为与标签实现](https://github.com/material-components/material-web/blob/main/textfield/internal/text-field.ts)、[共享样式](https://github.com/material-components/material-web/blob/main/textfield/internal/_shared.scss)、[Filled 样式](https://github.com/material-components/material-web/blob/main/textfield/internal/_filled-text-field.scss)、[Filled 令牌](https://github.com/material-components/material-web/blob/main/tokens/versions/v0_192/_md-comp-filled-text-field.scss)及[Outlined 令牌](https://github.com/material-components/material-web/blob/main/tokens/versions/v0_192/_md-comp-outlined-text-field.scss)；采用其现有 M3 文本字段变体，不引入 Expressive 新变体。其他实现对照包括 [Material Web 按钮令牌](https://github.com/material-components/material-web/blob/main/tokens/versions/v0_192/_md-comp-filled-button.scss)、[开关令牌](https://github.com/material-components/material-web/blob/main/tokens/versions/v0_192/_md-comp-switch.scss)与 [shadcn/ui 按钮源码](https://github.com/shadcn-ui/ui/blob/main/apps/v4/registry/new-york-v4/ui/button.tsx)。画布、PDF 文档、图表和排版正文保留各自的内容尺寸，不随控件密度等比缩放。

形状调整另对照 [M3 按钮规格](https://m3.material.io/components/buttons/specs)、[Material Web 形状主题](https://material-web.dev/theming/shape/)、[按钮共享样式](https://github.com/material-components/material-web/blob/main/button/internal/_shared.scss)、[描边卡片令牌](https://github.com/material-components/material-web/blob/main/tokens/versions/v0_192/_md-comp-outlined-card.scss)和[对话框样式](https://github.com/material-components/material-web/blob/main/dialog/internal/_dialog.scss)。shadcn 的圆角矩形按钮、稳定的按压形状、描边卡片与 12px 弹层圆角属于本项目的风格定制。

shadcn 中性配色参考 [shadcn/ui Theming](https://ui.shadcn.com/docs/theming) 的 Neutral 主题；Material 保留原有色彩契约，两者都沿用 [Material Web Color](https://material-web.dev/theming/color/) 的表面、前景与交互语义角色配对。
