# Wake 工具链

仓库统一使用 `@crab-dev/wake`，不再维护旧工具链兼容层。

| 任务 | 命令 |
| --- | --- |
| 构建组件库 | `wake library build .` |
| 生成设计令牌 | `wake library token .` |
| 生成 Props 文档 | `wake library docgen .` |
| 运行组件测试 | `wake test --serial --coverage` |
| 启动组件工作台 | `wake docs dev . --mode components` |

Wake 原生输出 ESM、CommonJS、声明与静态 CSS。测试运行在隔离的 Wake DOM 中，模块 mock、时钟和
React 操作均使用 Wake 的显式异步 API。
