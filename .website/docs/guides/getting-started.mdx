# 开始使用

Crab UI 面向 React 19 应用。在 Wake 项目中，按需安装并导入组件即可使用，样式由 Wake 自动加载；组件页提供使用场景、交互示例和 API。

## 安装组件

下面以 Button 为例；使用其他组件时，将包名替换为对应的 `@crab-dev/rc-*`：

```sh
yarn add @crab-dev/rc-button
```

本仓库使用 Yarn Plug'n'Play（PnP）管理依赖，无需创建 `node_modules`。

## 渲染第一个组件

```tsx
import Button from "@crab-dev/rc-button";

export default function SaveAction() {
    return (
        <Button appearance="primary" onClick={() => console.log("saved")}>
            保存
        </Button>
    );
}
```

大多数 UI 包默认导出主组件，附属组件和类型使用具名导入。例如：

```tsx
import Button, { ButtonGroup, type ButtonProps } from "@crab-dev/rc-button";
```

Hooks、令牌和主题等工具包的入口形式不同，请以对应包文档为准。

## 加载静态 CSS

Crab CSS 在构建期生成静态样式，不会向浏览器注入 CSS-in-JS 运行时。

- 使用 Wake 构建时，Wake 会自动发现并加载组件样式，示例无需手写 CSS 副作用导入。
- 使用其他构建器时，需要自行接入静态样式加载；公开样式入口为包内的 `css/index.css`，不能假定其他构建器也具有 Wake 的自动加载能力。
- 不要直接导入包内 `src/`、`esm/`、`cjs/` 或 `declarations/`，这些不是稳定的公共入口。

## 设置主题

需要浅色或深色主题时，安装 CSS-only 的 `@crab-dev/rc-theme`：

```sh
yarn add @crab-dev/rc-theme
```

普通组件随模块引用自动加载样式，但仅声明 CSS-only 主题包依赖不会触发加载。本仓库由 Wake Docs 的 `theme_css` 配置加载公共主题入口，无需在 JavaScript 中导入 CSS：

```toml
# .website/wake.config.toml；路径相对于文档项目根目录。
[docs]
theme_css = "docs/theme.css"
```

`theme_css` 文件必须位于文档项目内。本仓库的 `.website/docs/theme.css` 通过 CSS 引用公共主题：

```css
@import "../../components/rc-theme/css/index.css";
```

默认使用浅色主题。在页面根节点或局部容器设置 `data-theme="dark"` 可切换为深色。
主题选择、持久化和首屏设置由应用负责，详见 [Theme 主题](/components/rc-theme)。

## 跟着教程写代码

组件页先提供最小用法，再逐步加入状态和组合能力。按“动手试试”操作预览，对照“你会看到”检查结果，完成后再切到下一步。每一步可以重置，代码可直接复制。

教学示例中的 `css` 模板需要 Crab CSS 的构建期处理，不能直接在没有对应构建集成的浏览器中执行。最便捷的本地练习方式是在本仓库已有的 Wake 文档环境中修改 `.website/docs/examples/`：

```sh
corepack yarn install --immutable
corepack yarn docs:dev
```

打开组件教程，修改对应的 `step-*.tsx`，页面和展示源码会一起刷新。复制到其他应用时，除了安装源码中的组件包，也要确认该应用已经接入 Crab CSS 编译与静态样式加载；只使用预构建组件本身时则无需编写 `css` 模板。
