## 常见问题

### 为什么有些文字不能修改？

转曲文字、复杂嵌套、裁剪或无法识别 Unicode 的对象保留原样。对象属性会给出原因。

### 没有配置字体可以使用吗？

可以浏览、整理页面、编辑图片，以及变换原文字。修改文字内容和新增文字需要覆盖相应字符的 TTF 字体。

### 文件会上传到服务器吗？

默认不会。PDF 编辑和导出在浏览器的 Worker 中执行；提供 onSave 或 OCR recognize 适配器后，是否上传由宿主实现决定。

### 插件是否内置 OCR 模型？

没有。组件提供跨页选区、PNG 采集、坐标映射与取消信号；使用方通过 recognize 注入浏览器模型或服务端识别接口。
