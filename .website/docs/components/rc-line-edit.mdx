## 常见问题

### 清除按钮为什么不生效？

allowClear 支持受控和非受控模式，清除会触发 onValueChange；受控模式需在 onValueChange 中接受新值，onClear 只用于额外通知。disabled 或 readOnly 时隐藏清除按钮。

### 为什么输入框高度不同？

字段高度由当前设计与 size 决定。通过 ConfigProvider 统一设置，标签始终保留在字段外部；colorMode 独立控制明暗。
