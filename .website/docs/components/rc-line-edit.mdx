## 使用说明

用于单行文本录入，支持前后缀、清除按钮、字数统计和密码可见性切换。


### 何时使用

### 填充、描边与浮动标签

`appearance="filled"` 通过表面色和底线区分输入区域；`appearance="outlined"` 通过轮廓建立边界，也是兼容现有调用的默认外观。`label` 提供自动关联的浮动标签：空值时留在字段内，聚焦或有内容时上移，输入后仍然可见。

`supportingText` 将辅助说明置于字段下方；`errorText` 替换辅助说明、启用错误状态并自动设置描述关联。已有 `aria-describedby` 会保留，计数也会加入关联。调用方仍可显式指定 `aria-invalid`。带标签的 `showCount` 移到辅助信息行，避免挤占输入宽度；无标签的旧调用保持原布局。

`bordered=false` 仍交由宿主绘制边界，此时 label 使用外部标签。未提供新属性的调用继续使用原有 API。M3 Expressive 的色彩、强调排版和分组用于示例页面；文本字段遵循 [Material 文本字段结构](https://material-web.dev/components/text-field/)，不额外发明胶囊或装饰性输入形状。

用于名称、搜索词等单行文本输入。可根据场景配置前后缀、清除按钮、字数统计和密码可见性切换。备注、描述等多行内容请使用 `@crab-dev/rc-text-edit`。

`allowClear` 支持受控和非受控模式，清除会触发标准 `onChange`，`onClear` 仅用于额外通知；使用 `showCount` 时可配合 `maxLength` 显示长度限制。


### 结构与输入边界

标签说明字段名称，placeholder 只给输入示例。前缀表示单位或上下文，后缀动作只影响当前字段。单行输入保留原生横向编辑与选择能力；完整值应能通过聚焦、选择和复制获得，不以 CSS 截断替代编辑内容。

| 场景 | 选择 | 约束 |
| --- | --- | --- |
| 名称、搜索词、短编号 | 普通 LineEdit | 配置可见标签，按业务决定 maxLength |
| 密码核对 | type="password" | 切换按钮改变可见性，值不变；禁用时按钮同步禁用 |
| 已有内容可复制、不能修改 | readOnly | 保留完整文字对比度和键盘聚焦；密码可见性仍可切换 |
| 暂时不可用 | disabled | 输入和内部操作都不激活，原因由相邻说明提供 |
| 需要多行说明 | TextEdit | 不把换行文本压进单行高度 |

### 当前尺寸与状态实现

默认字段使用 Material Design 3 的 56px 高度。显式 size 属性保留较小与较大的变体；数值来自本包 `token.toml`。

| size | 容器最小高度 | 默认字号 / 行高 | 内边距 |
| --- | --- | --- | --- |
| large | 64px | 16px / 24px | 上下 4px、左右 12px |
| middle | 56px | 16px / 24px | 上下 4px、左右 12px |
| small | 48px | 16px / 24px | 上下 0、左右 8px |

高度可随内容和字体设置增长。粗指针下输入区最小高度为 48px，内部动作最小目标为 48×48px，边框仍计入外层尺寸；容器可能高于 48px。鼠标下的内部动作至少 48×48px，小尺寸带动作时也允许容器自然增高，不能裁掉动作焦点。

输入聚焦时，描边型将原有 1px 轮廓向内加粗为 3px，填充型将底线加粗为 3px，不额外叠加外侧焦点框或光晕；错误与 warning 沿用各自的反馈色。无边框模式和系统强制颜色模式保留独立的键盘焦点轮廓。`status="error"` 默认设置 `aria-invalid=true`，显式 `aria-invalid` 优先；warning 不自动宣告无效。错误原因和恢复方法仍需调用方以可见文字提供，并通过 `aria-describedby` 关联。

边框依据：2026-09-23 核对的 [M3 文本框规格](https://m3.material.io/components/text-fields/specs)、[使用指南](https://m3.material.io/components/text-fields/guidelines)、[无障碍说明](https://m3.material.io/components/text-fields/accessibility) 与 [Material Web 示例](https://material-web.dev/components/text-field/)。实现参照 Material Web 提交 `849b4dce` 的 [outlined 样式](https://github.com/material-components/material-web/blob/849b4dce877863752bbfd62f74f52829b2430868/field/internal/_outlined-field.scss)、[filled 样式](https://github.com/material-components/material-web/blob/849b4dce877863752bbfd62f74f52829b2430868/field/internal/_filled-field.scss)、[描边焦点令牌](https://github.com/material-components/material-web/blob/849b4dce877863752bbfd62f74f52829b2430868/tokens/_md-comp-outlined-text-field.scss) 和 [底线焦点令牌](https://github.com/material-components/material-web/blob/849b4dce877863752bbfd62f74f52829b2430868/tokens/_md-comp-filled-text-field.scss)。M3 规格表同时保留旧的 filled focus height 2dp 和新的 thickness 3dp；本实现采用新厚度，与 Material Web 的 3px 覆盖值一致。warning 为本库扩展，沿用相同的边界加粗规则。

内部清除和密码动作复用 Button，具有独立焦点、系统颜色和减少动态效果支持。清除先把焦点还给输入框，再调用 `onClear`；由调用方更新受控值。提供 `id` 时动作关联该 ID，否则组件通过 `useId` 建立关联。

### 组合、误用与验收

- 正例：成员邮箱出错时显示“邮箱格式不完整，请补全 @ 后的域名”，关联输入框；用户仍可继续编辑。
- 反例：只有红色边框。读者不知道原因，非视觉用户也无法获得修正提示；补充可见错误文字及关联。
- 正例：只读项目编号保持可选择、可复制。反例：把所有只读字段都禁用，导致内容被淡化且键盘无法进入。
- `bordered=false` 用于已有容器的复合控件；宿主负责边界和整体分组，输入自身仍保留键盘焦点。避免宿主与输入重复绘制同一焦点轮廓，定制后必须实测。
- 验收：Tab 进入输入和动作；Enter 清除后继续输入；禁用密码按钮不能被 Tab 到达；只读值不能修改；错误和聚焦可以同时辨认；320px 下动作不遮住文本；放大文字后无垂直裁切。

### 适用场景

用户输入一行可编辑文本。 需要前后缀、清除、密码可见性、字符计数或错误提示。

长段落使用 TextEdit，数值使用 NumberEdit，有限选项使用 Select。

### 使用要点

- label 描述字段含义，placeholder 只提供格式示例，不能代替标签。
- 受控 value 与 onChange 配对；defaultValue 只在初始非受控场景使用。
- status、supportingText 和计数要共同说明当前输入是否有效。

### 无障碍

- 使用 useId 关联 label、说明和错误，必填不能只靠星号表达。
- 清除与密码可见按钮要有可访问名称，错误出现后不能让输入焦点丢失。

## 常见问题

### 清除按钮为什么不生效？

allowClear 仅在受控模式下生效。确保 value、onChange 与 onClear 更新同一份状态。
