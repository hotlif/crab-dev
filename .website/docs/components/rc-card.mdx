## 何时使用

- 需要把一组相关信息（标题 / 媒体 / 正文 / 操作）组织为独立、可扫视的单元时
- 列表或网格中的条目需要比表格行更丰富的展示形态时
- 整块内容作为一个导航入口（`clickable`）, 或需要悬浮浮起反馈（`hoverable`）时
- 与 Dialog 的区别是它平铺在页面流中, 不打断上下文; 与 Collapse 的区别是内容常驻可见


## 两种使用形态

**快捷 props**：`title` / `extra` / `cover` / `actions` 描述常规结构, 裸 children 自动落入内容区。

```tsx
<Card title="标题" extra={<Button appearance="link">更多</Button>} actions={[<Button key="ok">确认</Button>]}>
    正文内容
</Card>
```

**自由拼装**：children 中出现 `Card.Cover` / `Card.Header` / `Card.Body` / `Card.Footer`
任一结构子组件时, 卡片切换为自由模式, 区块次序完全由使用方掌控; `Card.Meta` 属于内容
（头像 + 标题 + 描述组合）, 可用于任意模式。

```tsx
<Card hoverable>
    <Card.Header title="标题" />
    <Card.Body>正文</Card.Body>
    <Card.Cover><img src="..." alt="..." /></Card.Cover>
    <Card.Footer><Button>确认</Button></Card.Footer>
</Card>
```
