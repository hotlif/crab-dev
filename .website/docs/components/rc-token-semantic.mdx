## 使用说明

语义设计令牌（L2）将全局基础值映射为品牌色、表面色、文字色、间距、焦点环和动效等界面语义。组件令牌优先引用这一层，主题通过覆盖语义变量改变外观。


### 角色与默认主题

业务样式应消费角色，例如 `token.color.text.primary`、`token.color.brand.primary` 与 `token.color.selection.background`。L1 的 Purple 是原料，L2 才决定浅色品牌用 Purple 40、深色用 Purple 80。旧 CSS 变量名、默认导出、`TokenVars` 与 `vars` 保留。

| 意图 | 背景或主色 | 配套前景 | 使用边界 |
| --- | --- | --- | --- |
| 主要操作 | color.brand.primary | color.text.on-brand | 同时检查 hover / active 背景 |
| 当前选择 | color.selection.background | color.selection.foreground | 同时提供选择标记或 ARIA |
| 阅读容器 | color.background.surface | color.text.primary / secondary | 必要边界用 border.default，装饰分隔用 border.subtle |
| 反馈 | color.feedback 中对应意图的 background / solid | text / on-solid | 不混用容器文字和实心按钮前景 |
| 键盘位置 | color.focus.ring | 与所在表面比较 | 焦点独立于选中和错误 |

```tsx
import { css } from "@crab-dev/css";
import token from "@crab-dev/rc-token-semantic";

const panel = css`
    background: ${token.color.background.surface};
    color: ${token.color.text.primary};
    padding: ${token.space["card-padding"]};
`;
```

### 同一份配对数据与 CSS 主题

`themeColorContract` 是新增的公共只读数据导出，包含 `light`、`dark` 两组配对。它供主题编译、设计参考和契约测试使用，成员是 CSS 引用字符串，读取它不会切换主题或注入样式。

```ts
import { themeColorContract } from "@crab-dev/rc-token-semantic";
import type { ThemeColors } from "@crab-dev/rc-token-semantic";

const light: ThemeColors = themeColorContract.light;
const brand = light.brand.primary; // L1 Purple 40 的 CSS 引用
const onBrand = light.text.onBrand;
```

运行时主题仍使用 `@crab-dev/rc-theme/css/index.css` 与 `data-theme`。TOML 维护无主题样式时的 Light 回退值，`src/theme.ts` 维护完整明暗配对；改变共享角色时，两者必须同步并通过回退一致性测试。业务代码通常只需要默认 `token`，不用在每个组件里读取 `light` / `dark` 再分支。

### 覆盖、迁移与验收

### 从一个颜色生成配对

`createBrandTheme('#1677ff')` 返回 `{ seed, light, dark }`，其中 seed 为标准化六位颜色，light / dark 为品牌相关的 L2 变量映射。颜色统一输出为经过 sRGB 色域收敛的 OKLCh，并检查主色上的文字可读性；中性、反馈与控件轨道色不参与染色。

输入仅支持不透明 `#RGB` / `#RRGGBB`，非法值抛出 RangeError。`normalizeBrandColor(value)` 可独立校验并标准化输入。该函数本身不访问 DOM，也不会插入样式；React 应用通常直接使用 [ConfigProvider 的 brandColor](/components/rc-config-provider)，由 Provider 管理继承和作用域。

### 统一视觉尺度

- small 控件横向内边距为 `space.control-padding-x-small`（8px），middle / large 为 `space.control-padding-x`（12px）。
- 常用大尺寸表单控件使用 16px 字号与 6px 圆角；容器按自身层级保留更大的圆角。
- 卡片和内容分隔使用 `color.border.subtle`；可输入控件保留 `color.border.default` 的辨识度。
- 即时颜色、边框和阴影反馈使用 `motion.interaction`；大范围展开使用独立的 `motion.expand`。

### 验收范围

公共默认品牌本轮从中性灰切换为紫色，焦点从蓝色切换为紫色；站点从私有紫灰表面切换为公共 Zinc 中性表面。颜色 API 名称保持不变，视觉变化需要复测已有业务主题。仅覆盖主色不等于完成主题：主色前景、悬停、按压、链接、选中与焦点必须成组评审。

- L1 修改会影响所有上层引用；业务品牌定制优先覆盖 L2。
- L3 覆盖继续优先于 L2；应检查旧组件覆盖是否遮住新的公共默认。
- Portal 不会继承另一个 DOM 分支的局部变量。浮层根需置于相同主题边界或显式同步 data-theme 与业务覆盖。
- 在 Light、Dark、按压背景、选中底色和反馈容器上检查最终前景；数值测试不能替代键盘与真实浏览器验收。
