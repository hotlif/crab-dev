## 使用说明

在内容加载期间展示布局占位，减少页面跳动。


### 何时使用

- 列表、卡片或详情尚未加载完成，但内容结构已经确定。
- 需要提前保留内容空间，减少加载完成后的布局变化。

占位形状应接近实际内容。无法预估内容结构时，可使用 Spin 提供加载反馈。

### 主要功能

- 支持 `text` / `rect` / `circle` / `button` / `avatar` / `image` 六种常用形状。
- `rows` 控制多行文本占位，末行自动收窄以模拟段落尾部。
- `animation` 在 `pulse`（透明度脉动）与 `wave`（渐变扫过）之间切换；`active=false` 时保留静态底色。
- `width` / `height` 同时支持数字（自动补 `px`）与字符串（如 `"50%"`）。
- `loading=false` 时直接渲染 `children`，便于嵌入到数据驱动的分支里。
- 尊重 `prefers-reduced-motion`，自动禁用非必要动画。

### 适用场景

首屏内容需要等待，且最终结构大致可预测。 卡片、列表或详情加载时希望保持页面几何稳定。

短小、不可预测的任务使用 Spin/Progress；请求失败或空数据必须显示真实状态。

### 使用要点

- 占位数量和形状接近最终内容，但不要伪造不存在的信息。
- loaded 后替换真实内容，容器尺寸尽量保持稳定。
- 动画用于提示进行中，持续时间不确定时不要显示伪造百分比。

### 无障碍

- Skeleton 通常是装饰，应隐藏重复形状并在容器提供简洁加载状态。
- 减少动态效果时关闭闪烁/波纹；完成后清除 busy 状态并避免焦点跳动。

## 常见问题

### 所有加载都用骨架屏吗？

内容结构不确定或只是执行操作时，用 Spin 提供加载反馈。
