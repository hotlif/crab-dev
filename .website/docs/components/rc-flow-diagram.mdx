## 使用说明

基于 `rc-canvas` 的流程图组件，使用 ELK.js 计算布局，并提供正交连线路由。
调用方传入节点和边数据，通过子渲染函数使用布局结果，自定义节点与连线的内容。


### 何时使用

- 展示有向流程图或架构图，并自动计算节点位置。
- 使用正交折线连接节点，或手动指定部分连线路径。
- 拖拽节点、缩放和平移画布，或通过 `fitView` 将内容适配到视口。

### 主要功能

- **ELK 自动布局**：内置 Web Worker + ELK.js，支持 `layered`（层次）、`mrtree`（树形）、`stress`（力导向）等算法。
- **正交边路由**：基于 A\* 的障碍物避让，自动分配端口、生成折线，支持虚线与箭头方向。
- **Render Prop 模式**：`<FlowDiagram>` 提供 `children({ nodeRects, routes, zoom, loading, controls })`，节点 / 边的渲染完全由消费方控制。
- **画布封装**：内部使用 `@crab-dev/rc-canvas`，常规接入无需直接操作 WebGL。
- **节点拖拽**：`FlowNode` 的 `draggable` + `onDrag(dx, dy)` 支持拖拽覆盖布局位置。
- **手动走线**：通过 `manualRoutes` 对单条边指定端口与途经点，其余边仍自动路由。
- **无限网格 + 视口控制**：内置 `InfiniteGrid` 背景网格，支持 `useFlowDiagramControls()` 程序化缩放 / 平移 / fitView。

默认节点、文字、连线和网格使用 L3 语义令牌，随主题变化。`palette` 的部分覆盖只替换指定角色；如需保留旧版固定蓝色配色，可以显式传入导出的 `DEFAULT_FLOW_DIAGRAM_PALETTE`。

### 窄屏查看

**现有示例：** 节点和连线保留二维布局，外层提供有名称、可聚焦的局部横向滚动区域。视口变窄时，可查看完整画布，不把整个文档页面撑宽。

**设计要求：** 局部滚动与图内平移是不同操作。滚动区域获得焦点后可用方向键查看；图内拖拽、缩放和节点编辑仍需各自的键盘替代及状态反馈，不能仅凭外层可聚焦就认定流程图满足全部无障碍要求。


“默认语义色板”省略节点、标签、连线和网格的颜色参数，展示当前设计与明暗模式的默认配色。需要理解显式业务色和特殊边样式时，再查看 FlowEdge 样式示例。

FlowEdge 静态样式和流动动效示例的彩色连线使用品牌、反馈及第三色语义角色，箭头与其连线同步配色，随当前设计和明暗模式解析。节点保留示例的业务色与配对标签前景；虚线、双向箭头及速度说明同时表达差异，不依赖颜色单独传达状态。




### 设计风格与主题

FlowDiagram 组合 Canvas、视口、网格、节点与连线，按 Crab 的流程图扩展维护。Material Design 3 Expressive、Apple 和 shadcn/ui 的来源及固定基线见[三套设计体系](/guides/design-styles)；三体系为其承载表面、前景、边界和选中角色提供独立契约，不定义 ELK 布局或本库的编辑协议。

默认节点填充与标签使用品牌色及其配对前景，描边、连线和网格使用各自的语义角色，通过 FlowDiagram L3 色板传给绘制层。显式节点、标签和连线颜色仍表示业务覆盖；只替换节点填充时，需要同时核对标签前景。默认色板示例与显式业务配色示例应分别查看。

节点尺寸、字体大小、圆角、箭头、路由、拖动、平移和缩放属于领域参数，不由全局控件尺寸统一改写。`loading` / `error` 由渲染上下文提供，调用方应为当前场景呈现状态；局部滚动区可聚焦也不等于图元选择、拖拽和编辑已有完整键盘替代。

色板、布局与领域交互按三体系及浅深色分别验收，覆盖等级以[覆盖矩阵](/guides/design-coverage)及对应候选记录为准。

### 适用场景

流程编排、审批路径或系统拓扑需要可视化关系。 节点数量和关系使普通列表难以理解，但仍需要选择或编辑。

简单线性步骤用有序列表更清楚；大量精确数据比较使用表格或图表。

### 使用要点

- 节点和边都要有稳定 ID，数据模型与屏幕坐标分开保存。
- 自动布局负责初始位置，用户调整后要定义是否覆盖或保留。
- 动画只提示方向或变化，不能成为关系含义的唯一载体。

### 无障碍

- 提供节点列表、连接说明或其他等价文本视图，确保非视觉用户也能理解关系。
- 选择、连接和移动都要有键盘路径，减少动态效果时关闭非必要边动画。

## 常见问题

### 为什么需要文字流程？

流程图不应只靠画布传达业务关系。保留文字步骤，让辅助技术也能读取流程。
