## 常见问题

### 两次采样的时间间隔不同，该如何整理横轴？

横轴按类目等距排列。先按固定间隔生成完整的时间类目，再把各次读数放回对应时段，缺测位置填 null。

### 怎样给读屏用户说明这组数据？

用 aria-label 说明指标和时间范围，用系列名称标明测量对象。组件的数据表使用这些文字，formatValue 可为数值补充单位。
