## 使用说明

展示页面层级，并提供返回上级页面的入口。


### 何时使用

- 页面存在明确层级关系，需要展示当前位置。
- 需要在深层页面中提供快速返回上层路径的入口。

### 主要功能

- 支持通过 `items` 配置导航层级。
- 支持 `separator` 自定义分隔符。
- 支持 `maxCount` 折叠中间层级，避免路径过长。
- 支持每一项配置 `href`、`onClick`、`disabled`。
- `href` 使用链接；仅有 `onClick` 的上级项使用按钮，可通过 Enter / Space 激活。当前位置使用 `aria-current="page"`，禁用项不响应操作。
- 默认导航名称随 `ConfigProvider.locale` 切换中英文；同页存在多条路径时，用 `aria-label` 提供可区分的名称，自定义名称优先。

### 三套风格

面包屑保持链接与当前位置语义，不将路径伪装为一排按钮。Apple 使用较强调的当前项字重；Material 使用 medium；shadcn 使用常规字重。文本、分隔符、焦点和禁用状态随当前浅深色主题切换。

M3 与 Material Web 没有独立的面包屑组件；本组件是依据层级导航和文本角色扩展的 Web 导航能力。参考核对日期：2026-10-22；对照 [shadcn Breadcrumb](https://ui.shadcn.com/docs/components/radix/breadcrumb)及 [Breadcrumb 实现](https://github.com/shadcn-ui/ui/blob/main/apps/v4/registry/new-york-v4/ui/breadcrumb.tsx)，无障碍采用 [WAI-ARIA Breadcrumb pattern](https://www.w3.org/WAI/ARIA/apg/patterns/breadcrumb/)。

### 三体系验收规格

Breadcrumbs 是项目的层级导航扩展，没有直接对应的 M3 组件；它采用 [M3 Accessibility](https://m3.material.io/foundations/accessible-design/overview)的清晰层级与状态原则，Expressive 表现力保留在页面关键动作。Apple 依据 [Navigation and search](https://developer.apple.com/design/human-interface-guidelines/navigation-and-search)的可预测路径原则自主实现；不声称复刻系统路径栏。shadcn 对照清单锁定修订的 [New York V4 Breadcrumb](https://github.com/shadcn-ui/ui/blob/3d98900e9b73c45f035f8109e9d41ba6a51685e7/apps/v4/registry/new-york-v4/ui/breadcrumb.tsx)。核对日期：2026-10-29。

三体系均使用次级文字展示上级路径、主要文字展示当前位置；MD3 与 Apple 通过 `navigation.breadcrumb.current-weight` 保持明确位置，shadcn 保留中性文字层级。原生链接与 Button 动作分别保持语义。路径动作显式映射 Button 的中性文字、透明状态背景和焦点角色，并使用路径文字几何，避免新版动作尺寸撑高整条路径；粗指针仍保留独立命中区域。hover 另有下划线提示，焦点是可见轮廓，禁用与当前位置不可激活。

Breadcrumbs 无公开尺寸，矩阵固定 Provider 为 medium，不虚构三档组件尺寸；三档密度独立改变路径间距。长路径允许折行，分隔符和折叠省略号为装饰，`maxCount` 不产生隐藏的交互菜单。`docs/visual.json` 与 `breadcrumbs.visual.spec.mjs` 覆盖默认、hover、Tab 焦点、按下、禁用、动作与折叠，并断言 `aria-current`。环境场景另检查窄屏、RTL、中英文、触控、品牌、强制颜色与减少动画。尚未采集/复审的范围仍待验收。

路径项间距通过 L3 `root.gap` 引用 L2 `density.gap`，浏览器断言同时核对计算样式和相邻项的实际坐标。修复前该角色错误引用固定的 `space.inline-gap`，三档密度因而没有差异；修复后默认 standard 间距会增加，长路径可能更早折行。既有三档重复截图保留为旧候选，不能作为修复后的密度证据。

### 适用场景

信息结构有两级以上，用户可能从搜索或深链接直接进入内页。 同一内容有稳定的父子层级，并且返回任一上级都合理。

层级很浅或路径只是用户刚才点击过的历史时不必使用；页内步骤流程应使用 Stepper 类模式。

### 使用要点

- 每一项代表信息架构中的真实层级，不要把按钮操作塞进路径。
- 当前页通常不可点击，并通过语义声明为当前位置。
- 空间不足时折叠中间层级，但保留根节点、最近上级和当前页。

### 无障碍

- 整个路径使用有名称的导航区域，当前项标记 aria-current。
- 分隔符应作为装饰隐藏，链接文字要能脱离视觉位置单独理解。
