## 常见问题

### label 与 value 有什么区别？

label 是用户看到的内容；value 是唯一且稳定的字符串标识，不应随显示文案改变。

### 为什么清除后应保存 null？

单选的 null 表示受控空值，undefined 表示由组件维护状态。多选使用空数组。接入受控状态时应保存 onValueChange 返回的值。

### searchable 会请求远程数据吗？

不会。它只过滤传入的 options，当前没有搜索词回调。异步选项由应用加载后传入，loading 仅负责显示加载状态。
