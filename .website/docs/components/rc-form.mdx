## 常见问题

### LineEdit 需要手写事件适配器吗？

LineEdit 使用 Item 默认的 value/onValueChange 适配，不需要额外事件转换。布尔控件使用 adapter="checked"，原生字段使用 native/nativeChecked；复杂接口使用公开 FieldAdapter。标签、必填、帮助、错误、id 与 ARIA 关联必须完整保留。

### 设计体系、明暗和尺寸如何一起设置？

在 ConfigProvider 分别设置当前设计、colorMode、size 与 density。字段采用对应的结构、焦点与视觉角色，尺寸与密度独立，切换配置保留字段值。
