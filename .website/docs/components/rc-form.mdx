### 为什么不能直接使用 DOM onChange？

Form 字段需要值回调；LineEdit 返回输入事件，所以用适配器提取 event.target.value。

## 使用说明

管理字段值、校验规则和提交流程，并为字段布局与错误反馈提供统一结构。


### 何时使用

- 收集用户信息、创建记录或编辑配置。
- 集中管理字段值、校验规则、错误提示和提交结果。

### 无障碍

- 每个字段都使用可见 `<label>`；关联 ID 由 `useId` 生成，不使用占位符代替标签。
- 帮助文本和错误信息通过 `aria-describedby` 关联，错误控件同时设置 `aria-invalid`。
- 必填、格式和范围限制应在提交前说明；错误摘要需要能把焦点带回对应字段。
- 提交期间设置 `aria-busy` 并保留明确反馈，避免仅禁用按钮而没有解释。

更多通用要求见[无障碍使用指南](/guides/accessibility)。
