# Frame 框架布局

`Frame` 是一个用于构建应用主框架的布局组件，通常作为页面的顶层结构使用。它提供统一的布局规范，支持嵌套导航、侧边栏、头部工具栏等内容区域的组织，帮助开发者快速搭建现代 Web 应用的骨架。


## 何时使用

- 搭建后台管理系统的主框架。
- 构建中大型前端应用的统一布局。
- 希望统一页面结构风格、提升开发效率的项目。
- 需要支持侧边栏、顶部导航、可折叠菜单的复杂界面。
