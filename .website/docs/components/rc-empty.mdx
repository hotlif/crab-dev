## 使用说明

为无数据、搜索无结果或无权限的区域提供说明与操作入口。


### 设计理念

空状态应说明当前没有内容的原因，并在适用时提供下一步操作：

- 使用与场景匹配的标题和描述，区分无数据、搜索无结果和无权限。
- 通过 `action` 提供创建内容、调整筛选或申请权限等操作入口。
- 按图示、标题、描述和操作的顺序组织内容。

### 何时使用

- 列表、表格、搜索结果为空时
- 用户没有相应权限时
- 页面或模块首次使用，尚无内容时

### 适用场景

列表第一次为空，需要引导创建内容。 筛选或搜索后没有结果，需要说明如何恢复或调整条件。

仍在加载时使用 Skeleton 或 Spin；请求失败时显示错误原因和重试，而不是伪装成空数据。

### 使用要点

- 标题明确说明“没有什么”，描述解释为什么以及下一步。
- action 只放最可能的恢复动作，例如新建或清除筛选。
- preset 负责常见视觉，custom 用于确有业务意义的插图。

### 无障碍

- 空状态必须包含真实文本，插图应是装饰或有恰当替代文本。
- 从有数据变为空时，焦点不要落在已卸载项目上，并按任务重要程度提供状态通告。
