## 使用说明

为无数据、搜索无结果或无权限的区域提供说明与操作入口。


### 设计理念

空状态应说明当前没有内容的原因，并在适用时提供下一步操作：

- 使用与场景匹配的标题和描述，区分无数据、搜索无结果和无权限。
- 通过 `action` 提供创建内容、调整筛选或申请权限等操作入口。
- 按图示、标题、描述和操作的顺序组织内容。

### 何时使用

- 列表、表格、搜索结果为空时
- 用户没有相应权限时
- 页面或模块首次使用，尚无内容时
