## 使用说明

### 普通按钮

普通按钮使用 Material Outlined：中性文字、细描边、透明背景和胶囊圆角，适合取消、返回、刷新等次要操作。默认与悬停状态均不使用阴影。

基础示例完整展示五种官方外观。实际表单中，可将实色“保存修改”与描边“取消”放在同一操作区，文字“查看说明”作为辅助入口。

```tsx
<Button appearance="primary">保存修改</Button>
<Button>取消</Button>
<Button appearance="text">查看说明</Button>
```

### 外观选择

| appearance | 用途 |
| --- | --- |
| `elevated` | Elevated，浅色表面与阴影，需要从背景中浮起的操作 |
| `primary` | Filled，保存、提交等主要操作 |
| `outlined`（默认） | Outlined，取消、返回等普通操作 |
| `tonal` | Tonal，需要适度强调的次级操作 |
| `text` | Text，说明、展开等轻量入口 |

五种外观对应 [Material 按钮概览](https://m3.material.io/components/buttons/overview)。Elevated 单独提供，使用 Surface container low、Primary 文字和 Level 1 阴影，悬停提升至 Level 2。普通按钮采用当前 [Material 按钮 Specs](https://m3.material.io/components/buttons/specs) 的 On surface variant 文字和 Outline variant 描边；基础尺寸采用 40px 高度、16px 水平内边距、14px 标签文字。

### 尺寸

| size | 高度 | 水平内边距 | 对应 Material 尺寸 |
| --- | --- | --- | --- |
| `xs` / `small` | 32px | 12px | XS |
| `s` / `middle`（默认） | 40px | 16px | S |
| `m` / `large` | 56px | 24px | M |
| `l` | 96px | 48px | L |
| `xl` | 136px | 64px | XL |

提供 M3 Expressive 五档尺寸，并保留现有尺寸属性名作为别名。XS/S/M/L/XL 的图标间距分别为 4/8/8/12/16px，描边宽度为 1/1/1/2/3px。粗指针下通过独立命中区域保证至少 48×48px，不改变可见按钮高度；文字放大可使按钮自然增高。使用 `shape="round"`（默认）或 `shape="square"`。按压时两者变为同一圆角；选中时在圆与方之间切换。

### 状态与无障碍

- 悬停提供 8% 状态层；焦点与按压提供 10% 状态层，颜色跟随对应外观的前景角色；键盘焦点环使用 Secondary、3px 宽度和 2px 外偏移。
- 禁用内容使用 On surface 的 38% 不透明度，填充容器独立使用 10%；描边与文字外观保持各自的容器规则。
- 普通按钮按压时收紧圆角，不移动文字或改变边框宽度。
- `isSelected` 用于可切换操作并同步 `aria-pressed`；描边按钮选中后使用反色填充和更方的圆角。Text 用于普通动作。
- `loading` 显示进度并阻止重复激活，保留焦点；同时设置 `disabled` 时退出键盘顺序。
- 禁用链接也退出 Tab 顺序并阻止激活和导航；图标与加载图形不重复参与按钮的无障碍名称。
- `ButtonGroup` 可统一设置 `appearance`、`size` 和 `danger`，子按钮显式值优先。
- 纯图标按钮需要 `aria-label`；不可逆操作应提供确认或撤销，危险语义同时使用明确文案。

`danger` 表达危险操作，`href` 表达链接行为。它们独立于普通按钮的外观选择。

本组件采用当前 M3 Expressive 的尺寸、颜色与形状令牌。Material Web 的实现仍采用 baseline 按钮（如 24px 水平内边距、18px 图标和 12% 按压状态层），这些差异以当前 M3 Specs 为准。危险操作是 M3 允许的颜色角色定制：Filled 使用 Error / On error，Tonal 使用 Error container / On error container，Elevated 保留 Surface container low。前置单图标为推荐配置；`iconAfter` 为后置图标兼容能力，不应同时设置前后两个图标。

参考：[M3 Specs](https://m3.material.io/components/buttons/specs)、[使用指南](https://m3.material.io/components/buttons/guidelines)、[无障碍](https://m3.material.io/components/buttons/accessibility)、[Material Web 文档与示例](https://material-web.dev/components/button/)、[交互实现](https://github.com/material-components/material-web/blob/main/button/internal/button.ts)、[共享样式](https://github.com/material-components/material-web/blob/main/button/internal/_shared.scss)、[Tonal 令牌](https://github.com/material-components/material-web/blob/main/tokens/_md-comp-filled-tonal-button.scss)。

```tsx
<Button appearance="primary" danger>删除项目</Button>
<Button appearance="text" href="/settings">查看设置</Button>
```

### 适用场景

提交、保存、创建、取消或打开下一步等明确动作。 需要用 Filled、Tonal、Outlined、Elevated 或 Text 区分一组操作的主次。

页面跳转优先使用链接语义；二态设置使用 Switch，可多选条件使用 Checkbox。

### 使用要点

- 一个区域通常只有一个最高强调操作，避免所有按钮都用 primary。
- loading 防止重复提交但仍要说明处理结果；disabled 应有可理解的原因。
- isSelected 只用于真正的可切换动作，普通提交按钮不应伪装成选中状态。

### 无障碍

- 纯图标按钮必须有 aria-label；可见文字应直接描述动作而不是写“确定”。
- 危险操作同时使用明确文案、错误色和必要的确认或撤销机制。

## 常见问题

### 危险操作和链接如何设置？

危险操作设置 danger，并使用“删除项目”等明确文案；导航设置 href，可配合 appearance="text"。它们不再作为独立的常用外观类型。

### 如何比较禁用、加载和选中状态？

查看“禁用状态”“加载中”“选中状态”和“按钮组”示例。加载示例持续显示，方便观察，不发起网络请求。

### 在哪里查看暗黑主题和不同品牌色？

通过文档的主题菜单切换浅色、深色或跟随系统。自定义品牌色的接入方式见 ConfigProvider 与主题文档。

### 旧的按钮外观还能用吗？

subtle 继续可用，并映射为 outlined 描边外观。新代码使用 elevated、primary、tonal、outlined、text 五种公开外观；dashed、link 和 danger 保留旧接口兼容。
