## 使用说明

为 Markdown、MDX 或富文本生成的内容提供统一排版样式。


### 何时使用

- 渲染 Markdown / MDX 内容时，提供一致的排版体验。
- 文章页面、文档页面、博客内容的排版。
- 需要对标题、段落、列表、代码块、表格等元素统一样式。

### 主要功能

- 零运行时，基于 Crab CSS 编译为静态 CSS。
- 支持四种尺寸变体：`sm`、`base`、`lg`、`xl`。
- 支持 `invert` 暗色排版模式。
- 支持 `as` 语义标签：`div`、`article`、`section`、`main`。
- 完整的排版规则覆盖：标题、段落、链接、列表、引用、代码、表格、媒体、定义列表。
- 三层设计令牌架构，支持主题覆写。

### 适用场景

帮助文档、发布说明或富文本内容需要稳定阅读样式。 Markdown 或 CMS 输出需要一层可控的语义排版容器。

表单、仪表盘和紧凑数据界面使用各自组件布局，不要套用文章行高。

### 使用要点

- 使用正确 HTML 语义，让样式跟随 h1、p、ul、code 等结构。
- size 调整整体阅读尺度，但标题层级仍由文档结构决定。
- 表格和代码块要处理窄屏溢出，而不是压缩到不可读。

### 无障碍

- 标题不能跳级，链接文字要描述目标，图片和代码有必要说明。
- 在 200% 缩放、长中文和高对比模式下检查行长、换行和焦点。

## 常见问题

### 直接传 Markdown 字符串会解析吗？

不会。先由 Markdown/MDX 工具解析，再将结果放入 Prose。
