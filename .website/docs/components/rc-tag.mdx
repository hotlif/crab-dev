## 使用说明

标记分类、属性或状态，支持关闭和勾选。


### 何时使用

- 用于标记事物的属性和维度。
- 进行分类和筛选。
- 展示状态信息（成功、警告、错误等）。

预设颜色包括默认、品牌、成功、警告和错误。状态应同时通过文字或图标表达。

### 主要功能

- 支持预设颜色与自定义颜色字符串（如 `#1677ff`）。
- 支持 `icon` 前缀图标。
- 支持 `closable` 与 `onClose` 关闭交互。
- 支持 `closeIcon` 自定义关闭图标。
- 支持 `CheckableTag` 可勾选标签（`checked` / `onChange`）。
