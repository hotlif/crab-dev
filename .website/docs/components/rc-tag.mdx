## 使用说明

标记分类、属性或状态，支持关闭和勾选。


### 何时使用

- 用于标记事物的属性和维度。
- 进行分类和筛选。
- 展示状态信息（成功、警告、错误等）。

预设颜色包括默认、品牌、成功、警告和错误。状态应同时通过文字或图标表达。

### 主要功能

- 支持预设颜色与自定义颜色字符串（如 `#1677ff`）。
- 支持 `icon` 前缀图标。
- 支持 `closable` 与 `onClose` 关闭交互。
- 支持 `closeIcon` 自定义关闭图标。
- `CheckableTag` 对应 Material Filter chip，选中后显示勾选标记并使用 secondary container；多个筛选标签应放在有名称的 toolbar 中。

### 适用场景

记录需要显示类别、属性或简短状态。 用户要移除一个已输入条件，或在一组标签中切换筛选。

主要动作使用 Button；长说明使用正文；大量筛选需要更完整的筛选器。

### 使用要点

- 先决定标签是只读、closable 还是 checkable。
- 自定义颜色要保持文字对比，并避免与反馈色混淆。
- 关闭只移除这一项，业务数据更新和撤销由外层处理。

### 无障碍

- 关闭按钮有“移除 + 标签名”的可访问名称，不能只朗读“关闭”。
- 可选择标签表达 pressed/selected 状态，静态 Tag 不应进入 Tab 顺序。

## 常见问题

### 关闭标签等于删除数据吗？

不一定。onClose 只通知关闭意图，删除业务数据需要另外处理，并提供确认或撤销。
