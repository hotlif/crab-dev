##### 基础用法 — 最基本的树形组件用法，展示节点的展开、收起和选择功能。

##### 全部展开 / 折叠 — 通过 `TreeDataUtil` 提供的 `expandAll` 与 `collapseAll` 方法，一键展开或折叠所有 FOLDER 节点。

##### 显示连接线 — 通过 `showLine` 属性展示树节点之间的连接线。

##### 图标插槽与禁用节点 — 通过 `icon` 字段为节点设置前置图标；`disabled` 字段禁用节点，禁用节点不可点击、不可拖拽、样式置灰。

##### 复选框 checkable — 通过 `checkable` 开启复选框模式。选中父节点自动级联选中所有子节点；取消选中子节点时，父节点自动变为半选状态。`checkedKeys` 与 `onCheckedKeysChange` 实现受控。

##### 搜索过滤 filterTreeNode — 通过 `filterTreeNode` prop 过滤节点。返回 `true` 的节点及其所有祖先节点均会保留显示，其余节点被隐藏。结合展开所有匹配路径，可实现完整的搜索体验。

##### 拖拽排序 — 通过 `draggable` 属性启用拖拽功能，支持节点的拖拽排序和层级调整。

##### 拖拽限制 allowDrop — 通过 `allowDrop` 回调控制节点的放置规则。本示例只允许同级排序：禁止 INSIDE（移入子节点），也禁止跨层级的 DOWN/UPWARD（那样会改变父节点）。

##### 默认节点编辑器 — 使用 Tree 自带编辑器重命名节点，展示提交与取消回调次数。Enter 保存、Escape 取消；输入法组合期间继续输入，键盘结束后由 Tree 恢复焦点。

##### Inline 节点编辑 — 双击节点标题进入 inline 编辑模式。本例通过 renderEditInput 复用 LineEdit，演示字数限制与实时校验。onCommit(value) 提交，onCancel() 取消。

##### 键盘导航 — 点击树组件后可使用键盘操作：`↑↓` 移动焦点，LTR 时 `→` 展开文件夹、`←` 折叠或跳转到父节点；RTL 时左右键交换。`Enter` 选中/取消选中当前节点。

## 常见问题

### 展开和选中为什么要分开？

展开控制可见子节点，选中表示当前操作对象。异步加载时还需要维护节点 loadState。

### 为什么提供树外的操作按钮？

外部按钮演示业务操作如何更新受控的 expandedKeys 和 selectedKeys，不是节点交互的替代入口。关闭拖拽不会禁用节点；Tab 可聚焦树，上下方向键选择节点，左右方向键展开、收起或返回父节点，Enter 切换当前节点的选择状态。只有 node.disabled 为 true 时节点才会被禁用。
