## 常见问题

### 展开和选中为什么要分开？

展开控制可见子节点，选中表示当前操作对象。异步加载时还需要维护节点 loadState。

### 为什么提供树外的操作按钮？

外部按钮展示业务状态驱动展开和选择的方式，并提供明确的键盘入口。当前组件的拖拽节点在未启用拖拽时仍带有 aria-disabled；教程通过按钮完成练习，节点本身的键盘语义仍需组件层后续修复。

## 使用说明

展示层级数据，支持展开、选择、搜索和拖拽。


### 何时使用

用于文件目录、组织架构等层级数据的浏览和管理。通过展开、收起和选择定位节点，并按需启用搜索、复选、行内编辑或拖拽。

### 无障碍

- 为树所在区域提供可见标题，搜索框必须使用 `<label>` 建立可访问名称。
- 保留方向键浏览、Enter 选择和清晰的 `:focus-visible` 焦点环；不要在业务层拦截这些按键。
- 节点标题中的图标只作装饰时应从无障碍树隐藏，加载、禁用、展开和选中状态不能只靠颜色表示。
- 拖拽和右键菜单必须提供键盘可操作的等价入口，并在操作后说明结果。

更多通用要求见[无障碍使用指南](/guides/accessibility)。

### 容器与窄屏

**现有实现：** `width` 和 `height` 接收数值，单位为 CSS px。工作台示例通过 [AutoSizer](/components/rc-auto-sizer) 测量父容器，再传入 `Math.min(width, 示例目标宽度)`；父容器必须允许收缩，不能直接传入 `width="100%"`。多选示例在空间不足时把结果摘要换到下一行。

**设计要求：** 长标题应提供全文获取入口；宽度适配不能替代标题可读性、层级键盘导航及拖拽替代操作的验收。


### 节点数据

通过 `treeData` 传入节点数组。`Node` 类型包含唯一标识 `id`、标题 `title`、父节点 `parent`、节点类型 `type` 和加载状态 `loadState`。

- 根节点的 `parent` 为 `null`，子节点通过 `parent` 建立层级关系。
- `type` 使用 `NodeType`，`loadState` 使用 `LoadStateType`；两者均从组件包具名导出。
- 可通过 `disabled` 禁用节点，通过 `icon` 设置前置图标，通过 `height` 指定节点高度（单位为 px）。
