# Tree

一个多功能且可定制的树形组件，用于 React 应用程序，提供高效的渲染和拖放功能。

##### 复选框 checkable — 通过 `checkable` 开启复选框模式。选中父节点自动级联选中所有子节点；取消选中子节点时，父节点自动变为半选状态。`checkedKeys` 与 `onCheck` 实现受控。

##### 搜索过滤 filterTreeNode — 通过 `filterTreeNode` prop 过滤节点。返回 `true` 的节点及其所有祖先节点均会保留显示，其余节点被隐藏。结合展开所有匹配路径，可实现完整的搜索体验。

##### 拖拽排序 — 通过 `draggable` 属性启用拖拽功能，支持节点的拖拽排序和层级调整。

## 何时使用

例如文件夹、组织架构、生物分类、国家地区等。使用树控件可以完整展现这些层级关系，并提供展开、收起、选择等交互功能。


## 无障碍

- 为树所在区域提供可见标题，搜索框必须使用 `<label>` 建立可访问名称。
- 保留方向键浏览、Enter 选择和清晰的 `:focus-visible` 焦点环；不要在业务层拦截这些按键。
- 节点标题中的图标只作装饰时应从无障碍树隐藏，加载、禁用、展开和选中状态不能只靠颜色表示。
- 拖拽和右键菜单必须提供键盘可操作的等价入口，并在操作后说明结果。

更多通用要求见[无障碍使用指南](/guides/accessibility)。
