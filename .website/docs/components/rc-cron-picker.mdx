## 使用说明

支持五段式 Cron 表达式的可视化编辑、手动输入和执行时间预览。


### 三套主题的计划字段

CronPicker 复用 LineEdit，支持 `label`、`supportingText`、`errorText` 和 `appearance`。MD3 使用浮动标签；Apple 与 shadcn 使用静态标签和各自的桌面焦点环。非法表达式除了错误边框，也显示可见修正说明并关联到输入框，修正后恢复辅助文字。

基础演示增加“执行计划”可见标签，结果说明使用语义文字颜色。面板中的 Select、NumberEdit、Checkbox 和 Tabs 分别继承主题，不改变表达式解析与提交规则。定时规则编辑器是项目组合能力，参考 [Material Web Text field](https://material-web.dev/components/text-field/)和 [Select](https://material-web.dev/components/select/)，没有对应的官方 Cron 组件。核对日期：2026-10-22。

### 何时使用

- 为定时任务、报表或调度策略配置执行周期。
- 通过面板编辑表达式，并查看中文说明与后续执行时间。
- 直接输入表达式；支持月份和星期英文缩写、以 `7` 表示周日，以及 `1,2-5` 等组合写法，提交时规范化输出。

表达式采用五段式，依次表示分、时、日、月、周。`parseCron`、`formatCron`、`describeCron` 和 `nextOccurrences` 均为具名导出的纯函数，可用于独立校验与预览。

表达式输入和生成结果始终按从左到右的语法顺序显示；`direction="rtl"` 只改变面板、字段与操作的布局，不反转 Cron 五段的阅读顺序。动态切换方向保留当前值和面板实例。

### 三体系验收规格

Cron 没有官方 M3、Apple 或 shadcn 对应组件。2026-10-29 的组合规格参考 [Material Web Text field](https://material-web.dev/components/text-field/)、[Tabs](https://material-web.dev/components/tabs/)与 [Select](https://material-web.dev/components/select/)的已有基线；Expressive 规则集中于实际动作，五段式编辑器是本项目桌面扩展。Apple 参考 [Pickers](https://developer.apple.com/design/human-interface-guidelines/pickers)的就近编辑与可预测选项原则；shadcn 对照清单锁定修订的 [New York V4 Tabs](https://github.com/shadcn-ui/ui/blob/3d98900e9b73c45f035f8109e9d41ba6a51685e7/apps/v4/registry/new-york-v4/ui/tabs.tsx)和 [Select](https://github.com/shadcn-ui/ui/blob/3d98900e9b73c45f035f8109e9d41ba6a51685e7/apps/v4/registry/new-york-v4/ui/select.tsx)。

尺寸仅改变字段公开三档，密度独立改变面板分组与选项间距。默认、hover、键盘焦点、按下、禁用、只读查看、警告、非法草稿、合法提交、展开、步进与五字段均列入 `docs/visual.json`。错误必须来自真实输入；非法草稿不会污染已提交规则。只读允许展开查看，面板控件禁用；禁用阻止展开。有限过渡自然结束后截图，预览日期只固定 Date，不暂停计时器或产品动画。

五字段按实际适用方式覆盖每个、固定间隔、连续范围和指定集合；星期不提供固定间隔。数值参数通过真实方向键修改，集合通过空格键选择；星期范围的两个 Select、各类集合的选中反馈以及只读间隔、数值范围和星期范围分别检查，避免只验默认分钟面板便计为编辑器完整覆盖。

`cron-picker.visual.spec.mjs` 使用实际输入、Enter、页签和 Select 进入状态，完整截图保留 Portal 与焦点。环境场景另核对长表达式、320px/768px、触控、RTL、语言、品牌、强制颜色、减少动画和配置切换保持草稿。候选采集与人工复审独立记录，矩阵未完成前不升级设计覆盖。


“只读与填充计划字段”对照可编辑计划与归档计划。只读字段保留聚焦、选择和复制，可展开只读面板查看；filled 字段继续使用同一值协议和校验反馈。




`value/defaultValue/onValueChange(next, details)` 管理表达式，默认 `* * * * *`；受控值和默认值互斥。合法输入提交的原因是 `input`，面板编辑的原因是 `field` 并携带字段名；非法草稿不会对外提交。`open/defaultOpen/onOpenChange` 独立控制面板，外部同步不触发用户操作回调。

面板以完整字段（含标签、辅助与错误说明）定位，保留修正说明的可见空间。手输非法草稿时，输入框保留草稿和错误提示，面板仍展示上一次已提交的合法计划；Enter 不提交非法值，失焦或 Escape 放弃草稿并回退。外部传入非法受控值时，面板使用默认计划兜底，输入保持错误反馈。

`details.event` 透传实际触发提交的事件：手输在 Enter 或失焦提交时携带对应键盘或焦点事件，面板编辑保留下层控件提供的事件对象。下层控件没有提供事件时省略该字段，不创建替代事件；一次提交只触发一次 `onValueChange`。

面板标签、校验说明、执行预览与 ARIA 名称跟随 `locale`。`describeCron(value, locale)` 可独立生成中英文描述，省略语言时使用中文；执行预览使用本地时区。日与周同时限定时按标准 Cron 并集语义计算。

点击输入框或按下方向键展开面板；单独聚焦不会展开。方向键切换字段标签并操作字段控件，Tab 移动焦点。Escape 由共享弹层栈处理：先关闭嵌套选择菜单，再关闭计划面板并恢复输入焦点，每次只通知对应层一次。受控父级继续传入 `open={true}` 时面板保持显示；程序更新 `open` 不产生用户操作回调。

`id`、`name`、`required`、`readOnly` 及 ARIA 关联传递给实际文本输入。使用外部 `<label htmlFor>` 时提供匹配的 `id`；未提供可见或外部标签时，用 `aria-label` 提供名称。只读字段可展开查看，输入和面板控件均不可修改表达式；禁用字段阻止编辑和展开，即使由父级保持面板展开也不能修改。面板限制可用宽度，长表达式换行。

### 适用场景

定时任务需要由非专业用户配置常见周期。 既要提供可视化编辑，也要让高级用户核对表达式。

只有几个固定计划时用 Radio 或 Select；涉及复杂日历例外时应使用专门的日程规则界面。

### 使用要点

- 先确认后端支持的字段数、时区和特殊字符。
- 受控 value 与可读摘要必须同步，不能只显示一串表达式。
- 无效组合要在具体字段附近解释原因，并阻止提交错误规则。

### 无障碍

- 每个分段字段都要有 label、说明和错误关联，分组名称说明当前配置哪一部分。
- 时间与星期不能只用缩写，需提供可读文本并明确时区。

## 常见问题

### 选择规则后任务会执行吗？

不会。组件只编辑表达式；服务端应负责时区、持久化与调度。
