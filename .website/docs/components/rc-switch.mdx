## 使用说明

切换立即生效的开启或关闭状态。


### 何时使用

用于通知开关、功能启停等立即生效的布尔设置。选中状态表示开启，未选中表示关闭。需要先选择、再随表单提交的选项通常使用 Checkbox。

### 视觉状态与验证

切换轨道使用独立的实线焦点环，强制颜色下保留轨道、手柄位置与焦点。立即生效操作如涉及异步保存，应在业务层明确处理中和失败恢复；组件本身不会请求服务器。

`material` 下，`middle`（默认）与 `large` 使用 52×32px 轨道；`small` 保留 28×16px，作为显式紧凑选项。`shadcn` 的 `small` / `middle` / `large` 轨道维持 28×16、32×18、36×20px。

`macos` 的 small / middle / large 轨道为 28×16、36×22、44×26px，手柄分别为 12、18、22px；这组比例保留桌面 mini 与 regular 控件的层级，尺寸为项目的 Web 适配。

三套设计各自定义手柄和状态反馈：MD3 默认未选中手柄 16px、选中 24px、按压 28px，并保留圆形状态层；macOS 使用带轻阴影的白色手柄与蓝色选中轨道；shadcn 使用中性色轨道，选中手柄消费配对前景色。后两者在选中前后保持手柄等大，不叠加 MD3 光晕。浅深色与嵌套风格均通过 L2 变量切换。

`aria-invalid="true"` 给轨道和焦点提供错误色，开启状态同时使用错误填充；应配合 `aria-describedby` 提供具体错误与恢复操作。macOS 是参考 Apple HIG 的 Web 定制，紧凑尺寸为项目适配，不声称复刻 AppKit。

视觉尺寸与命中区独立：所有指针环境下，命中区均至少为 48×48 CSS px；标签使用 14px 正文。

键盘焦点使用公共 L2 焦点角色，通过 L3 覆盖可调整；减少动态效果时移除非必要过渡。实际浏览器应逐项检查 Tab / Shift+Tab、原生激活方式、两种主题、强制颜色、长标签与粗指针布局。当前源码修复与自动检查状态见质量审查记录，不能把 CSS 中存在媒体查询等同于设备验收通过。

### 适用场景

切换后可以立即保存或应用，例如通知、同步、显示选项。 当前值比一次性动作更重要，用户需要随时看到开关状态。

提交表单时才生效的多个选择使用 Checkbox；普通动作使用 Button。

### 使用要点

- checked 与 onChange 构成受控状态，label 不要写“开启/关闭”两套文案。
- 切换失败时恢复真实值并说明原因，不能保持虚假视觉状态。
- disabled 只在确实不可操作时使用，并就近解释限制。

### 无障碍

- 提供与设置含义一致的可访问名称，状态通过 checked 语义表达。
- 标签与开关都可点击，焦点环清楚，RTL 下视觉方向与逻辑含义保持一致。

## 常见问题

### 受控与非受控可以混用吗？

同一实例应选择一种方式。需要业务代码读取或修改状态时，用 checked 和 onChange。
