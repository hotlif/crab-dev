## 常见问题

### 设计体系与明暗模式有什么区别？

designSystem 选择 md3、macos 或 shadcn，colorMode 只接受已解析的 light 或 dark。库、网站和工作台默认 md3/light/medium/standard/zh-CN/ltr。网站跟随系统属于应用偏好，解析后传给 Provider；历史偏好仅在浏览器存储入口迁移。

### 哪些组件会跟随配置？

主题作用于消费语义颜色的后代；按钮、输入框、选择器、表格和树等已接入尺寸配置，详细范围见“统一尺寸与密度”指南。locale 自动切换 Empty 的预置文案，业务文案仍由应用提供。

### Portal 浮层如何继承主题？

将浮层放在主题容器内，或在 Portal 内再包一层无配置属性的 ConfigProvider，从 React Context 继承配置并重建 CSS 边界。
