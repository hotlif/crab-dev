## 使用说明

通过拖拽或键盘调整两侧面板尺寸，支持复位与尺寸记忆。


### 何时使用

- 调整编辑器侧栏、文件树或属性面板的宽度。
- 分配主内容区与控制台、日志区的高度。
- 通过 `persistKey` 记住调整结果，并提供键盘调整路径。

需要两块面板以外的自定义布局时，可直接使用 `@crab-dev/rc-hooks` 的 `useDragResize`。
