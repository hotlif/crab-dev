## 使用说明

通过拖拽或键盘调整两侧面板尺寸，支持复位与尺寸记忆。


### 何时使用

- 调整编辑器侧栏、文件树或属性面板的宽度。
- 分配主内容区与控制台、日志区的高度。
- 通过 `persistKey` 记住调整结果，并提供键盘调整路径。

需要两块面板以外的自定义布局时，可直接使用 `@crab-dev/rc-hooks` 的 `useDragResize`。

### 适用场景

用户需要在两个相关区域之间分配空间。 两个面板需要同时可见，并可能记住用户上次尺寸。

窄屏无法同时容纳内容时改为分步、Tabs 或 Drawer；纯装饰分栏使用 CSS Grid。

### 使用要点

- orientation、primary、min/max 共同决定尺寸计算。
- 拖动过程中限制合法范围，结束后再持久化最终尺寸。
- 内容溢出由各面板处理，不能让分隔条被滚动内容遮住。

### 无障碍

- 分隔条使用 separator 语义并提供当前值、方向键调整和可见焦点。
- 触控命中区可以大于可见线；缩放和窄屏时两个面板仍要可达。

## 常见问题

### 为什么看不到分栏？

父容器必须有明确尺寸；窄屏可以改为上下方向或单列布局。
