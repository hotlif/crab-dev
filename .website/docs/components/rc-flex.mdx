## 常见问题

### 怎样让虚拟目录中的每个条目独占一行？

省略 virtual.itemWidth，每个条目就会占满一行。itemHeight 仍需给出，使组件能把滚动位置换算为可见索引。

### 滚出视口或改变卡片列数后，如何保留条目内的编辑内容？

将编辑状态按稳定的业务 ID 存在列表外，并用相同 ID 作为 getItemKey 的返回值。离开渲染范围的条目会卸载，换列或数据重排时跨行的卡片也可能重新挂载，此时可按 ID 恢复草稿。
