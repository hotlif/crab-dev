## 使用说明

在同一区域切换多个同层级内容面板。


### 何时使用

- 页面需要在同一区域内展示多组相关但可独立查看的内容。
- 需要减少页面切换与滚动，将内容分组组织。

### 主要功能

- 支持 `line` / `card` / `pill` 三种视觉形态。
- 支持 `small` / `medium` / `large` 三档尺寸。
- 支持受控（`activeKey`）与非受控（`defaultActiveKey`）两种用法。
- 支持 `closable` 标签页以及 `onTabClose` 回调。
- 支持 `tabBarExtraContent` 在左右两侧注入自定义内容。
- 支持 `destroyInactiveTabPane` 按需销毁未激活面板。
- 键盘可达：`←` / `→` / `Home` / `End` 切换、`Enter` / `Space` 激活、`Delete` 关闭可关闭项。
- Material 下 `line` 使用主标签页样式：48px 默认高度、24px 行内图标、随标签文字宽度变化的 3px 指示条，以及独立的悬停、聚焦与按压状态层。`small` 为显式紧凑选项。
- `centered` 在标签未溢出时居中。初始化、外部切换、列表变化和尺寸变化时，活动标签会保持可见。
- `card` / `pill` 为业务扩展，保留原有 API，并沿用相同的语义色、状态层与键盘行为。

### 三套风格

默认 `line` 是兼容的 API 名称：Material 呈现带文字下划线指示器的 primary tabs；macOS 使用 2px 轨道内边距和带阴影的选中块；shadcn 使用 muted 容器、3px 内边距和表面色选中块。后两种风格不叠加 Material 的下划线。显式 `card` 与 `pill` 是业务扩展，不宣称为 M3 primary tabs。

选择不同设计只改变 L2 视觉角色；`tablist` / `tab` / `tabpanel` 的关联、禁用项跳过、方向键切换、溢出可见性与关闭操作保持一致。浅色和深色对照演示可直接检查各主题状态。

参考核对日期：2026-10-22。Material 对照 [M3 Guidelines](https://m3.material.io/components/tabs/guidelines)、[Specs](https://m3.material.io/components/tabs/specs)、[Accessibility](https://m3.material.io/components/tabs/accessibility)、[Material Web 文档及示例](https://material-web.dev/components/tabs/)、[Tabs 交互实现](https://github.com/material-components/material-web/blob/main/tabs/internal/tabs.ts)、[Primary tab 样式](https://github.com/material-components/material-web/blob/main/tabs/internal/_primary-tab.scss)和 [v0.192 令牌](https://github.com/material-components/material-web/blob/main/tokens/versions/v0_192/_md-comp-primary-navigation-tab.scss)。macOS 参考 [Apple Segmented controls](https://developer.apple.com/design/human-interface-guidelines/segmented-controls)的页内选择表现；shadcn 对照 [Tabs 文档](https://ui.shadcn.com/docs/components/radix/tabs)与 [New York v4 实现](https://github.com/shadcn-ui/ui/blob/main/apps/v4/registry/new-york-v4/ui/tabs.tsx)。

### 适用场景

少量同级视图共享同一个页面上下文。 用户经常在这些内容之间来回比较，并希望保留当前位置。

不同页面目的地使用主导航；步骤流程使用逐步导航；大量标签考虑 Select 或其他信息架构。

### 使用要点

- 每个 tab key 稳定并对应唯一面板。
- 受控 activeKey 与 onChange 同步路由或业务状态。
- closable/card/pill 是不同视觉或管理能力，先确认是否符合内容层级。

### 无障碍

- 使用 tablist、tab、tabpanel 关系和方向键模型，并管理 roving tabindex。
- 选中指示器、aria-selected 和可见内容同时变化；关闭标签后把焦点放到相邻合理项。

## 常见问题

### 切换后需要清除表单吗？

先决定是否保留未激活面板状态，再选择 destroyInactiveTabPane；不要默认丢弃未保存输入。
