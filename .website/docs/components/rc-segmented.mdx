## 使用说明

以紧凑的分段选项切换视图、时间粒度或筛选值。


### 何时使用

- 快速切换视图、时间粒度或筛选维度。
- 选项较少，且需要在同一区域内直接比较。

Segmented 负责选择值，内容展示由业务代码处理；需要同时管理标签与内容面板时使用 Tabs。通常保持 2–5 个简短选项，选项较多时使用 Select。

采用 M3 基线的单选分段按钮：等宽选项、40px 视觉高度、48px 命中高度、胶囊描边与分隔线。选中项使用次要色容器和勾选图形；文字选项的前置图标由勾选图形替换，仅图标选项则同时保留图标和勾选标记。每个仅图标选项必须提供 `aria-label`。

Tab 进入原生单选组，方向键切换选项，Space 或 Enter 选中当前聚焦项。这是 Web 单选组的键盘模型。此组件保留 M3 基线，不等同于 Expressive 的 connected button group。

### 适用场景

二到五个选项需要快速比较和切换。 选中结果立即改变当前视图或设置，并且选项标签很短。

长标签或大量选项使用 Select；页面级导航使用 Tabs；普通动作不要伪装成选项。

### 使用要点

- options 的 value 稳定唯一，label 描述同一维度下的不同值。
- 受控 value 与 onChange 同步，block 只改变占用宽度。
- 图标是标签的辅助，不能用难懂图标完全替代文字。

### 无障碍

- 根据选择模型提供 radio group 或 toolbar 中 toggle button 的正确语义。
- 方向键、Tab 和选中状态要可预测，焦点不能只靠背景色表现。

## 常见问题

### 为什么没有自动切换内容面板？

Segmented 只管理选值；需要面板关联和标签页语义时使用 Tabs。
