## 使用说明

选择和编辑颜色，支持格式切换、预设色板与透明度调整。


### 三套主题的复合取色

颜色面板复用 Select、LineEdit、Slider 与 Button，格式菜单、颜色值输入和动作随 Apple、MD3、shadcn 的共享主题更新；颜色预览和实际色值不随界面主题改变。演示标签和说明改用语义色，以保证浅色与深色一致。

取色触发器的悬停、按下和键盘焦点分别有独立反馈；禁用触发器保持禁用表面并阻止展开，反馈不改变色值预览。

颜色取值面板没有直接对应的 Material Web 组件，是输入、菜单和滑块的项目组合。参考 [Material Web Text field](https://material-web.dev/components/text-field/)、[Material Web Select](https://material-web.dev/components/select/)与 [shadcn Input](https://ui.shadcn.com/docs/components/input)；具体取色算法、色域和吸管能力属于本库扩展。核对日期：2026-10-22。

### 何时使用

- 为文字、图形或背景选择颜色。
- 通过预设色板限制常用颜色，或通过输入框精确编辑色值。
- 需要切换颜色显示格式或调整透明度。

格式切换只改变显示方式，输出统一为 OKLCh。确定或取消后，焦点返回颜色触发器；取消保留打开前的色值。吸管取色依赖浏览器的 EyeDropper API。

强制颜色模式下，当前颜色预览与预设色块保留作为数据的颜色值。触发器内部色样局部保留 RGB 与 alpha，外围文字、焦点和边框继续使用系统颜色，不把所选颜色替换为系统表面色。触发器色样不增加棋盘格底纹；半透明颜色按实际 Canvas 底色合成，因此看到的是合成结果，不能将它视为不透明原色。

禁用触发器在强制颜色模式下不使用整体透明度淡化数据色，改用 GrayText 边框表达禁用，同时保留 `aria-disabled`、退出 Tab 顺序和禁止展开的行为。非强制颜色模式的禁用外观不变。状态应同时通过控件语义或文字表达，不能仅靠色样区分。



选择器使用互斥的 `value` / `defaultValue`，初始值只在首次挂载读取。`onValueChange(next, details)` 在确认时提交 OKLCh 值，`details.reason` 为 `confirm`；取消和重置草稿不提交。独立 `ColorPickerPanel` 在选择滑块、预设或输入颜色时使用 `reason: 'choose'`。

内置文字与无障碍名称继承 `ConfigProvider.locale`。局部 `locale.overlay` 与 `locale.panel` 逐字段覆盖文字，未提供的字段继续继承全局语言。`size` 只控制触发器尺寸，不调整页面的数据密度。

### 适用场景

主题、标注、图表或内容编辑允许用户自定义颜色。 既需要快速预设，也需要输入精确颜色值。

业务状态色应由设计令牌决定，不应让用户随意选择；只需少量固定主题时使用 Radio 或 Select 更清楚。

### 使用要点

- 明确 value 的颜色格式、透明度和受控更新方式。
- 预设色用于快速选择，文本输入用于精确校正，两者必须保持同步。
- 选择结果要在真实背景上预览，单个色块不能证明可读性。

### 无障碍

- 色块要有可读名称或数值，并提供键盘选择和可见焦点。
- 任何颜色含义都必须有文字、图标或图案补充，同时验证前景背景对比度。
