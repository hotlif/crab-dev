## 使用说明

在元素旁展示计数、更新提醒或状态。


### 何时使用

- 在导航项、头像或图标上展示未读计数。
- 用独立的圆点（`dot`）表达"有更新"但不强调具体数字。
- 以"状态点 + 文字"的形式展示运行、成功、告警等状态。

### 主要功能

- 支持 `count` 数字与 `overflowCount` 溢出显示（默认 `99+`）。
- 支持 `dot` 小圆点模式，适合表达"是否有更新"。
- 支持 `status`（`default` / `processing` / `success` / `warning` / `error`）与 `text` 组合的状态模式；其中 `processing` 带脉冲动画，并遵循 `prefers-reduced-motion`。
- 支持预设语义颜色与任意 CSS 颜色字符串。
- 包裹子节点时角标自动定位到右上角，支持 `offset` 微调。
- `showZero` 控制 `count = 0` 时是否显示。

### 适用场景

图标、头像或导航入口需要显示未读数量。 需要用一个很短的状态标记吸引注意，但不应打断当前任务。

较长状态文字使用 Tag 或正文；需要用户立即处理的错误使用 Alert、Notification 或 Dialog。

### 使用要点

- 数字要设置合理上限，避免大数撑坏目标元素。
- dot 适合只表达有无，count 适合数量本身有意义。
- Badge 应依附清楚的宿主，单独出现通常缺少上下文。

### 无障碍

- 为宿主提供包含数量含义的可访问名称，不能只让读屏读出一个孤立数字。
- 状态变化不要只用颜色表达；频繁更新时避免把每次计数都作为强制通告。

## 常见问题

### 能只用颜色表达状态吗？

不能。使用状态点时应提供 text 或邻近文字，说明状态含义。
