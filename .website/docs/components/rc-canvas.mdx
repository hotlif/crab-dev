## 示例

<div hidden aria-hidden="true" data-docs-search-index="demos">

##### 基础图元 — 在 Canvas 中声明矩形与圆形，颜色支持 OKLCh / 十六进制，opacity 控制透明度。

##### 任意角度直线 — 直线在顶点着色器端挤出为带宽度的四边形，支持任意斜率与线宽。

##### 圆角矩形（SDF） — radius 0 时自动切换到 SDF 着色器，边缘与圆角均为亚像素级抗锯齿。

##### 整体透明度（opacity） — opacity 同时作用于 fill 和 stroke，从 1.0 到 0.1 均匀过渡，Line 的 color 同样受影响。

##### 文字渲染 — 首行文字默认跟随语义主题；其余文字展示显式颜色与图形叠加。文字经 OffscreenCanvas 生成字形位图，在 GPU 端以 alpha mask 着色。

##### 文字对齐与多行 — textAlign（left / center / right）、textBaseline（top / middle / bottom）以及 \\n 换行和 maxWidth 自动词换行的综合演示。

##### HTML 与画布文字对照 — 相同字体、字重和字号下比较 HTML、SDF 与 auto。画布滚轮缩放后，HTML 同步字号；auto 在缩放稳定后更新纹理。

##### 分组变换与嵌套 — Group 维护 TRS 矩阵栈，子孙坐标随父级平移 / 旋转 / 缩放叠加，支持任意层级嵌套。

##### Draggable — Draggable 示例

##### hover 回调 — 通过 onMouseEnter / onMouseLeave 响应图元悬停事件，驱动颜色高亮与状态提示。三种图元均支持该回调。

##### Transformer — 初始视口完整显示三个形状；点击形状后拖拽手柄缩放与旋转，也可平移和缩放画布。

##### 属性驱动动画 — 用 React state 逐帧更新图元 props，Canvas 内部 rAF 渲染循环自动重绘；减少动态效果时暂停属性更新。
