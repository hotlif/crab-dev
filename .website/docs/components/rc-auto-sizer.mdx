## 使用说明

测量容器宽高，并将尺寸传给子组件。


### 何时使用

- 需要将外层容器的实际像素尺寸传入子组件（如虚拟列表的 `viewportWidth` / `viewportHeight`）。
- 需要在容器大小变化时自动重新布局（响应式窗口调整、面板拖拽等场景）。
- 希望组件与具体容器尺寸解耦，只接收数值而非自行测量 DOM。

### 适用场景

子组件必须拿到数字宽高才能布局或虚拟化。 容器会随窗口、侧栏或分栏变化而改变尺寸。

普通 CSS 自适应已经足够时直接使用布局规则，不要为了读取尺寸增加测量链路。

### 使用要点

- 父容器必须先有可计算的尺寸，尤其要明确高度来自哪里。
- render 函数收到的是测量结果，业务组件应直接消费而不是再次测量。
- 尺寸变化可能很频繁，避免在回调中执行与布局无关的昂贵工作。

### 无障碍

- 测量容器不应改变内容的语义顺序或制造额外可聚焦元素。
- 缩放到 200% 和窄屏时仍要确保内容可达，不能因为宽高为零而永久隐藏状态说明。
