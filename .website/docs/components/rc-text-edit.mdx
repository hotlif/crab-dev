## 使用说明

输入多行文本，支持清除、字数统计和内容自适应高度。


### 何时使用

需要用户输入多行文本（备注、描述、评论等）时使用，支持多种尺寸、验证状态、
一键清除、字符计数与内容自适应高度。单行输入请使用 `@crab-dev/rc-line-edit`。


### 选型与结构

文本域用于备注、描述、评论等允许换行的内容。标签明确对象，帮助说明用途和长度限制，计数放在内容之后；清除只作用于本字段。单行名称使用 LineEdit，带格式的编辑器不能仅靠 TextEdit 的纯文本 API 模拟。

| 场景 | 配置 | 边界 |
| --- | --- | --- |
| 稳定的短备注区 | rows | 用户可按默认 vertical 方式增高；周围内容不能被覆盖 |
| 随内容增长 | autoSize | 支持 CSS field-sizing 的浏览器生效，否则以 rows 回退；不同时手动 resize |
| 只可查看和复制 | readOnly | 保留焦点、选择和对比度，隐藏清除 |
| 暂时不可编辑 | disabled | 禁用文本域并隐藏清除；相邻文字说明原因 |
| 清除 | allowClear + onChange | 支持受控和非受控；触发标准值变更并将焦点送回文本域，onClear 仅用于额外通知 |

### 当前排版与状态

size 控制排版与内边距，不控制总高度。三档默认 16px / 24px，上下 4px；large 和 middle 左右 12px，small 左右 8px，来源为本包 `token.toml` 的语义引用。不要把 rows 当成固定像素高度，也不要对包含错误信息的整组字段设置固定高度。

清除动作复用 Button，鼠标下 24×24px、粗指针下 48×48px；文本区常驻预留对应横向空间，按钮出现或消失不改变可用行宽。粗指针下文本域最小高度为 48px。计数与按钮不应遮住末行或滚动条，超长文本保留原生滚动与选择。

`appearance="outlined"` 与 `appearance="filled"` 对应 Material 的两种文本字段；`label`、`supportingText`、`errorText` 会自动建立可见标签和 `aria-describedby` 关联。`errorText` 替换辅助说明并启用错误语义；显式 `aria-invalid` 仍优先，warning 不自动无效。计数位于字段下方的信息区，不占用正文空间，也不会在每个字符变化时强制重复播报。

聚焦时，outlined 将原有 1px 轮廓向内加粗为 3px，filled 将底线加粗为 3px，不额外叠加外框或光晕；错误与 warning 沿用各自的反馈色。无边框模式和系统强制颜色模式保留独立的键盘焦点轮廓。

边框依据：2026-09-23 核对的 [M3 文本字段规格](https://m3.material.io/components/text-fields/specs)、[使用指南](https://m3.material.io/components/text-fields/guidelines)、[无障碍说明](https://m3.material.io/components/text-fields/accessibility) 与 [Material Web 多行字段示例](https://material-web.dev/components/text-field/#textarea)。实现参照 Material Web 提交 `849b4dce` 的 [outlined 样式](https://github.com/material-components/material-web/blob/849b4dce877863752bbfd62f74f52829b2430868/field/internal/_outlined-field.scss)、[filled 样式](https://github.com/material-components/material-web/blob/849b4dce877863752bbfd62f74f52829b2430868/field/internal/_filled-field.scss) 与 [焦点令牌](https://github.com/material-components/material-web/blob/849b4dce877863752bbfd62f74f52829b2430868/tokens/_md-comp-filled-text-field.scss)。采用与 LineEdit 相同的新 3px 焦点厚度；M3 规格表另保留旧的 filled focus height 2dp。warning 为本库扩展，沿用相同的边界加粗规则。

- 正例：备注允许 500 字，先解释用途与上限；服务端失败后保留原文并在附近说明重试方法。
- 反例：提交失败后清空文本。用户必须重新输入；应保留受控值，仅在确认成功后重置。

- 验收：Tab 到达清除动作，Enter 后值清空且焦点在文本域；只读 / 禁用无清除入口；错误与焦点叠加可辨认；320px 和文字放大时计数、清除、长行均不覆盖正文；autoSize 不支持时仍能通过 rows 和原生滚动完成输入。

### 适用场景

用户需要输入可换行的较长文字。 需要字符计数、自动增高、清除或错误说明。

单行名称使用 LineEdit；富文本格式编辑使用专门编辑器。

### 使用要点

- label 说明内容目的，placeholder 给出简短格式提示。
- autoSize 设置合理最小/最大行数，避免输入后无限撑高页面。
- showCount 是反馈，不应替代真实 maxLength 和服务端校验。

### 无障碍

- label、帮助文字、计数和错误都要与 textarea 关联。
- 错误出现和自动增高时保留光标与滚动位置，禁用与只读语义分开。

## 常见问题

### 单行输入能替代吗？

需要保留换行时使用 TextEdit；名称或搜索词等内容使用 LineEdit。
