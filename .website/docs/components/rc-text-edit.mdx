## 常见问题

### 单行输入能替代吗？

需要保留换行时使用 TextEdit；名称或搜索词等内容使用 LineEdit。

### 怎样统一多行字段的外观？

在根级 ConfigProvider 设置当前设计、明暗和尺寸，无需逐个字段覆写样式。rows 或 autoSize 控制内容高度；标签、说明和错误保留各自位置。
