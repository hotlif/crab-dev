# TextEdit

多行文本编辑组件。

## 组件预览

<div hidden aria-hidden="true" data-docs-search-index="demos">

##### 一键清除 — 设置 `allowClear` 后，有内容时右上角出现清除按钮；开启后文本区常驻预留按钮空间，按钮出现或消失不会引起文本回流

##### 高度自适应 — 设置 `autoSize` 后高度随内容自动增长（CSS field-sizing，浏览器不支持时按 `rows` 回退）；开启后手动拖拽调整被禁用，两种高度控制方式不会互相冲突

##### 字符计数 — 设置 `showCount` 后在右下角实时显示已输入字符数；配合 `maxLength` 使用时显示「已输入 / 上限」格式，并在输入层直接阻止超出上限（输入约束前置）

##### 基础用法 — 最基础的多行文本输入；`rows` 控制初始可视行数，右下角可拖拽调整高度

##### 三种尺寸 — `size` 控制内边距与字号排版（large / middle / small），可视高度仍由 `rows` 决定

##### 验证状态 — `status` 设置 error / warning 边框与焦点光环，为表单校验提供即时反馈；请同时配合错误文案与 `aria-invalid` 使用，不要只靠颜色传达状态

## 何时使用

需要用户输入多行文本（备注、描述、评论等）时使用，支持多种尺寸、验证状态、
一键清除、字符计数与内容自适应高度。单行输入请使用 `@crab-dev/rc-line-edit`。
