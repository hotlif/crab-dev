## 使用说明

以水平、垂直或内嵌菜单组织页面与功能导航。


### 何时使用

用于应用顶部或侧边栏导航，通过层级菜单组织页面入口。`mode` 支持 `horizontal`、`vertical` 和 `inline`；垂直与内嵌模式可通过 `inlineCollapsed` 收起为图标栏。
