## 使用说明

以水平、垂直或内嵌菜单组织页面与功能导航。


### 何时使用

用于应用顶部或侧边栏导航，通过层级菜单组织页面入口。`mode` 支持 `horizontal`、`vertical` 和 `inline`；垂直与内嵌模式可通过 `inlineCollapsed` 收起为图标栏。

### 适用场景

应用侧栏或顶部需要组织多个目的地。 入口存在稳定分组或层级，并需要展开、收起和当前项反馈。

临时动作列表使用弹出菜单；同一区域切换少量同级内容使用 Tabs。

### 使用要点

- 每个 item 使用稳定 key，title 是用户可读名称。
- selectedKeys 表示当前位置，openKeys 表示展开层级，两者不是同一状态。
- inlineCollapsed 只改变展示密度，收起后仍要让用户知道图标代表什么。

### 无障碍

- 导航容器提供名称，当前目的地与展开状态都要有语义。
- 支持 Tab 进入、方向键移动和可见焦点；收起图标需要 Tooltip 或等价名称。

## 常见问题

### 菜单会自动切换路由吗？

不会。通过选择回调更新路由或业务状态；不要仅改变高亮却保留旧页面内容。
