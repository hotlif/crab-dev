## 使用说明

从屏幕边缘滑出面板，展示详情或处理辅助任务。


### 何时使用

- 在保留当前页面上下文的同时查看详情或填写表单。
- 临时展示筛选条件、辅助信息或其他侧栏任务。
- 需要从页面边缘展开较大内容区域，关闭后继续原任务。

### 适用场景

用户需要边看列表边处理一条记录的详情。 辅助任务比 Dialog 更长，但还不值得跳转到独立页面。

关键确认使用 Dialog；复杂多步骤流程或需要大量宽度的编辑使用完整页面。

### 使用要点

- placement 由内容关系和阅读方向决定，不要只按视觉喜好选择。
- open 与 onClose 形成受控开合，footer 放稳定的主要和次要动作。
- 嵌套 Drawer 要减少层级并清楚说明返回关系。

### 无障碍

- 打开时移动焦点、限制背景交互并在关闭后恢复焦点。
- 标题、关闭按钮和 Escape 行为都必须可用；窄屏下内容仍应完整滚动。

## 常见问题

### 何时用 Dialog？

短确认通常使用 Dialog；需要更多详情或较长表单时使用 Drawer。
