## 使用说明

通过拖动滑块在指定数值范围内选择值。


### 何时使用

用于音量、亮度或阈值等有明确范围的数值调整，可选择连续值或按步长选择离散值。需要精确键入数值时可使用 NumberEdit。

### 桌面密度

`md3` 使用竖向手柄、轨道间隙与终点标记。`size` 提供 `xs`（默认）、`s`、`m`、`l`、`xl`，轨道高度分别为 4、6、8、12、16px，手柄高度分别为 20、24、28、32、40px。这是保留 Expressive 竖向手柄的项目密度定制，尺寸不等同于官方 Expressive 规格，也不同于 Material Web v0.192 的圆形手柄；粗指针仍提供至少 48px 的纵向操作区域。按压时手柄变细；数值更新立即跟随拖动，不对拖动位置添加延迟。

`apple` 参考 Apple HIG 的线性滑块，采用 8×20px 的浅色窄胶囊手柄、轻阴影、连续细轨道；五档轨道高度为 4 / 4 / 6 / 8 / 10px。`shadcn` 使用 16px 白色圆柄、1px 品牌描边与连续轨道，五档高度为 6 / 6 / 8 / 10 / 12px。两者不显示 MD3 终点标记，按压不把圆柄压成竖线。Apple 尺寸与 shadcn 额外档位是项目 Web 定制。

所有设计共享 `aria-valuenow`、`aria-valuetext`、禁用、错误和键盘焦点能力。焦点轮廓跟随当前手柄；方向键逐步调整，Home / End 到达边界，PageUp / PageDown 调整十步。`dir="rtl"` 将低值放在行首，指针和左右方向键同步反转，上下方向键继续表达增加和减少。

错误状态下轨道与焦点使用错误色，MD3 的实心手柄同步变色；Apple 与 shadcn 保留浅色手柄并显示错误描边。状态演示为每条轨道提供可见标签，并通过 `aria-labelledby` 关联控件。

MD3 禁用状态采用 `on-surface` 中性色：已填充轨道与手柄为 38%，未填充轨道为 12%，避免继续以品牌色表示可用操作。

### 状态契约

`value / defaultValue / onValueChange(next, details)` 管理数值。`details.reason` 区分 `pointer / keyboard / wheel`，并提供对应的原始事件。

受控值与默认值互斥；默认值仅在初始化时使用。外部属性更新不触发操作回调，省略回调可展示只读受控快照。

### 适用场景

音量、亮度、比例等范围值需要快速调整。 min、max 和 step 明确，用户可以根据相对位置做决定。

精确数值输入使用 NumberEdit；少量离散选择使用 Segmented 或 Radio。

### 使用要点

- min、max、step 和 value 必须使用同一单位。
- 受控 value 与 onValueChange 配对，拖动和键盘调整都会通知最新值。
- 标签或值显示帮助用户理解手柄位置代表什么。

### 无障碍

- 提供可访问名称、当前值文字、上下限和键盘增减操作。
- 轨道颜色之外要有可定位手柄与焦点，触控目标大于可见手柄。
