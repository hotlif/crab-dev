## 使用说明

按可见范围渲染列表和网格，减少长列表的 DOM 节点数量。


### 何时使用

用于长列表、日志和大型表格等需要滚动浏览大量条目的场景。组件仅渲染可见范围及预留区域，减少同时挂载的 DOM 节点。

需要跳转到指定行列时，可通过 `scrollToCell` 定位。容器尺寸可配合 AutoSizer 测量。
