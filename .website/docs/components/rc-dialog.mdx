## 何时使用

需要用户处理事务，又不希望跳转页面以致打断工作流程时，可以使用 Dialog 在当前页面正中打开一个浮层，承载相应的操作。

## 无障碍

- 优先传入简洁的 `title`，组件会用它标记对话框；无标题时必须提供 `aria-label`。
- 正文包含关键说明或错误时，使用 `aria-describedby` 指向对应元素，不要把必要信息只放在按钮 tooltip 中。
- 保留 Escape 和取消按钮两条关闭路径；破坏性确认应使用明确的动作名称，例如“删除项目”，而不是“确定”。
- 打开前保存触发器，关闭后将焦点还给它；不要在对话框外继续保留可操作的业务入口。

更多通用要求见[无障碍使用指南](/guides/accessibility)。
