## 使用说明

在当前页面打开模态对话框，承载确认操作或补充信息。


### 何时使用

需要用户确认操作、补充信息或完成短表单，同时保留当前页面上下文时使用。对话框会暂时阻止用户操作页面其他区域，操作完成或取消后应返回原任务。

### 无障碍

- 优先传入简洁的 `title`，组件会用它标记对话框；无标题时必须提供 `aria-label`。
- 正文包含关键说明或错误时，使用 `aria-describedby` 指向对应元素，不要把必要信息只放在按钮 tooltip 中。
- 保留 Escape 和取消按钮两条关闭路径；破坏性确认应使用明确的动作名称，例如“删除项目”，而不是“确定”。
- 顶部关闭入口为可聚焦的 Button，名称沿用 `i18n.cancelText`，与底部取消及 Escape 执行同一个取消回调。不要为了隐藏初始焦点环移除其键盘语义；默认初始焦点可落到此安全入口，业务字段可通过原生 `autoFocus` 明确指定。
- 打开前保存触发器，关闭后将焦点还给它；不要在对话框外继续保留可操作的业务入口。

更多通用要求见[无障碍使用指南](/guides/accessibility)。

需要组合时间选择器等专用面板时，可以通过 `header`、`footer` 替换标题区和操作区。省略属性保留默认布局，传入 `null` 隐藏对应区域。自定义标题区必须通过 `aria-label` 或 `aria-labelledby` 提供对话框名称；自定义操作区由调用方负责确认、取消和 pending 状态，Escape 与遮罩仍经过 `onCancel`。

### 视口、长内容与提交

默认最小宽度为 280px；实际使用时会收敛到视口减去两侧各 16px 的可用宽度。长段落不会自动把对话框撑到整个桌面视口。`useConfirm` 的 22rem 同样受视口约束。长标识符允许换行，内容区域在高度不足时局部滚动；自定义内容、表格和操作标签仍需检查，不能以整页横向滚动代替适配。

默认在视口中央显示，`md3` 容器内边距为 24px，`shadcn` 为 20px。MD3 Expressive 默认操作区使用文字按钮；Apple 与 shadcn 使用填充确认和中性描边取消，主次操作通过 L2 主题角色区分，自定义 `footer` 不受这些默认样式影响。短视口限制内容高度并保留两侧和上下空间。已有 `--dialog-root-min-width`、`--dialog-root-top` 等覆盖仍可使用；显式设置 `--dialog-root-top` 后按指定顶部坐标放置。视口上限为新增约束，原来依赖超出视口宽度的定制需要迁移。

确认或取消请求处理中，发起操作的按钮使用 loading 保留已有焦点，其余动作暂时禁用；Escape 和遮罩同样受 pending 限制。同一渲染批次的连续操作也会被拦截。`onConfirm` / `onCancel` 返回 `false` 时保留对话框和内容；调用方应捕获预期服务端失败、显示就近错误并返回 `false`，不能用未处理的 Promise 拒绝充当错误提示。长请求需定义超时与结果未知的恢复方式。

底部按钮保持 DOM 顺序，空间不足时自然换行，长标签在按钮内部换行；不用固定高按钮裁掉文字。顶部关闭目标为 48px；浮层在强制颜色模式以系统边界线表达表面范围。以上数值仅属于 Dialog 当前实现，不定义全库尺寸。

验收：在 320px 打开确认层，标题和正文完整可读，左右均留有空间；长正文可在层内滚动到操作区；Tab 能到达顶部关闭入口，Enter 可取消；异步确认与取消中焦点保留，连续触发不重复请求，返回 `false` 后继续操作。关闭后回到触发入口。原生模态限制背景页面控件，浏览器自身的地址栏仍可访问；嵌套、软键盘和真实读屏需要单独复核。

Dialog 没有公开 size/density 变体；表面来自 `overlay.dialog.*`，操作继续复用 Button 的公开 TokenVars。不要为模态层新增独立主题。关闭、确认、Escape、焦点锁定和恢复不随设计变化。长内容仅在层内滚动，安全操作可达；错误是调用方正文，使用 alert 或持久说明表达。

`visual.json` 展开三体系浅深色的 default、hover、focus-visible、pressed、long-content、error 及 pending-confirm/pending-cancel，真实打开后采集整个视口，包含遮罩、焦点与完整边界。Firefox / WebKit 默认、键盘焦点、长内容及异步子集在 `crossEngine` 声明。原有异步、重复请求、拒绝关闭与堆叠回归属于默认 DOM 测试，本包没有登记的额外浏览器入口。新增异步原生场景通过真实 Promise 保持处理中，核对发起按钮保留焦点、另一按钮禁用和重复/关闭拦截，保留自然动画帧与视频；实际运行和复审前仍为待验，不用 Button 独立外观代替 Dialog 组合验收。

### 三套设计风格

MD3 Expressive 基础对话框使用 surface-container-high 与 28px 圆角；Apple 使用较紧凑标题、柔和面板阴影和细边界；shadcn 使用中性色表面和清晰描边。三套设计共享焦点保留、Escape、确认及取消行为；Apple 是 Web 适配，不模拟原生窗口标题栏或系统 Liquid Glass。

切换文档站设计风格后，本页演示同步使用该设计；浅色和深色模式分别使用配对语义颜色。

### 配置与展开协议

使用 open / defaultOpen / onOpenChange(next, details) 表达受控、初始值和用户请求。默认值只在初始化时读取，外部配置更新不触发用户回调；details.reason 给出触发原因。内置弹层按 ownerDocument 共享栈，Escape 只作用于顶层。主题、语言、方向和 CSP nonce 沿配置继承，内容尺寸与布局密度独立。

### 适用场景

删除、授权、离开未保存内容等关键决定需要明确确认。 一项短小任务必须先完成或取消，才能回到原页面。

长表单和复杂工作流使用独立页面或 Drawer；非阻塞说明使用 Alert、Notification 或 Tooltip。

### 使用要点

- 标题说明决定对象，正文解释影响，按钮使用具体动作名称。
- 受控 open 决定是否显示，onClose 统一处理取消、Escape 和遮罩等关闭来源。
- 内容过长时保持标题与操作可理解，不要把完整页面塞进小对话框。

### 无障碍

- 打开时把焦点放到合理元素，Tab 留在对话框内，关闭后恢复到触发器。
- 对话框必须有可访问名称；危险确认的默认焦点要经过审慎选择。
