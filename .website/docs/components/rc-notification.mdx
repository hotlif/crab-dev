## 使用说明

在页面角落展示包含详细内容或操作入口的通知。


### 何时使用

- 展示需要标题和详细说明的系统通知或异步任务结果。
- 为通知提供查看详情、重试等后续操作。
- 在页面角落保留通知，同时允许用户继续当前任务。

仅需简短反馈时可使用 Message；必须获得用户确认时使用 Dialog。

### 动画与关闭

通知通过 CSS 过渡从对应边缘进入和退出，进度条使用 CSS 关键帧，不依赖 Motion。系统开启减少动态效果时关闭这些动画，自动关闭仍正常工作。

`useNotification` 在每个方向独立堆叠最多 3 条通知，仅最上层计时。鼠标悬停或通知中的操作获得键盘焦点时暂停，离开后继续剩余时间；`duration={0}` 时保持显示且隐藏倒计时条。关闭后等待退场完成再移除节点。

多条通知以卡片层叠展示：最新一条完整显示，后两层按 96%、92% 缩小，每层露出 8px 边缘，并使用较浅的阴影和区分明暗的表面色。后层暂时隐藏文字和操作，关闭前层后平滑补位，避免多个关闭按钮或正文相互重叠。顶部通知向下叠放，底部通知向上叠放。

通知根节点接受原生 `div` 属性和 `className`。自定义动画通过 CSS 类实现，不再接收 Motion 的 `initial`、`animate`、`exit` 或 `transition` 属性。

关闭按钮使用通知表面的语义前景色，并保留完整的不透明焦点环与悬停、按下反馈，不通过整体透明度降低操作可见性。局部样式通过公开 Button 令牌映射，不改变其他按钮的颜色或行为。



`notification.open({ title, description, duration })` 返回 `{ id, close, update }`。可调用 `handle.close()` 或 `notification.close(handle.id)` 关闭指定通知；调用 update 修改内容或时长会保留 ID 并重新计时。duration=0 时持续展示。onClose 只执行一次，已经关闭的句柄不能重新打开通知。




### 三套设计风格

Apple 使用 16px 圆角的通知面板；MD3 Expressive 使用 12px 内容容器；shadcn 使用 8px 圆角和细描边。通知队列、关闭按钮、键盘焦点暂停和倒计时与主题无关。此组件为持续通知模式扩展，不宣称等同于 MD3 snackbar 或操作系统通知中心。

### 适用场景

后台任务、系统事件或跨页面结果需要较长说明。 用户可以稍后处理，通知中可能包含一个清楚的后续动作。

字段级错误就近显示；必须立即决策使用 Dialog；只有一句确认使用 Message。

### 使用要点

- title 概括事件，description 解释影响和下一步。
- 控制堆叠数量与位置，避免新通知遮住主要任务。
- 使用 hook/holder 让通知继承主题并便于统一销毁。

### 无障碍

- 通知出现时使用合适的 live region，但不要自动抢走键盘焦点。
- 关闭按钮和通知动作要有清楚名称，自动关闭时间应与内容长度匹配。
