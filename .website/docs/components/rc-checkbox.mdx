## 使用说明

从一组选项中选择多个值，或标记单个选项的选中状态。


### 何时使用

- 从多个独立选项中选择一项或多项，例如筛选条件、权限或批量操作对象。
- 标记是否同意条款等布尔值。
- 选项需要随表单一起提交时使用 Checkbox；设置需要立即生效时通常使用 Switch。

### 无障碍

- 将可见选项文字作为 `children` 传入；没有可见文字时必须提供准确的 `aria-label`。
- 一组选项应放在带 `<legend>` 的 `<fieldset>` 中，让组名和每个选项的名称都可被感知。
- `indeterminate` 表示“部分选中”，业务仍需维护明确的 `checked` 状态，不能把它作为第三种提交值。
- 错误说明使用 `aria-describedby` 与控件关联，禁用原因应在附近以文字说明。

更多通用要求见[无障碍使用指南](/guides/accessibility)。

### 视觉状态与验证

视觉以 [Material Design 3 Checkbox](https://m3.material.io/components/checkbox/overview) 为基准：默认方框 18×18px、圆角 2px、描边 2px；未选中为空心轮廓，选中与半选使用品牌填充，并分别显示勾选和横杠。

40×40px 的圆形状态层响应整个标签的悬停、聚焦与按压，透明度分别为 8% / 12% / 12%；粗指针环境下，控件区域扩展到至少 48×48px。禁用透明度为 38%，禁用选中状态保留中性填充与反白标记。颜色引用 L2 语义令牌，自动响应暗黑模式和 ConfigProvider 的品牌色。

保留 Crab 的 `small / middle / large` 扩展：方框分别为 16 / 18 / 20px，状态层统一为 40px；颜色与图标过渡使用公共 `motion.interaction`。状态切换只改变颜色、透明度和图标缩放，固定外框、描边宽度与行内对齐，避免布局跳动。

原生输入负责名称、选中和键盘行为；半选通过 `aria-checked="mixed"` 表达。`aria-invalid="true"` 显示错误色，应同时通过 `aria-describedby` 关联说明。键盘焦点提供独立轮廓，强制颜色使用系统颜色，减少动态效果时移除过渡。图标为常驻的无障碍隐藏装饰，不增加 Tab 停靠点。

规则依据：[状态系统](/guides/accessibility)、[无障碍与键盘](/guides/accessibility)、[布局与密度](/guides/getting-started)。

### 适用场景

用户可以从多个选项中选择任意数量。 需要全选/部分选择父子关系，或接受一项非即时生效的确认。

只能选一个时使用 Radio；设置切换后立即生效时优先使用 Switch。

### 使用要点

- 受控模式由 checked 与 onChange 共同组成，不能只传 checked。
- 组内每项 value 必须稳定且唯一，显示标签应能单独理解。
- 父级 indeterminate 要从子项计算，并在点击后明确转为全选或全不选。

### 无障碍

- 每个框都要与可点击标签关联，整组使用 fieldset/legend 或等价的组名称。
- 错误、必填和禁用原因应通过文字传达，焦点指示不能被容器裁掉。

## 常见问题

### 受控与非受控可以混用吗？

同一实例应选择一种方式。需要业务代码读取或修改状态时，用 checked 和 onChange。
