## 使用说明

显示耗时操作的加载状态，支持延迟显示和区域加载遮罩。


### 何时使用

- 请求或计算需要等待时，显示操作仍在进行。
- 局部区域刷新时，使用包裹模式标记加载范围。
- 内容结构已知时，可使用 Skeleton 保留布局；进度可计算时，应展示明确的进度。

### 延迟显示

`delay` 控制指示器出现前的等待时间，避免短请求导致指示器频繁闪现。例如 `delay={300}` 表示加载持续超过 300 ms 后才显示。

延迟只影响出现时机。`spinning` 变为 `false` 时，指示器立即隐藏。

### 复用 SpinIndicator

`Spin` 提供 `role="status"` 和 `aria-live`。宿主已提供加载语义时，例如按钮已设置 `aria-busy`，可改用具名导出的 `SpinIndicator`，避免重复播报。

`SpinIndicator` 使用 `aria-hidden` 隐藏视觉指示环，加载语义由宿主负责。尺寸与配色可通过 CSS 变量调整：

```tsx
import { css } from '@crab-dev/css';
import { SpinIndicator, vars as spinVars } from '@crab-dev/rc-spin';

// 指示环随宿主字号缩放，并使用宿主前景色。
const style = css`
    --rc-spin-size: 1em;
    ${spinVars['ring.indicator-color']}: currentColor;
    ${spinVars['ring.track-color']}: transparent;
`;
```

`rc-button` 使用 `SpinIndicator`，`rc-table-pro` 使用 `Spin`，共同复用加载指示样式。

### 无障碍

- 使用 `role="status"` 和 `aria-live="polite"` 提供加载状态播报。
- `tip` 提供具体的操作说明；未设置时使用 `label`，默认值为“加载中”。
- 包裹模式为容器设置 `aria-busy`，并通过 `inert` 阻止内容区的指针交互和键盘聚焦。
- 在 `prefers-reduced-motion` 下，将旋转改为低频透明度变化，保留加载反馈。
