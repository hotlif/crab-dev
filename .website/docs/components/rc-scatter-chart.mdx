## 常见问题

### 两条路线的采样里程必须一致吗？

每个点都带有自己的 x 和 y。各系列可以提供不同数量的记录，且可以在任意有限数值处取样。

### 如何从图上打开所选样本的详情？

提供 onPointClick，在回调中读取 point、seriesIndex 和 pointIndex。点击或通过键盘激活数据点即可获得该样本。
