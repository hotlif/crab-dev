## 常见问题

### 如何连接真实保存接口？

保留 validate 与提交反馈，替换 mockSave 的函数体。按服务端返回的字段错误更新 errors；不要把密钥写进浏览器代码。

### 为什么使用确定性的失败开关？

同样的操作始终得到相同结果，便于练习、回归检查和排查问题。刷新或重置示例会恢复初始状态。
