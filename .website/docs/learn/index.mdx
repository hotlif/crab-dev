# 把组件组合成业务页面

三个实战按复杂度递进。每个实战都有四个可独立运行的步骤，你可以直接切到想学习的部分，也可以从第一步跟着完成。

<PracticeGallery />

## 怎么跟着做

1. 阅读当前步骤的目标与修改原因，再操作预览。
2. 展开完整代码，复制到自己的 React 页面，安装代码中引用的组件包。
3. 对照“你会看到”检查结果，然后进入下一步。
4. 遇到不熟悉的属性，回到对应组件的教程和 API。

代码从真实运行的示例文件读取，包含导入与样式入口。示例里的属性调整按钮也属于完整代码，不需要安装隐藏的演示辅助包。

## 模拟数据说明

请求结果由操作决定，固定等待 600 ms，不使用随机失败。资料表单可以模拟保存失败；数据列表可以模拟失败、空数据并重试。后台页面只更新当前示例内存。重置当前示例或切换步骤会恢复该步骤的初始状态。

每个模拟函数或本地保存逻辑旁都标有“业务接入位置”。接入后端时替换这些位置，并保留加载、错误与空状态的展示。
