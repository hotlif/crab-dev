# 数据展示

> **规范状态：设计要求与既有能力映射。** 工作台提供搜索、选择和分页样板；本页排序、跨页选择与批量恢复规则仍需在具体业务中落实。

数据展示首先帮助用户判断“这是什么、当前怎么样、下一步做什么”。企业界面应优先保证比较、定位和核对的效率；视觉装饰不能改变数值的含义，也不能让次要指标占据主要任务的空间。

## 选择合适的展示方式

| 方式 | 适用任务 | 不适用的情况 |
| --- | --- | --- |
| 表格 Table | 多条记录拥有相同字段，需要逐行核对、跨行比较或批量选择 | 内容结构差异很大，或每条记录主要是一段长文 |
| 卡片 Card | 展示一个对象的摘要、独立分组或包含少量操作的内容单元 | 为每一个普通字段单独包一张卡片，造成过度分隔 |
| 标签 Tag | 表达状态、类别或已选条件；文字与状态图形共同传达含义 | 将静态标签绘制成按钮却没有操作，或只用颜色编码 |
| 徽标 Badge | 在对象附近提示数量或新增内容 | 承载长句、重要错误详情或未经定义的数字 |
| 空状态 Empty | 明确数据区域没有可展示的记录，并提供下一步 | 代替加载失败、权限不足或仍在加载的状态 |

指标卡用于概览，不代替完整数据。指标必须提供名称、数值、单位和统计范围；涉及趋势时说明比较周期。没有可靠数据来源时不显示百分比趋势，也不把随机变化作为“实时”反馈。

## 表格结构与信息顺序

一张完整的业务表格由标题与范围说明、查询工具栏、列标题、数据行、状态区域和分页区域组成。批量操作靠近选择结果，分页与结果总数靠近表格底部。

| 部位 | 必须表达的信息 | 布局要求 |
| --- | --- | --- |
| 标题 | 对象类型，例如“项目台账” | 靠近查询区域，避免重复页面标题 |
| 工具栏 | 搜索范围、当前筛选条件、必要操作 | 标签常驻；窄屏按阅读顺序换行 |
| 列标题 | 字段名称、共用单位；排序能力存在时展示方向 | 不把只有鼠标悬停才能看到的图标作为唯一提示 |
| 数据行 | 对象身份、状态、数值、更新时间等 | 最重要的识别字段在前，操作靠近对应行 |
| 选择摘要 | 已选择多少项，以及选择作用范围 | 明确“当前页”与“所有筛选结果”的区别 |
| 页脚 | 结果数、页码、翻页操作 | 查询变化后回到有效页，不能停留在不存在的页码 |

### 对齐、数字与缺失值

文本默认左对齐，金额和需要比较的数值右对齐，并使用等宽数字。相同列的小数位与单位规则保持一致；不要在同一列混用“元”和“万元”却不注明。日期使用一致的格式，并在时间精度对业务有意义时说明时区。

零是有效值，不等于缺失。“—”可以表示暂无数据，但应在列说明或上下文中解释；“不适用”与“未填写”应分别表达。标识符、账号和版本号不按普通数字添加千位分隔。

### 密度与行高

标准模式的数据行目标高 44px，紧凑模式为 36px；触控环境的交互目标至少 44px。行内文本应保持完整基线和可读行距，不应仅靠缩小字号增加行数。需要多行内容时允许行高增长，不能用固定高度裁掉重要字段。

表头与行的边界主要组织阅读，属于装饰分隔线。复选框、输入框、焦点指示等操作所需边界按至少 3:1 校验，不能因表格整体采用细线而降低。

## 查询、排序与选择

搜索框应说明匹配字段。多个筛选条件默认取交集；若产品采用并集，应在界面中直接解释。清空搜索只清除搜索词；“重置筛选”清除全部查询条件，两者不可混淆。

排序必须说明当前字段与方向，排序变化不能让键盘焦点突然消失。金额按数值、日期按实际日期排序；不能把显示字符串的字典顺序当作业务顺序。当前工作台样板展示搜索、筛选、选择与分页，排序是后续业务接入规则。

### 选择范围

- 当前页全选只影响可见页的记录；跨页全选需要额外明确的入口和总数说明。
- 筛选、翻页后保留或清空选择必须有统一策略。当前样板采用清空策略，避免隐藏选中项。
- 批量操作前显示对象数量。无法处理的记录必须说明原因，不能静默跳过并报告全部成功。
- 如果数据刷新后记录已不存在，应同步移除失效选择，并向用户解释变化。

## 加载、空结果与错误

首次加载在数据区域提供进度说明；局部刷新可保留旧内容，但必须说明内容正在更新，避免将旧值误认为最新结果。加载期间保留查询上下文。

“没有记录”提供创建或了解规则的入口；“没有符合条件的结果”提供修改条件或重置入口；“无法读取数据”提供重试及原因说明。三者不能共用一个模糊的“暂无数据”。

## 小屏与无障碍

宽表格可以在自身容器中横向滚动，页面整体不得溢出。对象识别字段不应为了省空间被无提示截断；截断时提供可用键盘到达的完整内容入口。固定列与固定表头不能遮挡聚焦单元格。

应使用组件已有的表格语义和键盘模型，不自行把每个单元格都加入 Tab 顺序。行内复选框要能识别其对应对象；排序变化、查询结果数与选择数应有适度的状态播报，避免每次输入都重复朗读整张表。

## 使用禁例与验收

| 避免 | 应采用 |
| --- | --- |
| 只显示一个绿色圆点 | “进行中”等文字配合状态图形 |
| 总数不变，却不说明指标是否跟随筛选 | 明确区分全局概览与当前查询结果数 |
| 翻页后保留不可见选择且没有摘要 | 明确的选择范围和清理策略 |
| 用卡片列表无条件替代表格 | 根据比较任务选择布局，保留必要字段 |
| 隐藏横向内容且没有滚动入口 | 独立滚动容器和完整内容访问方式 |

验收时至少检查：零值和空值、长名称、大金额、不同状态、第一页与最后一页、筛选后结果减少、全部选中与取消选择、加载失败重试，以及 320px 宽度下的区域内滚动。

## 表格、树、卡片和图表的进一步选型

| 阅读目标 | 优先结构 | 必须补充的信息 |
| --- | --- | --- |
| 同字段逐行核对 | Table | 稳定列名、单位、对象身份 |
| 父子关系与层级定位 | Tree，或具有明确树形能力的数据表 | 展开关系、层级、选择范围 |
| 异质内容与对象摘要 | Card | 对象标题、关键属性和相关动作 |
| 一眼了解规模 | 指标摘要 | 名称、数值、单位、周期、统计范围 |
| 比较分类或趋势 | 适合数据关系的图表 | 图例、坐标含义、直接标签或数据替代 |

图表不能代替精确核对，树不能仅为了视觉缩进而代替普通列表。BarChart 等现有图表能力以组件文档为准，本章不承诺新的图表类型。颜色编码按[色彩](/design/color)，数值格式按[排版](/design/typography)。

## 列、行与操作边界

列设计依次确定字段含义、排序方式、对齐、单位、完整值入口和最小阅读条件。对象标识优先，状态与关键比较值靠近，操作列说明具体动作。没有交互的单元格不应全部显示 pointer；行可点击时，复选框、链接和菜单不能同时触发行点击。

单行高度采用样板密度目标，多行内容需要增长或独立详情入口。固定行高只适合已知内容结构，不能以虚拟滚动为由裁掉必要错误。调整列宽时保留对关键字段的访问；列隐藏不能变成权限控制。

固定列用于保留识别或高频操作，数量应受可见比较空间约束。窄屏固定列覆盖所有中间列时，减少固定范围或调整展示结构。粘性表头、工具栏和分页不能遮住当前聚焦单元格，参照[布局](/design/layout)验收。

## 查询、排序和计数的契约

| 项目 | 设计必须说明 | 错误风险 |
| --- | --- | --- |
| 搜索 | 匹配哪些字段，是否与其他条件取交集 | 用户把无结果误认成没有数据 |
| 排序 | 字段、方向、空值顺序和作用范围 | 仅当前页排序被误认成全结果排序 |
| 多字段排序 | 优先级及清除方式 | 多个箭头但不知道哪个先比较 |
| 总数 | 全量、筛选后或当前页数量 | 指标和分页计数相互矛盾 |
| 数据更新 | 当前结果对应的查询和更新时间 | 旧响应覆盖新条件 |

生产全结果排序必须在分页前或由服务端以相同语义完成；不能把当前页展示字符串排序称为整个集合排序。相等值应具有稳定后续顺序，避免翻页重复或遗漏。具体空值顺序和多字段能力由业务契约确定并写入页面设计记录，当前样板没有排序演示。

## 选择范围与批量结果

当前页全选、所有筛选结果全选、显式跨页选择是不同策略。界面应在选择时就写明范围；跨页全选要有独立且可撤销的选择动作。稳定记录标识用于选择，不能以行号作为对象身份。

| 范围变化 | 规范要求 | 当前样板 |
| --- | --- | --- |
| 翻页 | 明确保留或清除，并同步摘要 | 清空选择 |
| 修改筛选 | 新结果与旧选择关系可见 | 清空并回到第一页 |
| 刷新记录 | 核对失效项与权限变化 | 未接入真实刷新 |
| 批量部分成功 | 分别列出成功、失败和不可处理范围 | 未提供批量操作 |
| 对象删除 | 更新计数和有效页码 | 属于后续业务规则 |

批量结果不能只显示“操作成功”。部分失败时保留失败项的处理入口，明确重试只作用于哪些项。对于异步任务，用“已提交”与“已完成”区分阶段；高风险操作的确认见[操作按钮](/design/actions)。

## 场景样本与验收

**正例**：预算列按数值排序，标题显示方向；“当前页已选 3 项”与确认范围一致。**反例**：第一页按格式化金额字符串排序，下一页顺序不同，用户误以为已经按全部预算排序。修正应先保证排序范围与数据类型正确。

构造零记录、一记录、刚好一页、多一条、最后一页、重复名称、未知金额和长文本。检查筛选后总数减少、选择失效、请求失败和数据更新时，计数、页码、状态与内容一致。键盘能访问行内操作、完整值和局部滚动，强制颜色下排序、选择与错误仍能辨认。
