# 导航与定位

> **落实状态：文档站已实现顶部栏目、设计章节侧栏与移动导航。** 本页同时规定其他业务页面迁移时应遵守的导航语义。

## 导航层级

| 层级 | 回答的问题 | 常见形式 |
| --- | --- | --- |
| 栏目 | 我在产品的哪个部分 | 顶部主导航 |
| 页面 | 这个栏目有哪些任务或章节 | 左侧导航或菜单 |
| 页内视图 | 同一对象有哪些并列视角 | Tabs 或分段选择 |
| 内容位置 | 当前长页面的哪一部分 | 页内目录、锚点 |
| 上级关系 | 这个对象从哪里进入 | 面包屑 |
| 数据范围 | 目前展示结果的哪一段 | 分页 |

先确定层级，再选择组件。分页不是页面目录，Tabs 也不是多步骤向导。菜单分组展开只改变目录可见性，不应该直接切换正文。

## 共用顶部与栏目侧栏

顶部在栏目间保持相同身份、顺序和入口。进入设计语言后，侧栏显示设计分类；进入组件与指南后，显示对应文档目录。不要让用户每切一个栏目都重新寻找返回按钮。

设计目录按“开始使用、视觉基础、交互规则、组件规范、业务模式、实施与维护”分组。分组名称说明主题，页面名称说明内容。当前页面使用明确的 current 语义，分组展开使用 expanded 语义；两者不是同一种状态。

## 链接与地址

独立页面应拥有稳定地址，支持刷新、书签、复制链接和浏览器前进后退。普通点击可使用站内路由，Ctrl / Cmd 点击等修饰键应保留浏览器默认行为。

页内目录使用真实锚点。页面跳转与锚点跳转完成后，目标标题应可见且可被合理聚焦；不能滚到固定页头后面。目录中的标题与正文标题保持一致，不让用户猜测对应关系。

## Tabs 与分段选择

Tabs 用于同一上下文中的并列内容，如“概览、成员、设置”。每个标签应可预测其内容；不要把破坏性动作放进标签位置。切换是否保留未保存输入，需要根据页面任务明确规定。

分段选择适合少量互斥选项，如主题和密度。标签长度应相近，选中状态清楚。选项过多、说明过长或需要分组时，应使用其他合适的选择方式，而不是把一整排分段控件挤到不可读。

## 手机导航

屏幕变窄时，可把侧栏放进导航抽屉，但当前栏目和打开入口仍需可见。抽屉标题说明目录范围；打开后焦点进入抽屉，选择页面后关闭并聚焦正文标题。

顶部仍保留栏目切换入口，因此设计目录里不必混入项目和组件分类。返回原栏目后恢复对应目录，不把设计目录的展开状态当成全站筛选条件。

## 空、禁用和权限状态

导航项暂不可用但对用户有明确预期时，可保留禁用项并说明条件；完全不适用的能力可以不显示。没有权限的页面不能只靠隐藏菜单保护访问，实际权限仍由业务层处理。

删除当前对象或失去访问权限后，应跳转到仍存在的合理位置并说明结果。不要保留一个高亮但无法访问的“当前页”，让用户陷入无法恢复的空白。

## 验收与禁例

- 目录分组可展开和收起，当前页高亮不会被 hover 覆盖。
- 键盘顺序与视觉顺序一致，收起区域不再接收键盘焦点。
- 刷新、深链接、前进后退和修饰键点击行为正常。
- 手机选择页面后，抽屉关闭，标题不被固定顶部遮挡。
- 避免一个控件同时切页、筛选和提交，也避免使用没有地址的文本容器模拟页面链接。

## 导航元素的结构

导航项包含目的地名称、可选图标、当前位置或展开线索；分组标题表达分类，不能同时暗含独立页面跳转。确需“进入页面”和“展开子项”两种动作时，分别设置明确控制，不让点击同一位置产生不确定结果。

| 元素 | 表达的状态 | 不能混用 |
| --- | --- | --- |
| 当前页面 | current 与稳定的选中线索 | 不等于指针悬停或目录展开 |
| 展开的分组 | expanded 与可见子项 | 展开不表示已经进入其中页面 |
| 当前 Tabs 面板 | selected 与关联面板 | 不等于浏览器路由已经变化 |
| 分段值 | 互斥设置的当前值 | 不等于多步骤任务进度 |
| 当前页码 | 数据集合的当前分段 | 不等于章节层级或对象身份 |

尺寸、间距与触控目标统一见[布局](/design/layout)。导航标签不为对齐而任意缩写；长名称可以换行或提供完整名称入口，不能把所有项目都截成难以区分的前几个字。

## 从信息关系选择组件

主导航用于稳定栏目，侧栏用于栏目内目的地；面包屑表达层级而非完整浏览历史。进入同一对象的概览与设置可用 Tabs，改变同一数据视图的呈现模式可用 Segmented，浏览不同记录段使用 Pagination。

当前 Crab Tabs 的水平键盘处理包括左右、Home、End，并随目标激活；这不代表支持纵向模式或可配置的手动激活。新业务若需要网络加载后才切换面板，应先核对能力并记录差距，不能在文档中发明属性。模式说明见[无障碍与键盘](/design/accessibility)。

## 导航生命周期与状态保留

| 操作 | 预期结果 | 需要保留或处理 |
| --- | --- | --- |
| 进入独立页面 | 地址与正文一致 | 标题、当前位置和可用返回路径 |
| 展开分组 | 只改变目录可见性 | 当前页仍有归属，不额外提交 |
| 跳转锚点 | 指向可见正文标题 | 固定页头不遮挡目标 |
| 切换视图 | 呈现所选内容 | 明确草稿、筛选和滚动是否保留 |
| 返回历史 | 恢复对应目的地 | 不能只恢复地址而留在旧正文 |
| 删除当前对象 | 转到有效列表或后继 | 说明对象已删除，不留死页面 |

用户离开有未保存修改的视图时，按[复杂表单](/design/forms)处理；不能只在抽屉关闭时保护草稿，切标签或切页面却无声丢弃。当前样板没有全局离开拦截，生产接入需单独实现并验证。

分页改变数据范围时同时更新结果和页码；筛选减少结果后应落到有效页。若业务将筛选和页码写入 URL，应明确深链接、刷新与返回行为；本章规定一致性目标，不要求当前本地样板新增地址状态。

## 手机、键盘与权限

移动导航打开后焦点进入，取消关闭恢复触发器，选择页面后转到新正文。选择后不能把焦点恢复到旧页的目录项，导致读屏继续报告旧上下文。收起分组的内部项不可成为透明焦点目标。

顶部、侧栏与页内目录分别有清楚名称，辅助技术能区分它们。普通文档导航不因看起来像菜单就自动使用应用菜单键盘模型；优先保留链接语义和自然 Tab 顺序。

权限不足的入口根据任务决定隐藏或禁用，但访问校验仍由业务负责。权限变化后若当前目标不可访问，说明变化并提供有效返回路径，不自动将用户送往无关栏目。不存在页面与暂时加载失败要分别处理，不能都显示空白导航壳。

## 正反例与路径验收

**正例**：分组箭头只展开目录，章节文字进入独立地址；当前页高亮始终保留。**反例**：点击分组既展开又切页，手机抽屉关闭后正文和地址不一致。修正为单一明确动作和可靠路由结果。

从直接打开深链接开始，依次测试刷新、前进后退、修饰键点击、目录折叠、锚点跳转和手机选页。每一步核对地址、标题、current/selected/expanded、焦点位置及可见内容。两种主题都需区分当前项与 hover，窄屏入口不隐藏，长目录可以滚动到最后一项。
