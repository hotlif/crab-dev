# 动效与过渡

> **落实状态：复用现有语义动效令牌。** 页面和样板不新增弹簧、涟漪或动态取色效果；以下规则用于统一交互节奏和迁移验收。

## 动效需要解释什么

每个动画都应说明一个变化：动作已被接受、内容正在出现、容器展开了，或用户正在等待处理。不能解释变化的动画应优先移除。高频后台操作应让用户迅速继续工作，而不是等待界面完成表演。

颜色过渡适合悬停、按压和选中；透明度适合临时内容出现；容器展开适合导航分组和补充信息。不要把所有状态变化统一做成缩放弹跳。

## 动效令牌

| 语义令牌 | 当前时长 | 当前曲线 | 适用场景 |
| --- | --- | --- | --- |
| motion.interaction | 150ms | easing.out | 颜色、选中、悬停等即时反馈 |
| motion.fade | 200ms | easing.out | 内容淡入淡出 |
| motion.expand | 300ms | easing.out | 容器展开与收起 |
| 减少动态效果 | 移除非必要过渡 | 无 | 保留最终状态和任务反馈 |

以上时长来自现有全局 duration 与语义 motion 映射。使用语义令牌，不在页面里复制一串新的毫秒值。数据保存延迟、请求超时和动画时长是不同概念，不能用动画延迟模拟真实业务进度。

## 即时交互

悬停和按压应立即开始反馈。用户快速离开、再次进入或连续点击时，动画应能从当前状态自然过渡，不排队播放旧动作。

焦点必须在进入控件时立即可见，不能等待渐显完成才出现。禁用态不能保留 hover 动画，加载中也不能继续暗示“再点一次会更快”。

## 出现、消失与焦点

打开抽屉时，内容、标题和关闭入口构成同一个任务层。焦点进入浮层；关闭后返回触发点或逻辑上的后继位置。退出动画不能让已关闭的控件继续响应键盘。

收起导航分组时，收起区域应立即退出键盘顺序，再完成视觉动画。展开完成前也不能让透明但可点击的内容挡住其他操作。

## 加载与不确定等待

预计超过约 400ms 的操作应提供可感知的处理中反馈，例如按钮加载、局部 spinner 或内容骨架。动画只说明“正在处理”，不能编造确定进度。没有可信进度时，不显示虚假的百分比。

保留容器尺寸和已有输入，避免加载状态导致按钮和表格上下跳动。请求失败时结束加载反馈，给出恢复路径；不能让旋转图标永久替代错误处理。

## 减少动态效果

检测到减少动态效果偏好后，移除非必要位移、缩放、滚动动画和过渡。最终的选中、展开、错误和保存结果仍必须出现。即使 spinner 停止转动，也应保留“保存中”等文本与 busy 语义。

这不是简单把所有元素隐藏：删除动画不能删除状态。组件需要退出清理时，必须在无动画路径下同样正确释放焦点与监听。

## 推荐与禁例

- 推荐：围绕用户动作选择一个主要过渡，保留清楚的起点和终点。
- 推荐：快速连续切换、取消、重试和减少动态效果时检查中断行为。
- 避免：用长动画延迟按钮可用时间，或让焦点环缓慢浮现。
- 避免：错误提示摇晃整张表单、多个卡片同时上下浮动。
- 避免：用位置跳动或边框变粗作为默认点击反馈。

## 动效规格如何记录

每个过渡记录触发条件、起止状态、参与属性、时长、缓动、中断方式和无动画结果。只写“加一点动效”无法实施；视频也不能代替焦点与关闭时机说明。

| 情形 | 建议参与属性 | 不应参与的变化 |
| --- | --- | --- |
| 按钮悬停、选中 | 前景、背景、边界颜色 | 字号、边框宽度、控件高度 |
| 展开补充内容 | 容器展开与必要透明度 | 无关区域同时位移 |
| 打开临时任务层 | 与来源相符的位移或淡入 | 大幅弹跳掩盖内容 |
| 状态更新 | 就近出现说明，必要时淡入 | 强制滚动到远处提示 |
| 不定等待 | 局部加载反馈 | 伪造确定百分比 |

不要使用 transition: all 包含不可预期的几何属性。用户切换密度时也不应等待所有数据行逐个播放尺寸动画。

## 通用令牌与组件实现的区别

| 来源 | 当前实现 | 适用范围 |
| --- | --- | --- |
| motion.interaction | 150ms，easing.out | 通用快速视觉过渡 |
| motion.fade / expand | 200ms / 300ms，easing.out | 通用淡入和展开角色 |
| Dialog 内容与遮罩 | 进入 200ms，退出 150ms | 当前组件 JavaScript 动画 |
| Drawer 内容 | 进入 300ms，退出 200ms | 当前组件 JavaScript 动画 |
| Drawer 遮罩 | 进入与退出均 200ms | 当前遮罩实现 |
| 成员资料模拟保存 | 650ms 延迟 | 异步演示，不是动效规格 |

Dialog / Drawer 当前进入曲线为 cubic-bezier(0,0,0.2,1)，退出为 cubic-bezier(0.4,0,1,1)，由组件内配置给出；不能称为所有进退场都读取同一个语义令牌。统一实现属于后续迁移，本轮仅准确记录，来源见[令牌与实施](/design/tokens)。

## 中断、连续操作与关闭生命周期

### 跟随最后一次有效意图

快速悬停与移开不排队回放；展开未结束就收起，最终必须为收起，旧动画回调不能重新展开。页面跳转或组件卸载后，不把焦点移回已消失的触发器。

### 关闭分为请求、退出和清理

关闭请求可能因未保存修改被拦截；接受关闭后限制重复操作，退出结束再完成必要清理。模态约束在浮层仍可见时保持，不能先释放背景交互再播放遮罩动画。

当前 Dialog / Drawer 保留退出过程，结束后再关闭原生 dialog 并释放资源。导航折叠则需及时让隐藏内容退出键盘路径。两者不能机械套用“立即卸载”。

### 无动画也要完成清理

减少动态效果路径必须运行同样的关闭、滚动恢复、状态播报和监听清理。不得因没有 transitionend 而永远不完成关闭。当前组件显式读取媒体偏好，各具体组件仍需单独验收。

**正例**：未保存确认拦截关闭，继续编辑后草稿仍在；无动画路径呈现相同结果。**反例**：先卸载表单，播放退出动画后才提示未保存，重新打开已经丢失输入。修正必须先判断关闭是否允许。

## 动作验收表

| 验收动作 | 通过条件 |
| --- | --- |
| 快速进入、离开按钮 | 反馈与当前指针状态一致 |
| 展开中立即收起 | 最终收起且不可被 Tab 访问 |
| 关闭后立即再次打开 | 新任务不会被旧回调关闭 |
| 保存失败后重试 | 加载与结果属于当前请求 |
| 动画中改变窗口宽度 | 内容和关闭入口不越界 |
| 开启减少动态效果 | 无非必要运动，反馈与清理仍成立 |

记录浏览器实际媒体偏好，不为录到动画覆盖用户设置；比较两条路径时使用明确的测试环境。样板没有覆盖的中断组合标为待验收。
