# 图标与信息表达

> **规范状态：设计规则。** 样板使用现有组件图标和文字状态标记；本轮不引入新的图标库或字体文件，不宣称所有已有图标已经完成统一迁移。

## 图标的职责

图标用于快速识别熟悉动作、说明方向和辅助判断状态。它不能替代用户尚未学会的业务术语。专业工具中的“归档”“撤销”“提交审批”应先有清楚文案，再决定是否增加图标。

同一个含义在同一产品内使用同一图形。相似图形也不能分别表示“删除”“关闭”和“取消”；这些动作的后果不同，必须保持明确区别。

## 尺寸与笔画

| 项目 | 基准 | 使用规则 |
| --- | --- | --- |
| 常规图标 | 16px | 输入前后缀、行内操作、短标签 |
| 强调图标 | 20px | 工具栏或需要更明显辨识的操作 |
| 笔画 | 1.5px | 统一端点与连接方式，避免不同粗细混搭 |
| 图标与文字间距 | 4 / 8px | 选择一种适合控件尺寸的现有间距刻度 |
| 独立图标操作 | 目标至少 44px（触控） | 图形尺寸与实际命中范围分别定义 |

图标按光学中心与文字对齐，而不是只对齐 SVG 的外框。箭头、加号和细线图形需要在低像素密度屏幕检查清晰度。不要拉伸宽高比，或把一套 24px 图标任意压缩成细节不可辨的 12px。

## 图形与语义的对应

| 意图 | 推荐表达 | 需要避免的歧义 |
| --- | --- | --- |
| 展开与收起 | 箭头方向与内容展开方向一致 | 图标旋转了，内容却没有变化 |
| 搜索 | 搜索图标配字段标签或搜索按钮 | 把筛选漏斗当搜索 |
| 清除输入 | 输入内清除标记，并提供“清除…”名称 | 与关闭整个页面的图标混淆 |
| 返回 | 回到上一层任务的方向图形或文字 | 与撤销编辑共用同一个入口 |
| 成功 / 错误 | 图形加明确状态文字 | 只有绿色勾或红色点 |
| 外部跳转 | 必要时标明将打开外部目标 | 所有链接都加无意义装饰箭头 |

方向图标应符合语言与布局方向。中文界面按当前从左到右的阅读方式组织；如果未来支持从右到左语言，应整体评审方向性图标，不能只翻转文字。

## 图标按钮的名称与提示

独立图标按钮必须具有可访问名称，例如“关闭成员编辑”“清除搜索条件”。名称应包含对象，避免整页出现多个无法区分的“关闭”。有可见文字时，可访问名称应保留该文字的核心含义。

工具提示可以解释快捷键或补充说明，但不是唯一标签。键盘聚焦与触控用户也必须能理解操作；只在鼠标悬停后出现的解释不足以支撑高风险动作。

装饰图标应从辅助技术的阅读内容中排除。状态图标如果旁边已有完整状态文字，应避免重复朗读“成功，成功”。

## 状态与颜色

图标与相邻文字可以共用语义色。禁用图标取消可点击光标与悬停强调；加载图标配合加载文案，不能让用户误以为仍可重复点击。

必要图形与相邻背景至少满足 3:1。图标采用半透明色时，应检查混合后的实际结果。强制颜色模式下，关键轮廓和文字仍应保留。

## 验收清单

- 删除图标后，标签和信息结构仍能说明核心任务。
- 所有独立图标操作都有唯一且可理解的名称。
- 图标、文字、方向键与展开方向一致。
- 默认、悬停、禁用、选中和暗黑状态均可辨识。
- 触控目标至少 44px，实际点击区域不小于视觉区域。
- 没有仅靠颜色表达的重要状态，也没有只能悬停发现的关键操作。

## 图标类型与结构

一个图标需同时定义图形框、实际笔画范围、视觉中心和命中区域。16px 图形不等于 16px 按钮；透明空白也不能作为实际交互范围的唯一证据。上表 16/20px 与 1.5px 笔画是设计基准，尚不是全库图标已统一的声明。已有组件应先核对自身令牌与资源，不机械改写所有 SVG。

| 类型 | 作用 | 标签与交互规则 |
| --- | --- | --- |
| 动作图标 | 添加、编辑、删除、下载 | 有动作名称，命中范围与按钮一致 |
| 方向图标 | 展开、返回、上一页、下一页 | 与内容方向、键盘方向相符 |
| 状态图标 | 错误、完成、等待、警告 | 配合状态文字，静态状态不伪装为按钮 |
| 对象图标 | 文件、团队、目录 | 补充对象识别，不替代独有名称 |
| 装饰图形 | 品牌或说明的视觉辅助 | 不进入 Tab 顺序，不制造无意义朗读 |

同组图标应有相同视觉重量、端点和连接方式。若用实心表达选中，应在同一控件体系保持稳定，并仍有选择语义；不能随意在不同业务页切换实心和线形含义。

## 图文排列与完整名称

前置图标通常解释动作或对象，后置图标通常解释展开、外部跳转或额外状态。一个按钮不应在两侧放置意思相近的两个箭头。4/8px 图文间距选取见[布局与密度](/design/layout)，不要每页微调一个新值。

多行文本旁图标应与第一行或整个信息单元明确对齐；不能随着第二行出现而漂到两组内容之间。错误图标靠近错误文本，不贴到下一字段。紧凑模式优先减少容器留白，不能无限压缩笔画。

图标按钮名称以“动作＋对象”为默认结构，例如“编辑项目海蓝设计系统”。列表中的名称应能区分对象；上下文已清楚时，也不要把整行无关信息拼进名称。Tooltip 只是补充，按钮自身仍须有名称。

## 图标状态与替换规则

| 变化 | 必须保留 | 需要检查 |
| --- | --- | --- |
| 未选 → 已选 | 对象与动作含义 | 图形变化不成为唯一选择线索 |
| 展开 → 收起 | 相同控制目标 | 箭头与实际内容同步 |
| 动作 → 加载 | 操作名称和按钮空间 | 替换不挤走文字或重复触发 |
| 可用 → 禁用 | 不可用原因 | 不继续呈现可点击悬停 |
| 浅色 → 深色 | 相同图形语义 | 必要轮廓在当前表面可辨 |

“✓”“◐”等是现有样板的辅助状态标记，字形随系统字体变化，不能据此宣称已经建立统一图标资产库。重要状态始终保留完整文字，避免字体缺字导致信息消失。

## 方向、歧义与替代

关闭只关闭当前层，删除改变对象存在性，取消终止操作；三者不能共用相同位置和不加说明的叉号。返回上级与撤销上次修改也需不同语义。仅在有必要时提示外部目标，不给普通站内链接增加外部跳转暗示。

未来支持 RTL 时，对方向箭头整体评审；品牌、数字、时钟和非方向性图形不能全量镜像。此为扩展设计要求，本轮不声明已经提供 RTL 支持。

**正例**：行内编辑图标有对象名称，聚焦时轮廓可见，触控命中区扩大且不重叠。**反例**：三个无名称小图标表示关闭、删除和取消，只能悬停试探。修正为明确标签或带名称的独立操作，高风险动作提供可见文字。

专项验收包含两行文本、低像素密度显示、深色浮层、键盘、触控和强制颜色。通过条件为无图形歧义、无重叠点击区、名称可区分、笔画未裁切；未统一的旧图标登记迁移差距。
