# 文档分类侧栏

将“开始、组件、实战、工具”从页面链接改为真正的分类按钮。分类按钮只控制侧栏，不修改地址、正文或示例状态；文档条目仍使用真实链接并保留部署前缀、修饰键和新标签页行为。首页与 GitHub 保持页面链接。

分类从 Wake 的现有导航数据划分，不另维护一套文档清单：

- 开始：开始使用、无障碍指南。
- 组件：组件目录与原有组件子分类，保留展开状态与当前文档标记。
- 实战：实战概览及三个完整案例。
- 工具：开发工具文档。

桌面重复点击当前分类可以收起侧栏。首页与组件目录也可以直接显示侧栏。手机抽屉内使用同一分类状态：切换分类保持抽屉打开，选择具体文档后才导航并关闭。
