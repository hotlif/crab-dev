# 文档站：Material 官网参考优化

## 参考与检查

对照 [Material 首页](https://m3.material.io/) 和 [Radio 概览](https://m3.material.io/components/radio-button/overview) 的实际浏览器页面。参考其导航轨、宽阔标题区、圆角表面、组件示意与章节组织；保留 Crab 的中文文档、真实 React 示例和源码入口。视觉质量以交付后的可读性、可操作性与布局验证评估，不将“更好”写作未经用户评估的客观结论。

检查发现：原站点的顶部导航与分类侧栏重复，组件页缺少稳定的章节入口；首页装饰没有展示组件，目录图示与标题的层次较弱。窄屏搜索的自动网格列会被结果内容撑宽。

## 本次改动

- 桌面站点导航轨承接首页、开始、组件、实战与工具；窄屏保留导航抽屉、搜索与主题。组件目录与首页不再显示分类侧栏，给视觉内容留出空间。
- 全部文档页使用统一标题区；组件页加入跟随滚动的章节锚点，保留原始 URL、部署前缀和完整正文。锚点导航没有冒用 tab 的切换语义。
- 首页用 Button、Radio、Slider 三个可点击组件入口替代装饰轨道；目录改为图示在上、用途在下的圆角卡片。保持语义颜色及其配对前景。
- 统一页尾上一篇与下一篇，保留组件工作台、教程、API、源码和移动导航。不恢复设计语言页面。
- 修复移动搜索结果网格的内容最小宽度，中文首页快速入口不拆字换行。

主要源码：`documentNavigation.tsx`、`documentStyles.ts`、`ui.tsx`、`learningHome.tsx`、`homeStyles.ts`、`componentCatalog.tsx`、`catalogStyles.ts`、`siteStyles.ts`。Radio 的局部标题样式归入公共页面标题规范。
