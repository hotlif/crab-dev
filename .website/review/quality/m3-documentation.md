# M3 文档站对照复查

2026-09-21。本记录以本次实现为准，替代此前缩小标题、移除展示图、将目录放在标题之前的方案。

## 发现的问题与修复

- 旧版把“本页内容”放在标题上方，或与正文并排挤占宽度。现在采用官网宽屏的双栏标题 / 展示图、主要分区、正文与右侧目录布局；正文可用宽度不足 1200px 时，目录移到正文之前并保持可见。
- 恢复 M3 网站展示型标题：宽屏 88px / 96px、标题容器 56px 内边距和 24px 圆角，双栏头图最小高度 544px，与同尺寸官网测量一致。正文容器最大 1200px，目录与正文共用对齐轴；随可用宽度调整标题、留白和代码区域。
- 组件页复用已有组件目录中的 SVG 示意图，使用主题令牌构成展示背景；限制图形最大宽度，避免宽屏图形被裁切。
- 具有对应内容的组件文档使用“概览 / 使用指南 / API / 更多示例”四个主要入口。它们是连续文档的锚点链接，全部章节仍在下方目录中；没有把十余个章节塞进横向滚动条。
- 桌面保留用户要求的常驻侧栏：88px 主导航 + 240px 二级目录，正文预留空间，目录全高并内部滚动。重复点击、Escape 和页面跳转均不收起。
- 二级导航采用 48px 单行条目、圆角选中状态；中文名称优先显示，完整中英文名称保留在无障碍名称及 title 提示中，避免包名挤掉实际用途。
- 首页只高亮首页，避免常驻的“开始使用”目录导致两个主导航项同时填充选中。
- 手机保留导航抽屉，正文目录不折叠；分区入口在小屏显示为图标加文字，锚点预留吸顶区域。

## 保留的差异与检查边界

- 遵从用户偏好，桌面目录始终显示；官网在较窄桌面可以浮动展开二级导航，本站始终预留目录空间，因此双栏断点按正文可用宽度判断。
- 保留 Crab 品牌令牌、Roboto 与中文回退字体、自己的组件示意图和文档内容；未复制 Google 品牌字体、图片与视频。
- 四个主要入口跳转连续文档，保留搜索、浏览器查找和已有深链接；官网使用独立文章分区。
- 强制颜色、减少动效保留显式 CSS 适配，本次未模拟系统设置。253 个独立演示没有逐一穷举所有控件状态。
