# 按钮简化与文档密度调整

用户在 MD3 默认视觉升级后要求页面稍紧凑，并减少按钮类型。本轮保留 Material 的用途色彩、胶囊形状与状态反馈，按新的密度要求调整按钮及文档站。

## 实现

- 常用外观收敛为 `primary`（主要）、`subtle`（普通、默认）、`text`（文字）。基础示例、尺寸对照、状态对照和基础工作台使用相同的三类选择。
- 新增 `danger` 属性，与三类外观组合；ButtonGroup 可继承，子按钮的显式值优先。导航继续通过 `href` 表达。
- `tonal`、`outlined`、`dashed`、`link`、`danger` 旧值仍可调用并保留外观和覆盖入口；迁移说明折叠展示。`ButtonAppearance` 表达三类常用外观，`LegacyButtonAppearance` 表达兼容类型。
- small / middle / large 高度为 32 / 36 / 40px，水平内边距为 12 / 16 / 20px。默认 middle；粗指针目标仍至少 48×48px，文字行高可使按钮自然增高。
- 文档导航与搜索入口为 48px，桌面正文内边距为 24px，常规预览舞台为 24px 内边距、160px 最小高度；减少章节间留白。
- 新增危险操作前景与状态配色 L3 令牌，复用错误色语义；按钮选中填充仅在非强制颜色模式下生效，让系统选中颜色保持优先。

## 影响范围

Button / ButtonGroup、L2 的 36px 尺寸别名、按钮教程与工作台、文档公共样式。其他控件尺寸保持上一轮设置。Wake / Crab CSS 仍为 `0.1.45`，无依赖、版本或发布变化。

上一轮 [MD3 验收记录](../md3-standard/README.md) 记录的是调整前产物，不能作为本轮按钮尺寸与文档布局的验收证据。
