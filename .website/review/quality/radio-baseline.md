# Radio 选中状态的行内基线修复

日期：2026-09-18。Wake / Crab CSS 0.1.45。

## 复现与原因

在生产文档的「基础用法」独立 Radio 示例中，选中前圆框 y=49.5px、标签 y=47px；选中后分别变为 53.25px、50.75px，整体下移 3.75px。圆框始终为 16×16px，问题并非描边宽度变化。

原圆点仅在选中时挂载，作为圆框内的 Flex 子项参与基线计算；外层 inline-flex 默认使用 baseline 对齐。圆点出现后改变行内基线及父级行框，造成圆框和文字一起移动。RadioGroup 的 Flex 排列会掩盖该问题，因此独立场景必须单独检查。

## 修复

- 圆点常驻、绝对定位，不参与基线与尺寸计算；通过透明度和缩放过渡表达状态。
- 外层固定 `vertical-align: middle`，圆框显式使用 `box-sizing: border-box`。
- 保留 14 / 16 / 20px 三档圆框、现有配色和 Props；增加长标签换行约束。
- 装饰圆框设为 aria-hidden，原生 radio 保持命名、组内互斥与键盘行为。
- 动画消费 L3 → L2 `motion.interaction`，保留减少动画及系统强制颜色规则。

## 验证

- 独立实例 unchecked → checked：圆框、文字、外层、父级的坐标及尺寸变化均为 0px。
- 三档尺寸的 A → B 切换：六个选项的圆框、文字及外层坐标变化均为 0px；圆框分别为 20 / 16 / 14px。
- 原生方向键切换正常，focus-visible 焦点环为 2px。
- 主文档暗色示例切换前后相对坐标不变，使用暗色 L2 品牌填充和圆点配色。
- 320×720 视口中组宽 104px，无横向溢出，点击切换正常。
- 页面无浏览器错误；验证后关闭临时页面并恢复原主题和视口。
- Radio：令牌生成、库构建、lint、类型检查及 22 项 Wake 测试通过；新增三档尺寸的常驻圆点回归测试。
- 直接消费方 Table：104 项测试通过。
- 文档一致性检查、lint 和生产构建通过：81 条路由，1,901 个生产 JS 文件无未绑定引用。
