# 常规按钮中性描边设计

> 历史方案；当前常规按钮已采用[浅阴影设计](./button-shadow.md)。以下记录保留当时的验证结果。

日期：2026-09-17。范围：默认 / `subtle` 按钮及对应文档。

## 设计取舍

常规按钮保持中性，品牌色在交互时出现。参考 [Ant Design 默认按钮](https://ant.design/components/button) 的表面色、正文色与描边关系，以及 [MD3 outlined 按钮](https://material-web.dev/components/button/#outlined-button) 的次要操作层级和状态反馈，结合 Crab 的紧凑尺寸实现。

| 状态 | 文字 | 底色 | 边线 |
| --- | --- | --- | --- |
| 默认 | 主文字色 | 表面色 | 40% 语义边框色与表面色混合 |
| 悬停 | 85% 品牌色与 15% 主文字色 | 4% 品牌色与表面色混合 | 品牌色 |
| 按压 | 与悬停相同 | 8% 品牌色与表面色混合 | 品牌按压色 |
| 禁用 | 主文字色，整体透明度 0.4 | 禁用中性底色 | 弱边框色 |
| 加载 | 保留默认配色与 spinner | 保留默认底色 | 保留默认描边 |
| 选中 | 品牌色对应前景 | 强品牌填充 | 品牌色 |

默认描边在 Ant Design 的浅边线与 MD3 的强调轮廓之间取值，保留轮廓同时降低边线的视觉重量。交互文字混入主文字色以满足明暗下的文字对比度。没有增加投影、按压缩放、运行时取色逻辑或公共 Props。

全部颜色经 L3 消费现有 L2，使用 OKLCh；交互混色沿用品牌色相以避免近中性操作数导致偏色。保持 1px 边线、6px 圆角、24 / 32 / 40px 高度及原有内边距。公共 CSS 变量与旧别名保留。

## 自动验证

- 令牌生成和 Button 库构建通过。
- Button Wake：4 个测试文件，30 项测试通过；lint 0 错误 / 0 告警，类型检查通过。
- 默认明暗主题与 128 种品牌色：三态文字至少 4.5:1；焦点和交互态边线至少 3:1；选中前景至少 4.5:1。另验证常态颜色不受品牌种子影响，以及交互色相、颜色渐进、旧变量覆盖。
- 文档生成一致性、lint 与类型检查通过。
- 文档生产构建通过：81 个路由；1901 个生产 JavaScript 文件检查，0 个未绑定引用。

## 浏览器验收

在 Chrome 的本地生产文档页实测：

- 紫、蓝、绿品牌的明暗面板：常态保持中性；悬停文字、描边和淡底色跟随品牌，主按钮保持强填充。
- 紫色明暗两侧捕获真实鼠标按压：背景分别进入 8% 状态色，文字与悬停相同；按钮保持 54×32px，文字偏移保持 13px / 5.5px，无缩放。
- Tab 跳过原生禁用按钮；加载按钮保留焦点；Shift+Tab 返回普通按钮，显示 2px 焦点环和 2px 间隔。禁用项点击不改变演示反馈，配色保持中性，透明度为 0.4；加载配色保持正常，透明度为 1。
- 选中与未选中切换保持 68×32px；三档常规按钮实测高度为 24 / 32 / 40px。
- 320px 视口下检查明暗两侧的保存 + 取消、工具栏及按钮组：没有页面横向溢出；相邻按钮间隔保持 8px，工具栏空间不足时自然换行；按钮组选中不改变宽度或横向位置。验收后已恢复桌面视口。
- 修复示例外层 ConfigProvider 默认浅色导致深色文档说明文字过暗的问题：品牌色分别注入两个明暗面板，外层说明与品牌切换控件继承文档主题。深色页面已目视确认。
- 页面控制台未捕获错误。当前浏览器启用了减少动态效果；保留原有强制颜色规则，本轮没有开启操作系统强制颜色或关闭减少动态效果进行设备验收。
