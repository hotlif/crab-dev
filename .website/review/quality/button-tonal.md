# 常规按钮轻品牌色验收

日期：2026-09-17。范围：Button 默认 / `subtle` 外观及文档示例。

状态：历史设计验收。用户随后要求结合 Ant Design 与 MD3 重新设计，现行方案与验证见 [中性描边按钮验收](./button-outlined.md)。

## 实现

- L3 消费现有 L2 变量，底色品牌占比为 10% / 14% / 18%，边线为 20% / 28% / 36%，文字为 65% 品牌色与 35% 主文字色。
- 浏览器发现直接对显式中性色相进行 OKLCh 插值会使蓝、绿底色偏色。因此中性操作数采用 `oklch(from … l c none)`，保留明度、彩度和比例，色相沿用品牌色。全部由静态 CSS 计算。
- 保持 1px 边线、6px 圆角、24 / 32 / 40px 高度和既有内边距。常规按钮取消按压缩放，保留交互过渡、独立焦点环、禁用透明度、正常加载配色与强填充选中状态。
- 保留公共 CSS 变量和兼容别名；没有新增 Props、运行时取色、依赖或版本变更。
- 文档补充明暗选中状态、保存与取消、主操作与工具栏操作，修正默认外观和 subtle 被描述成不同层级的问题。

## 真实浏览器

在本地生产站点 `/components/rc-button` 实测，未以构建结果代替页面验收。

- 紫、蓝、绿 × 浅色、深色共六组：真实鼠标悬停、拖动期间持续按压，捕获 `:active` 的实际颜色与位置。文字颜色稳定，transform 为 none，按钮与文字尺寸、相对位置均无变化。
- 色相修正后，紫 / 蓝 / 绿三态底色、边线和文字分别保持约 293.709° / 259.039° / 164.666°，不再出现中性色相插值造成的偏色。
- Tab 跳过原生禁用项；加载项保留键盘可达但不能激活。焦点环 2px，间隔 2px；点击禁用和加载项不更新操作结果。
- 禁用使用主文字色、中性底色、透明边线与 0.4 透明度。加载保持正常颜色，spinner 实际 stroke 继承前景。切换选中后恢复强品牌填充，宽高不变。
- 默认大小普通与禁用按钮均为 54×32px，加载按钮为 76×32px，与修改前的既有 spinner 布局一致；三档高度实测 24 / 32 / 40px，圆角均为 6px。
- 320px：页面无横向溢出，主次操作可以换行；按钮组切换前后相邻按钮位置不变、间距 8px。
- `/design/forms` 的实际成员编辑表单：320px 下保存与取消入口完整，主按钮更醒目；标准密度覆盖仍保持 36px 高、8px 间距，明暗配色正确。
- 当前浏览器启用了减少动态效果，实测 transition 为 none。普通交互过渡与 forced-colors 规则保留；未将强制颜色的源码检查描述为操作系统模式实测。
