# Notification 叠层视觉调整

日期：2026-09-18。Wake / Crab CSS 0.1.45。

## 问题与修复

原实现声明 `--notification-stack-offset: token.stack.offset`，而这个令牌本身展开为同名变量的 `var()`，形成自引用。生产页面实测三条通知均位于 y=0，完全重合，且没有缩放和阴影层级。

- 移除自引用，直接使用 L3 令牌计算位移。前层距离边缘 24px，后两层每层错开 8px；底部方向取反。
- 三层缩放为 100% / 96% / 92%，使用明确的局部 z-index。后层使用较浅的阴影，并通过 L2 表面色和文字色的 OKLCh 混色区分明暗。
- 卡片采用统一宽度和 Grid 拉伸，避免长短内容造成不规则的叠层边缘；窄屏限制宽度，长内容可以在内容区滚动。
- 后层保留卡片外形，隐藏正文、进度和按钮，并设为 inert / aria-hidden。关闭前层后恢复下一层的完整内容与交互。
- 继续使用 CSS 过渡完成位移、缩放、表面色和阴影变化，无新增动画依赖。
- 基础示例增加「查看 3 条通知层叠」；新增六方向、长短内容混合、连续添加的进阶示例。文档示例总数同步为 248。

- 文档：lint、类型检查、26 项生成器测试通过；生成及生产构建通过，1,901 个生产 JS 文件无未绑定引用。
- 生产页面实测六个方向的三层位移分别为 ±24 / ±32 / ±40px，缩放为 1 / .96 / .92；逐条关闭和补位正常。
- 实测长短内容混合、浅色、暗色、320 × 720 视口；卡片边缘可辨认，正文与按钮不重叠，无内容横向溢出。
