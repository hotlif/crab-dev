# 常规按钮浅阴影设计

> 本页保留第一版阴影方案的验收记录。用户反馈出现双重轮廓后，现已移除内侧环线与第二层投影；修订结果见文末。

日期：2026-09-17。范围：默认 / `subtle` 按钮及对应示例。

## 设计

以中性表面和浅阴影替代可见描边，保留 Crab 的 24 / 32 / 40px 高度、6px 圆角和内边距。透明 1px 边框保留原来的尺寸占位及变量覆盖能力。

| 状态 | 表面与文字 | 阴影 |
| --- | --- | --- |
| 默认 | L2 抬升表面色、主文字色 | 极淡内侧边缘与小范围双层投影 |
| 悬停 | 4% 品牌底色、品牌文字 | 投影略微增强 |
| 按压 | 8% 品牌底色、同一交互文字色 | 投影收回，不缩放或移动 |
| 禁用 | 中性禁用底色与原有透明度 | 无阴影 |
| 加载 | 保留默认配色与 spinner | 保留默认阴影 |
| 选中 | 强品牌填充 | 无阴影，维持主次层级 |

暗黑主题通过 L2 抬升表面色与主文字色生成淡内侧亮边；外部投影颜色来自 L2 遮罩色。组件不按主题分支，没有运行时取色逻辑。三态阴影保持一致的层数和顺序，通过 `motion.interaction` 插值；减少动态效果时关闭过渡。强制颜色模式显式移除阴影并保留系统轮廓，键盘焦点环独立于阴影。

## 浏览器验收

在本地生产文档页实测，浏览器启用正常动效：

- 明暗两侧目视确认：浅色边缘柔和，深色表面抬升且有淡内侧亮边；主按钮的实色填充保持最醒目。普通按钮与加载按钮有默认阴影，禁用和选中按钮没有阴影。
- 捕获真实鼠标悬停和按压过渡，确认阴影从悬停增强到按压收回，使用 150ms 交互过渡。明暗按压采样均保持 54×32px、文字偏移 13px / 5.5px、transform 为 none。
- Tab 跳过原生禁用项，加载项仍可聚焦；Shift+Tab 返回普通按钮，独立焦点环为 2px，间隔 2px。选中切换后恢复常规阴影，按钮保持 68×32px。
- 320px 视口下检查绿色品牌的明暗表单操作区和工具栏；投影不挤占间距，按钮自然换行，没有页面横向溢出。按钮组选中前后尺寸和横向位置稳定，相邻间距为 8px。
- 三档常规按钮实测高度为 24 / 32 / 40px，圆角为 6px。临时视口已恢复。
- 文档构建过程中旧页面曾出现旧 chunk 加载失败，构建完成后刷新恢复，后续示例切换未新增错误。强制颜色及减少动态效果的适配保留在 CSS 中，本轮未切换操作系统设置验收。

## 单层阴影修订

根据实际截图，第一版的内侧环线与双层投影叠加成多重边缘，使小按钮看起来像带凹槽的输入框。因此默认阴影收敛为单层 `0 1px 2px`，悬停为 `0 2px 3px -1px`，按压时投影归零。投影颜色仍来自 L2 遮罩色；暗黑主题保留抬升表面，不再绘制内侧亮边。尺寸、间距、焦点环和品牌反馈不变。

- 在用户截图对应的基础示例卡片复查：常规按钮保持 82×32px，文字偏移保持 13px / 5.5px；默认计算样式只含单层 `0 1px 2px` 投影，浅色透明度为 0.09，没有 inset 或第二层投影。
