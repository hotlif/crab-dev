- RadioGroup selection, group keyboard arrows, every placement and all integration boundaries are outside this image set. Single-control defaults and state images do not prove those capabilities.
- No video was fully played or inspected second by second. Reduced-motion static PNGs establish visible appearance only.
- No original PNG, index, native report, source, build output or baseline was modified. No browser capture or build ran. No canonical approval, pixel baseline approval or verified coverage is granted.
