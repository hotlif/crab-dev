# Crab UI 官网与文档站改版

本轮日期：2026-11-05。改版前基准是当前工作区已包含 MD3 桌面紧凑化的版本，不使用历史截图代替本轮验收。

## 实现范围

- 首页采用最大 1280px 的居中展示区，移除常驻侧栏。首屏包含真实项目表单、状态反馈和视图切换；主题选择连接全站配置。
- 顶部五组导航进入真实页面，选中态和内页侧栏跟随当前路由；组件目录独立展示，保留清单派生的分类、数量和锚点。
- 目录卡片按桌面三列、平板两列、手机单列排列。文档标题使用独立容器，预览、示例说明、源码和 API 保留各自结构；正文行宽仍为 72ch。
- MD3 使用色调表面与变化圆角，Apple 使用中性表面和柔和阴影，shadcn 使用中性色和明确描边；真实组件继续通过公共 Provider 使用自身主题。
- 首屏三段错峰 0 / 75 / 150ms；位置和透明度分别使用 spatial / effects 令牌。滚动呈现使用共享 IntersectionObserver，一次入场后解除观察。
- 键盘焦点进入待展示区立即显示，减少动画模式直接呈现最终状态，缺少观察器时正常显示。没有新增动画依赖、逐帧滚动监听或持续漂浮动画。

路由、浏览器偏好、公共配置和 iframe 协议保持兼容。变更集中在站点自身的结构与样式，不改变组件公共 API、画布或 PDF 比例，也不提升产品清单的设计覆盖声明。

## 复核中修正的问题

| 问题 | 修正与回归 |
| --- | --- |
| 320px 下首页 MD3 分段选择器截短 shadcn 名称 | 站点入口使用公共 small 尺寸，保持原有 48px 触控命中规则；默认页面矩阵新增文字边界检查。 |
| 手机展台标题与实时预览标签争用空间 | 标题简化为“创建工作区”，保留真实 Card 与 Tag 的布局和主题。 |
| 顶部入口原本只切换侧栏，与实际页面的选中态可能不一致 | 五个真实页面链接跟随路由；修饰键仍交给浏览器，正常点击走原有导航。 |
| 移动抽屉扩展到桌面后，旧焦点恢复逻辑查找展开按钮 | 改为查找实际当前导航链接，首页使用品牌链接。 |
| 外观菜单定位期间隐藏，原生自动聚焦过早执行 | 仅在本站外观表面可见后聚焦当前模式；关闭或聚焦完成后解除观察。快速打开搜索也记录正确返回位置。浏览器检查明确断言菜单初始焦点、Home/End 和搜索取消后的焦点。 |
| 响应式规则重复分散在通用、预览和布局样式中 | 头部、侧栏及页面断点集中到布局样式；阅读与内容规则保留各自范围。 |
| MD3 的透明装饰边框在强制颜色模式下缺少明确边界 | 使用系统 CanvasText 边框，并确保优先级覆盖主题装饰规则。 |
| RTL 下侧栏仍固定在物理左侧，可能覆盖正文 | 侧栏改用逻辑方向定位，三主题浅深色均验证侧栏与正文边界不重叠。 |

最初的动效测试直接点击裁切的原生 radio，导致自动化等待超时；测试改为点击可见标签。Firefox 会保留关闭的原生 details 内部组件过渡，入场断言改为观察站点展示容器自身的动画，并继续检查最终透明度和位移；未取消组件动画，也未过滤运行时错误。最终统计只使用最终构建的运行与明确标出的单项重测。

## 仍未通过的检查

WebKit 在首页减少动画切换及重载场景间歇报告 `ResizeObserver loop completed with undelivered notifications.`。两项用例的页面行为断言执行完成，但公共测试夹具捕获到运行时错误，因此仍判定失败：[Apple 深色](diagnostics/webkit-apple-dark.md)、[shadcn 浅色](diagnostics/webkit-shadcn-light.md)。

独立诊断也复现了该警告。警告前最后一次观察回调来自首页组件墙的“应用类型”选择框，报告尺寸为 0 × 0；这是定位线索，尚不足以确认根因或证明属于原有组件缺陷。[观察记录](diagnostics/webkit-observer.json)保留回调来源。没有通过忽略警告、放宽断言或重复运行后隐藏失败来宣称通过；三主题在 WebKit 下的完整验收仍为部分完成。

## 兼容与验证边界

截图人工复核、交互断言和工程检查分别记录，不互相替代。默认视口截图只证明可见区域，不代表整页所有示例状态；跨浏览器结果不作为跨平台像素一致的证明。本轮执行了站点完整 `check` 与 `yarn docs:build`，未重新执行全库 `yarn check`，也没有同一提交的 CI 或线上发布结果。
