- 公共组件默认主题与文档站紫色主题有各自作用域；本次不迁移全库。
- 样板密度、排版和图标设计基准尚不构成全库稳定契约。
- Dialog / Drawer 的部分动效在 JavaScript 中配置，未统一改造为语义令牌。

- 表单缺少全局离开保护、多人编辑冲突、生产结果未知处理；默认保存不主动失败。
- 姓名长度采用 JavaScript 字符串计数，字段错误在提交时重新校验，文档已注明。
