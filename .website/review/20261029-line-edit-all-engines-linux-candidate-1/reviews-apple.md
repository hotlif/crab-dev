## 基准资格与限制

186图在各自真实可见范围内未见阻碍进入独立基准审批的问题，原生字节/来源匹配有效。此资格评估不等于基准批准；本任务没有执行建立基准后的两次稳定性复验，也不扩展为未拍摄状态/尺寸。

- Only Apple186 original native Linux PNGs were manually reviewed: Chromium150, Firefox18 and WebKit18. The Windows evidence is not reused or compared as a Linux pixel golden.
- Every duplicate-hash record was opened and viewed separately. Hash equality/differences do not substitute for interaction, motion or geometry assertions.
- Chromium core:54 cases/108PNG, light/dark×three sizes×nine states with outlined/filled actions; environment18 cases/36PNG, true zoom2 cases/4PNG, inventory2PNG.
- Firefox and WebKit each cover eight medium/standard core cases with sixteen PNG (light/dark×default/focus-visible/error/clear), plus two inventory PNG. No broader engine matrix is claimed.
- Apple outlined/filled share compact static labels and rectangular boundaries by the captured design contract; the review does not impose MD3 floating labels or notch behavior.
- Readonly core images show empty placeholders only. Existing-value readonly behavior, selection/copy and unchanged editing semantics are not established by those images; inventory CRAB-2026 is visible but has no dedicated readonly interaction proof here.
- Warning is a project Web extension. All twelve Chromium warning PNGs match the corrected semantic-label wording in captured docs; no Firefox/WebKit warning PNG exists in this subset.
- Long retained drafts show only current input scroll segments. Native Home/End, scrollLeft and full-value selection evidence is distinct from the visible fragment and prevents mistaking input clipping for draft loss.
- Actual browser zoom uses chrome.tabs.setZoom1→2 with Linux CSS viewport1280→640 and html/body zoom1; DPR change is a consequence, not a replacement. Four PNGs are complete visible viewports only, not full pages.
- No-PNG configuration boundary runs pass per engine and check the same DOM inputs/draft while switching all six configurations to large/comfortable/English/RTL. These are behavior evidence and are not manually reviewed images.
- Environment touch hit areas, label/support geometry, focus identity, errors and state properties remain native assertions; no exact contrast or pixel dimension is inferred from appearance alone.
- No video was fully played or reviewed second by second. Reduced-motion PNGs establish static appearance only.
- No source, original PNG, report/index, build output or baseline was changed. No capture or build was started. No canonical/baseline approval or verified design coverage is granted.
