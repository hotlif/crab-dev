# macOS Tahoe 桌面比例校准

用户用途：工程管理与设备运维，设备树、台账、属性面板与多任务工作区。目标是接近 Tahoe 26 的专业桌面观感，同时保持长时间读取、参数编辑和键盘操作的稳定性。

## 依据与适配

- [WWDC25 AppKit](https://developer.apple.com/videos/play/wwdc2025/310/)：工具按钮按操作分组，标题与状态文字不铺玻璃；侧栏浮动，属性面板贴边；窗口和内部轮廓协调。
- [Meet Liquid Glass](https://developer.apple.com/videos/play/wwdc2025/219/)与[Materials](https://developer.apple.com/design/human-interface-guidelines/materials)：导航和操作层与内容层区分，避免玻璃叠玻璃；数据与字段保持清晰。

13px 正文、28/32/36px 字段、8px 控件轮廓及材质滤镜是本库的 Web 适配值，不是 AppKit 常量。当前 CSS 不具备原生动态折射、环境采样与合成器的完整能力。

## 本轮改动

- 设备工作台重新组织标题、任务页签、操作分组、搜索区和底部状态；侧栏采用浮动材质，属性面板贴边。正文区域使用稳定的实色。
- 表格按可用宽度分配设备名称、系统和日期列，避免右侧空白；保留可调列宽和整行单选，用设备编号替代额外行号。通过公开 `rowSelection.showColumn=false` 隐藏选择控件列，保留行的选中状态与语义，沿用现有行点击/Enter 更新受控选择。属性按识别信息、只读事实和可编辑参数分组。
- 图标采用一致的线条与尺寸；不把没有子节点的系统节点显示成可展开文件夹。
- L1 补充 13px 字阶；L2 的 macOS 正文、字段、按钮及表头降低字重和尺寸，内容边界与纵向网格减轻。通过公共 Theme/语义令牌传播到菜单、表单、反馈、导航、数据及编辑器。
- 玻璃移除固定斜向亮带，降低底色遮挡、饱和度和控件浮雕，保留导航、浮层的边缘与层次。输入框的内阴影减轻，外部焦点环与高对比度退化保持独立。
- 更新字段尺寸说明与既有几何回归；工作台回归补充列宽填满可用区域检查，继续检查设备/任务切换中的草稿与窗口缩放后的模态状态。
- 键盘验收明确了既有 Table 的边界：Enter 激活最后点选的单元格锚点所在行，未实现方向键逐行浏览。隐藏选择列的工作台提供可聚焦的上一台/下一台按钮，避免设备切换仅剩鼠标入口；没有把现有表格描述为完整的原生键盘网格。
