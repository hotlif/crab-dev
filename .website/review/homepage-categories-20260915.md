# 首页组件分类区优化

日期：2026-09-15。页面：`http://127.0.0.1:4173/`。

## 调整依据与完成内容

用户截图中的六组分类靠大面积留白分隔，中英文被拆成两行，分类说明与组件入口缺少共同边界。本次仅调整首页组件分类区。

- 复用现有 Card filled 变体，以 L2 表面底色形成六个分类块；具体标题和组件链接继续复用 Button。分类块只承担分组，不增加整卡点击、悬浮位移或阴影。
- 移除分类序号，保留分类标题、用途说明、分类入口箭头及全部 24 个组件入口。
- 中英文名称优先同行，通过字重、字号和文字角色区分；窄屏单列时中文在左、英文在右。
- 标题、说明和组件名称对齐，内边距只由 Card 内容层提供。链接的点击区域向文字两侧扩展，保留可见键盘焦点。

## 局部规格

以下均为首页局部布局，不修改公共默认令牌。

| 部位 | 规则与来源 |
| --- | --- |
| 分类底色 | `token.color.background.surface`，跟随站点 L2 明暗主题 |
| 分类内容内边距 | 960 px 起 24 px，来自 `globalToken.space[6]`；959 px 以下 16 px，来自 `token.space["section-gap"]` |
| 分类块间距 | 16 px，来自 `token.space["section-gap"]` |
| 分类列数 | 1200 px 起三列；640–1199 px 两列；639 px 以下一列 |
| 每类组件入口 | 默认两列；399 px 以下一列。DOM 顺序始终为逐行阅读顺序 |
| 入口高度 | 至少 44 px，沿用首页局部触控规格 |
| 链接内部留白 | 8 px；标题与链接抵消这层留白后，文字与说明共用左侧基线 |
| 名称与入口间距 | 中英文之间及入口网格间距均为 4 px；在 640 px 两列布局下为 AutoSizer 等较长名称保留空间 |
| 强制颜色 | 分类框使用系统 CanvasText 边界，焦点使用 Highlight |
