# Drawer CSS 动效调整

日期：2026-09-18。工具链：Wake / Crab CSS 0.1.45。

## 原因与调整

- 原面板进入为 300ms、退出为 200ms，两者均使用 `cubic-bezier(0, 0, 0.2, 1)`，大距离位移在开始阶段过快。新增 L2 `motion.slide-enter` / `motion.slide-exit`，分别引用 L1 的慢速 + 标准缓动、常速 + 加速缓动；Drawer 通过 L3 消费。
- 进入改为 300ms `cubic-bezier(0.4, 0, 0.2, 1)`，退出改为 200ms `cubic-bezier(0.4, 0, 1, 1)`，关闭时遮罩与面板使用相同节奏。
- 原四方向示例关闭时清空 `placement`，导致左、上、下抽屉瞬间按右侧布局退出。浏览器确认顶部面板关闭后变为 `data-placement="right"`。示例现在独立管理方向和开关，关闭期间保留方向、尺寸及标题。
- `showModal()` 改在 layout effect 中调用，使原生模态层在绘制前就绪。内容的挂载与卸载统一由 presence 生命周期控制，去掉重开后再通过 effect 恢复内容的一轮更新。
- 继续使用 CSS 位移和透明度过渡。退出完成才关闭原生 dialog、释放滚动锁；支持中途反向与减少动画，无新增动画依赖。
