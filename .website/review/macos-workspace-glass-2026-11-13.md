# 工程设备工作台：局部玻璃层次复核

## 范围和依据

本轮只调整设计体系指南中的工程设备工作台，不把页面试验扩展到共享 macOS 主题，也不提高产品清单的设计覆盖。

依据 Apple [Materials](https://developer.apple.com/design/human-interface-guidelines/materials/) 和 [Build an AppKit app with the new design](https://developer.apple.com/videos/play/wwdc2025/310/)：功能层与内容层分离，操作按钮按逻辑共用材质，侧栏浮在内容之上，属性检查器贴边；移除遮挡玻璃的旧材质。CSS 数值属于本库的 Web 适配，并非 AppKit 常量。

## 页面调整

- 通过公开 Dialog TokenVars 关闭外层内容容器的滤镜，避免玻璃叠在玻璃上。窗口使用连续、低饱和度的背景，两侧功能区透出该背景；不增加壁纸或复制表格文字。
- 侧栏、操作组和属性面板分别使用透明底色、`backdrop-filter`、边缘反光和阴影，区分浮动侧栏、薄按钮组与贴边检查器的厚度。
- 去掉按钮组内部的实色主按钮和重叠描边；创建操作保留强调色文字。属性中的保存按钮仅在草稿有改动时启用，还原也跟随真实修改状态。
- 表格保持实色、13px 正文与既有紧凑行密度，去掉外层卡片圆角并减轻横向分隔。焦点在表格中时使用强调色选中行，焦点离开后使用中性选中底色；状态仍有文字和形状。
- 属性按设备身份、只读事实和编辑参数分组，字段使用较薄的填充与边框。分栏不再常驻双重描边，保留鼠标悬停、拖动和键盘焦点反馈。
- 无滤镜支持时使用不透明材质；减少透明度或增加对比度时关闭滤镜；强制颜色使用系统颜色并保留选中、焦点和分栏边界。

实屏状态检查发现，现有 Table 单元格选区逻辑会清除旧编辑器的焦点，较早的 `pointerdown` 焦点设置会被覆盖。本页通过公开 `onMouseDown` 在冒泡阶段恢复网格焦点，已在增量预览中核对浅深色的实际点击行为。共享 Table 的实现和键盘契约保持原样；设备逐项切换仍由属性面板的上一台 / 下一台按钮提供。
