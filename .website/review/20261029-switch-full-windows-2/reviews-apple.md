## 限制


- Only Apple94 original Windows Chromium PNGs were manually reviewed. No Linux, Firefox or WebKit matrix is claimed from this candidate.
- Duplicate-hash records were actually opened one by one; equal/different hashes do not prove interaction, motion or geometry.
- Core is72 cases: light/dark×three public sizes×twelve states, density standard. Nine ordinary environments×two modes are18 images, with two real200% and two default inventory images.
- Environment60 in native total includes six real zoom tests. Native283 =216 core+54 ordinary environment+6 zoom+6 inventory+1 no-PNG boundary.
- Standalone density variants, loading and mixed are excluded by package visual.json with reasons: density affects collection spacing, async loading belongs to the owner, Switch has no mixed protocol.
- Visible track is distinct from hit region. Native CDP geometry and actual edge clicks/taps, not a PNG or a copied CSS formula, prove the48px hit target and overflow accounting.
- Real200% is chrome.tabs.setZoom1→2 with Windows CSS viewport1264→632 and html/body zoom1. DPR changes because of real zoom. The PNGs show whole visible viewports, not whole pages.
- RTL images show selected white thumb toward inline-end (left); ordinary LTR selected thumb is right. English long text wraps normally; neither environment shows every error/disabled/focus combination.
- No-PNG boundary checks forced disabled-selected/restoration, same DOM retention, and checked/feedback across six configurations and size/density/English/RTL; not a manually viewed appearance sequence.
- No complete video or second-by-second motion review occurred; reduced-motion stills show static appearance only.
- Old failed run remains unchanged. Product asset identity does not turn old failed assertions or unreviewed old images into new passes.
- No original PNG, source, report/index, artifact or baseline was modified; no capture/build ran. No canonical, baseline approval or verified coverage is granted.
