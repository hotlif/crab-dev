# 审查证据

本目录保存历史审查与本轮验证记录。现行架构、公共 API、设计体系和维护规则以 `../docs/guides/` 为准；旧日志中的命名、工具版本与结论不得直接沿用为当前状态。

新验证写入 `runs/<日期或时间戳>/`，每次运行独立保存，不覆盖先前证据。记录至少包括：日期、源码提交或工作区范围、构建产物指纹、命令、浏览器条件、实际结果、失败与重试、未验证范围。未提交工作区必须明确标记，不能将 HEAD 当作全部改动的唯一版本依据。

`productionRevision()` 对实际服务目录全部文件计算指纹，页面壳相同不代表脚本和样式相同。源码、包构建或站点构建变化后，先前产物上的浏览器结果需要重新核对。

- 工程测试证明其断言范围，不代替布局或设计评审。
- L2 变量一致性证明设计边界传播，不代替全部组件状态验收。
- 截图和自动尺寸检查只覆盖所记录的组件、视口与状态。
- `partial` 只有在对应设计体系的完整矩阵和当前产物证据满足要求后才能升级为 `verified`。

根目录和旧专题文件夹保留为历史，不重命名、批量搬迁或删除。浏览器 profile、临时夹具构建、缓存与输出目录不作为正式证据提交。当前候选的验收索引应由本次运行结果建立，不能通过文件名中的 `final`、`verified` 或日期推断通过。
