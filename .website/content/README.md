# 教学内容维护

每个组件包对应一份 `rc-*.json`，三个实战对应 `practice-profile.json`、`practice-data.json` 和 `practice-admin.json`。这里是教学文字的源文件，不要修改生成的组件页。

一份教程包括 `id`、`title`、`summary`、`prerequisite`、`steps` 和 `faq`。每个步骤填写：

| 字段 | 写作要求 |
| --- | --- |
| `id` / `title` | 稳定步骤 ID 与简短任务名称 |
| `goal` | 完成本步后具备什么能力 |
| `why` | 为什么这样修改，以及对应的组件概念 |
| `changes` | 相对上一步的关键代码变化，用具体属性或函数名称说明 |
| `instruction` | 读者应在预览中执行什么操作 |
| `expected` | 可观察、可重复验证的结果 |
| `source` | 相对 `.website/docs/examples/` 的完整 TSX 文件路径 |

普通组件维护 2–4 步，实战按任务拆分。第一步必须可以独立运行。工具与令牌包应讲解数据、样式或运行环境，不要强行包装成按钮交互。

最小示例只保留目标组件所需的导入、属性和状态。只有一个子组件时，直接返回它，不要统一套 `layout`、`grid` 或宽度设置。新增样式必须能说明它服务于哪个教学目标：例如表格容器尺寸、表单字段间距或图形坐标。不要为演示容器的留白重复引入 `css` 和 `token`；这些样式也不能移到隐藏辅助文件以缩短展示代码。

示例只使用公开包入口；不要导入相邻示例、组件 `src/` 或隐藏辅助文件。所有必要的 Hook、类型、数据、模拟函数、CSS 入口都放在当前示例中。属性调整直接写进示例，读者复制到项目后仍然可以操作。需要隔离导航时使用示例自己的 History；旧进阶示例继续由工作台 iframe 承载。

修改后，在 `.website` 运行：

```sh
yarn generate:docs
yarn test:generator
yarn check:docs
yarn test
yarn typecheck
yarn eslint
yarn build
yarn preview
```

生成器从运行文件读取源码，不维护第二份展示代码。它检查教学字段、源码语法、越界路径、遗漏教程、孤儿示例和生成漂移，并刷新组件页、实战页、学习地图及可搜索的步骤文字。开发服务器会监听本目录和 `docs/examples/`。

浏览器验收包括每一步的操作与预期结果、切换后的状态隔离、重置、复制、失败重试，以及 320 px、平板、桌面、深色主题、键盘焦点、强制颜色和减少动画。固定本地模拟请求不等同于后端联调。

## 全局令牌参考手册

`rc-token-global` 使用独立参考布局，其他组件仍使用普通教学模板。主正文维护于 `components/rc-token-global/docs/index.mdx`；其中 `token-tutorial` 注释插入一次两步教程，`token-reference:分类` 注释插入对应完整参数展示，原有 Demos 标记连接工作台。使用二级标题建立目录，不再把正文降级到“使用说明”下。

`scripts/generate-token-reference.mjs` 读取公共 `token.toml` 中当前使用的点分键、双引号字符串语法；遇到重复键、未支持语法或未知类别应失败，不能静默漏项。扩展 TOML 写法时同步扩展读取器与测试。生成器输出 `docs/_generated/globalTokenReference.ts`，其中原始值、公共表达式、变量名与静态样式共同生成；完整目录也写入页面搜索索引。生成产物不得手改。

`docs/site/tokenReference.tsx` 与 `tokenReferenceStyles.ts` 只负责私有参考展示和操作，不是新的公共 API。样本使用被展示的 L1 引用，并在样本节点将该变量设为 initial，使其使用公共回退值；这样站点的 L1 sans 字体覆盖不会污染原始样本。阅读框架使用 L2，舞台尺寸为站点私有参数。分类内按源码顺序展示，保留零值；颜色标签不直接覆盖色块。新增基元必须登记分类、样本绘制方法并验证窄屏、主题与源码一致性。

参考展示按比较任务组织：颜色使用连续色阶带；圆角、阴影和透明度使用共享舞台；间距、排版与动效使用对齐列表；层级在同一堆叠上下文内展示。不得恢复每个参数的重复卡片外框或用分隔线替代间距分组。选择规则位于参数展示之前，源码维护附注集中在末章。

颜色和共享舞台只保留一个当前详情区，以左右方向键、Home、End 选择样本，Tab 离开样本组。当前样本同时以名称、选中标记和 `aria-pressed` 表达；切换时清除原复制反馈。列表默认显示名称、数值和样本，使用“代码”展开详细值。详情分别提供“复制引用”与“复制变量名”，失败时保留可选中的文字。色阶在窄屏局部横向滚动，不把样本压缩成难以点击的细条。

生成器测试检查目录覆盖、边界语法、漂移和参考页布局；站点交互测试检查复制成功、失败重试、键盘切换、反馈重置与主动动效。生产验收同时检查 CSS 最终计算值、共享详情的高度稳定性及 320 / 768 / 1440 px 明暗主题，防止样本样式被通用布局覆盖。工具链已有阻塞需在 `.website/review/` 单独记录，不以构建成功替代测试通过。
